# Подробный конспект по CSS с практическими заданиями

## Теоретическая часть:active — активируется в момент клика/нажатия на элемент


### **Псевдоклассы (`:pseudo-class`)**

Псевдоклассы — это специальные ключевые слова, которые добавляются к селекторам и определяют **особое состояние** элемента. Они позволяют применять стили к элементам в зависимости от взаимодействия пользователя или их положения в документе.

**Основные псевдоклассы состояния:**
- **`:hover`** — срабатывает при наведении курсора мыши на элемент
- **`:active`** — активируется в момент клика/нажатия на элемент
- **`:focus`** — применяется, когда элемент получает фокус (поля ввода, кнопки)
- **`:visited`** — для уже посещенных ссылок
- **`:disabled`** — для заблокированных элементов форм

**Структурные псевдоклассы:**
- **`:first-child`** — выбирает первый дочерний элемент родителя
- **`:last-child`** — выбирает последний дочерний элемент родителя  
- **`:nth-child(n)`** — выбирает элементы по их порядковому номеру
- **`:nth-of-type(n)`** — выбирает элементы определенного типа по номеру

```css
/* Примеры использования псевдоклассов */
a:hover {
    color: red;
    text-decoration: underline;
}

button:active {
    transform: scale(0.95);
    box-shadow: inset 0 2px 4px rgba(0,0,0,0.2);
}

input:focus {
    border-color: #4d90fe;
    outline: none;
    box-shadow: 0 0 5px rgba(77,144,254,0.5);
}

tr:nth-child(even) {
    background: #f8f9fa;
}

li:first-child {
    font-weight: bold;
    color: #2c3e50;
}
```

### **Псевдоэлементы (`::pseudo-element`)**

Псевдоэлементы позволяют стилизовать **определенные части элемента** или добавлять декоративное содержимое без изменения HTML-структуры.

**Основные псевдоэлементы:**
- **`::before`** — создает псевдоэлемент, который является первым потомком выбранного элемента
- **`::after`** — создает псевдоэлемент, который является последним потомком выбранного элемента
- **`::first-letter`** — выбирает первую букву текста элемента
- **`::first-line`** — выбирает первую строку текста элемента
- **`::selection`** — стилизует выделенный пользователем текст

```css
/* Примеры использования псевдоэлементов */
.warning::before {
    content: "⚠️ ";
    color: #e67e22;
    font-weight: bold;
}

.link::after {
    content: " →";
    color: #3498db;
    transition: transform 0.2s;
}

.link:hover::after {
    transform: translateX(3px);
}

p::first-letter {
    font-size: 200%;
    color: #e74c3c;
    float: left;
    line-height: 1;
    margin-right: 5px;
}

p::first-line {
    font-weight: bold;
    color: #2c3e50;
}

::selection {
    background-color: #3498db;
    color: white;
}
```

### **Наследование в CSS**

Наследование — это механизм, при котором некоторые CSS-свойства автоматически передаются от родительских элементов к дочерним.

**Наследуемые свойства** (в основном текстовые):
- `color`, `font-family`, `font-size`, `font-weight`, `line-height`
- `text-align`, `text-indent`, `letter-spacing`, `word-spacing`
- `visibility`, `cursor`, `list-style`

**Ненаследуемые свойства** (в основном блочные):
- `border`, `margin`, `padding`, `background`, `width`, `height`
- `display`, `position`, `float`, `overflow`

```css
/* Пример наследования */
body {
    color: #34495e;        /* Наследуется всеми текстовыми элементами */
    font-family: 'Segoe UI', sans-serif;
    line-height: 1.6;
}

.container {
    border: 2px solid #bdc3c7;  /* Не наследуется дочерними элементами */
    padding: 20px;
    background: #ecf0f1;
}

/* Явное указание наследования */
.special-box {
    border: inherit;       /* Явно наследует границу от родителя */
    color: initial;        /* Сбрасывает наследование цвета */
}
```

### **Каскад и Специфичность**

Когда к элементу применяются конфликтующие стили, браузер использует систему приоритетов:

**Факторы каскада (в порядке важности):**
1. **Важность (`!important`)**
2. **Специфичность селектора**
3. **Порядок объявления в коде**

**Система специфичности (вес селекторов):**
- **Инлайн-стили** — 1000 баллов
- **ID-селекторы** — 100 баллов
- **Классы, псевдоклассы, атрибуты** — 10 баллов
- **Элементы, псевдоэлементы** — 1 балл

```css
/* Примеры специфичности */
p { color: black; }                    /* Вес: 1 */
.text { color: blue; }                 /* Вес: 10 */
p.text { color: green; }               /* Вес: 1 + 10 = 11 */
#header p { color: red; }              /* Вес: 100 + 1 = 101 */
p { color: yellow !important; }        !important перебивает всё

/* Практический пример разрешения конфликтов */
<div class="container" id="main">
    <p class="text special">Какой цвет будет у этого текста?</p>
</div>

#main p { color: red; }                /* Вес: 100 + 1 = 101 */
.container .text { color: blue; }      /* Вес: 10 + 10 = 20 */
p.special { color: green; }            /* Вес: 1 + 10 = 11 */
p { color: black; }                    /* Вес: 1 */

/* Победит красный цвет (наибольший вес) */
```
