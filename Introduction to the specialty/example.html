Практические задания

Задание 1: Навигационное меню

Стилизуйте меню в левой колонке:

  • Изменение цвета при наведении
  • Выделение первого пункта
  • Разный фон для четных/нечетных пунктов
/* Ваш код для задания 1 */ .menu-example ul li:hover { /* Добавьте стили для наведения */ } .menu-example ul li:first-child { /* Стили для первого элемента */ } .menu-example ul li:nth-child(even) { /* Стили для четных элементов */ }

Задание 2: Псевдоэлементы

Добавьте декоративные элементы:

  • Иконки перед уведомлениями
  • Специальное оформление для цитат
  • Стилизация первой буквы параграфов
/* Ваш код для задания 2 */ .warning::before { content: ""; /* Добавьте иконку предупреждения */ } .quote::after { content: ""; /* Добавьте декоративный элемент */ } p::first-letter { /* Стилизация первой буквы */ }

Задание 3: Конфликт стилей

Создайте элементы с конфликтующими стилями:

Тестовый текст

/* Экспериментируйте с этими стилями */ #unique { color: red; } .special { color: blue; } .text { color: green; } p { color: black; } .text { color: orange !important; }
