## Практические задания (общие для обоих вариантов)

### Задание 1: Создайте HTML-структуру
Напишите HTML-код для страницы с:
- Заголовком h1 "Мой сайт"
- Навигационным меню с 3 пунктами
- Статьей с заголовком и двумя абзацами текста
- Изображением
- Футером с копирайтом

### Задание 2: Напишите CSS стили
Создайте CSS-код для:
- Установки шрифта Arial для всей страницы
- Стилизации навигационного меню (горизонтальное, без маркеров)
- Добавления рамки вокруг статьи
- Изменения цвета ссылок при наведении

### Задание 3: Комбинированная задача
Создайте карточку товара с:
- Изображением товара
- Названием
- Описанием
- Ценой
- Кнопкой "Купить"
И стилизуйте ее с использованием:
- Тени
- Скругленных углов
- Эффектов при наведении
- Псевдоэлементов
