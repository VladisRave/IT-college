# Тест по основам HTML и CSS

## Вариант 2

### Теоретические вопросы

**1. Какой тег используется для создания заголовка первого уровня?**
а) `<h1>`
б) `<head>`
в) `<header>`
г) `<h>`

**2. Какой тег используется для создания абзаца?**
а) `<p>`
б) `<par>`
в) `<text>`
г) `<div>`

**3. Как задать внутренние отступы в CSS?**
а) `margin`
б) `padding`
в) `indent`
г) `spacing`

**4. Какой селектор выбирает элементы с class="menu"?**
а) `#menu`
б) `.menu`
в) `menu`
г) `class=menu`

**5. Как сделать фон элемента красным?**
а) `background-color: red;`
б) `color: red;`
в) `bgcolor: red;`
г) `background: red;`

**6. Какой тег используется для создания ненумерованного списка?**
а) `<ol>`
б) `<ul>`
в) `<li>`
г) `<list>`

**7. Какое свойство CSS используется для изменения размера текста?**
а) `text-size`
б) `font-size`
в) `size`
г) `text-scale`

**8. Какой из следующих селекторов выбирает все элементы с классом .btn?**
а) `btn`
б) `#btn`
в) `.btn`
г) `*btn`

**9. Как сделать полужирный текст в HTML без CSS?**
а) `<strong>`
б) `<b>`
в) Оба варианта верны
г) Ни один из вариантов

**10. Какой тег используется для создания строки таблицы?**
а) `<td>`
б) `<tr>`
в) `<th>`
г) `<table-row>`

**11. Какой атрибут используется для задания альтернативного текста изображения?**
а) `alt`
б) `title`
в) `description`
г) `src`

**12. Какое свойство CSS изменяет курсор при наведении?**
а) `cursor`
б) `pointer`
в) `mouse`
г) `hover`

**13. Как задать границу элемента?**
а) `border-style`
б) `border-width`
в) `border-color`
г) Все вышеперечисленные

**14. Какой псевдокласс применяется к ссылке при наведении?**
а) `:hover`
б) `:active`
в) `:focus`
г) `:link`

**15. Какой тег используется для создания выпадающего списка?**
а) `<select>`
б) `<option>`
в) `<dropdown>`
г) `<list>`
