# Тест по основам HTML и CSS

## Вариант 1

### Теоретические вопросы

**1. Какой тег используется для создания ссылки в HTML?**
а) `<link>`
б) `<a>`
в) `<href>`
г) `<url>`

**2. Какой атрибут указывает адрес ссылки в теге `<a>`?**
а) `src`
б) `href`
в) `link`
г) `url`

**3. Как правильно подключить внешний файл CSS?**
а) `<style src="style.css">`
б) `<stylesheet>style.css</stylesheet>`
в) `<link rel="stylesheet" href="style.css">`
г) `<css>style.css</css>`

**4. Какой селектор выбирает элемент с id="header"?**
а) `#header`
б) `.header`
в) `header`
г) `id=header`

**5. Какое свойство CSS меняет цвет текста?**
а) `text-color`
б) `color`
в) `font-color`
г) `text-style`

**6. Как задать жирность текста в CSS?**
а) `font-weight: bold;`
б) `text-style: bold;`
в) `font: bold;`
г) `weight: bold;`

**7. Какой тег используется для создания нумерованного списка?**
а) `<ul>`
б) `<ol>`
в) `<li>`
г) `<list>`

**8. Какое свойство CSS используется для изменения внешних отступов?**
а) `padding`
б) `margin`
в) `border`
г) `spacing`

**9. Какой из следующих селекторов выбирает все элементы `<p>`?**
а) `p`
б) `#p`
в) `.p`
г) `all.p`

**10. Как сделать текст выровненным по центру?**
а) `text-align: center;`
б) `align: center;`
в) `text-position: center;`
г) `font-align: center;`

**11. Какой тег используется для вставки изображения?**
а) `<img>`
б) `<image>`
в) `<pic>`
г) `<src>`

**12. Какой атрибут тега `<img>` задает путь к изображению?**
а) `src`
б) `href`
в) `link`
г) `url`

**13. Какое свойство CSS скрывает элемент?**
а) `visibility: hidden;`
б) `display: none;`
в) Оба варианта верны
г) Ни один из вариантов

**14. Как изменить шрифт текста в CSS?**
а) `font-family`
б) `font-style`
в) `text-font`
г) `font-type`

**15. Какой тег используется для создания таблицы?**
а) `<table>`
б) `<tr>`
в) `<td>`
г) `<tab>`
