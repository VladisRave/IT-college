# Практические задания для студентов

### **Задание 1: Стилизация навигационного меню** (15 минут)

**Цель:** Научиться работать с псевдоклассами `:hover`, `:first-child`, `:nth-child()`

**Задачи:**
1. Сделайте пункты меню блочными с отступами
2. Добавьте изменение фона и цвета текста при наведении
3. Выделите первый пункт жирным шрифтом и другим цветом
4. Для четных пунктов задайте светлый фон
5. Добавьте плавные переходы для всех изменений

**Подсказка:**
```css
.menu-example ul {
    list-style: none;
}
.menu-example li {
    padding: 10px;
    margin: 5px 0;
    transition: all 0.3s ease;
}
```

---

### **Задание 2: Работа с псевдоэлементами** (15 минут)

**Цель:** Освоить `::before`, `::after`, `::first-letter`

**Задачи:**
1. Добавьте иконку ⚠️ перед предупреждающими уведомлениями
2. Для информационных уведомлений добавьте иконку ℹ️
3. После цитат добавьте декоративные кавычки
4. Сделайте первую букву в цитатах крупнее и другого цвета
5. Добавьте небольшую анимацию при наведении на уведомления

**Подсказка:**
```css
.warning::before {
    content: "⚠️ ";
    margin-right: 10px;
    font-weight: bold;
}
```

### **Задание 3: Исследование специфичности** (10 минут)

**Цель:** Понять принципы каскада и специфичности

**Задачи:**
1. Создайте конфликтующие правила для элемента с текстом "Тестовый текст"
2. Попробуйте предсказать, какой цвет применится
3. Используйте `!important` для переопределения
4. Измените порядок объявления стилей и посмотрите на результат
5. Поэкспериментируйте с комбинациями селекторов

---

### **Задание 4: Наследование свойств** (5 минут)

**Цель:** Изучить наследование CSS-свойств

**Задачи:**
1. Проверьте, наследуется ли цвет текста дочерним элементом
2. Проверьте, наследуются ли граница и отступы
3. Попробуйте явно задать наследование с помощью `inherit`
4. Сбросьте наследование с помощью `initial`
