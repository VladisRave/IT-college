# **Дифференцированный зачет по предмету «Введение в специальность»**

Данный документ содержит перечень всех тем, необходимых для успешной сдачи зачета. Так как курс был сфокусирован на веб-разработке и основах геймдева, данные разделы представлены наиболее подробно.

### **Глава 1: Введение в IT-профессии**
*   Понятия «Информационные системы» и «Программирование».
*   Краткий обзор языков программирования: низкоуровневые vs высокоуровневые, компилируемые vs интерпретируемые.
*   Ключевые профессии в сфере разработки: веб-разработчик (frontend/backend), геймдев-программист, мобильный разработчик, специалист по данным. Особенности работы каждого из них.
*   Понятие «кадры цифровой экономики». Какие soft и hard skills важны для IT-специалиста.

### **Глава 2: Процесс разработки программного обеспечения**
*   Жизненный цикл программного продукта (ПО): планирование, разработка, тестирование, внедрение, сопровождение.
*   Основные этапы создания программы: анализ, проектирование, кодирование, отладка, тестирование.
*   Инструменты разработчика:
    *   **Среды разработки (IDE)** и редакторы кода: назначение и основные функции.
    *   **Трансляторы:** компиляторы и интерпретаторы, их отличия.
*   Контроль версий как основа командной работы. Система **Git** и платформа **GitHub**:
    *   Базовые понятия: репозиторий, коммит, ветка.
    *   Основной workflow: создание ветки (`feature-branch`), коммиты, создание Pull Request (Merge Request) для code review.

### **Глава 3: Основы веб-разработки (Frontend)**
*   **Базовые технологии «клиентской части» (Frontend):**
    *   **HTML (HyperText Markup Language):**
        *   Назначение и роль в создании веб-страниц.
        *   Базовая структура документа (`<html>`, `<head>`, `<body>`).
        *   Основные теги для разметки: заголовки (`<h1>`), параграфы (`<p>`), ссылки (`<a>`), изображения (`<img>`), списки, блоки (`<div>`, `<span>`).
    *   **CSS (Cascading Style Sheets):**
        *   Назначение – оформление и вёрстка.
        *   Основной синтаксис: селекторы, свойства, значения.
        *   Способы добавления стилей на страницу: inline, внутренние (`<style>`), внешние (подключение файла `.css` через `<link>`).

### **Глава 4: Основы разработки игр на Python (библиотека PyGame)**
*   Введение в геймдев: основные концепции (игровой цикл, обработка событий, отрисовка спрайтов).
*   Библиотека **PyGame**:
    *   Особенности и возможности: работа с графикой, звуком, обработка ввода с клавиатуры и мыши.
    *   Отличия от других библиотек (простота для 2D, ориентированность на обучение и прототипирование).
    *   Базовые понятия PyGame:
        1.  Инициализация и создание окна игры.
        2.  Главный игровой цикл (`while running`).
        3.  Обработка событий (`pygame.event.get()`).
        4.  Отрисовка объектов (`screen.fill()`, `screen.blit()`).
        5.  Работа со спрайтами и текстурой (Surface).
