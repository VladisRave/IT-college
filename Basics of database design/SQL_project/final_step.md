- **Время выполнения:** 3 часа
- **Можно использовать:** черновик, ручку, простой калькулятор
- **Нельзя использовать:** интернет, телефон, готовые решения

## **ВАРИАНТ 1**

### **Задача 1: Концептуальное проектирование**
**Ситуация:** Нужно спроектировать БД для спортивной секции. Секция проводит тренировки, соревнования, ведет учет посещений.

**Задание:**
1. Перечислите минимум 5 сущностей (таблиц), которые понадобятся
2. Для каждой сущности напишите 3-4 ключевых атрибута
3. Нарисуйте схему связей между сущностями или опишите их словами

*Если не можете нарисовать - опишите алгоритм создания таблиц*

### **Задача 2: Нормализация**
**Дана денормализованная таблица:**
```
Тренировки (ид_тренировки, дата, тренер_ид, тренер_имя, тренер_телефон, 
           спортсмен_ид, спортсмен_имя, спортсмен_разряд, вид_спорта, результат)
```

**Задание:**
1. Объясните 2 проблемы такой структуры
2. Приведите таблицу к 3НФ (третьей нормальной форме)
3. Опишите получившиеся таблицы

### **Задача 3: SQL DDL**
**Задание:** Напишите SQL-скрипт для создания 3 основных таблиц из предыдущего задания.

*Если не можете написать SQL - опишите структуру таблиц на естественном языке*

### **Задача 4: SQL DML**
**Задание:** Напишите SQL-запросы:
1. Найти всех спортсменов с разрядом выше второго
2. Посчитать средний результат по каждому виду спорта
3. Найти тренеров, у которых больше 10 подопечных

*Если не можете написать SQL - опишите алгоритм каждого запроса*

### **Задача 5: Оптимизация**
**Задание:**
1. Для каких полей нужно создать индексы? Обоснуйте выбор 3 полей
2. Предложите 2 способа оптимизации производительности БД спортивной секции
