# **Диффиренцируемый зачет по предмету "Основы проектирования баз данных (SQL)"**

Данный документ содержит перечень всех тем, знание которых необходимо для успешной сдачи дифференцируемого зачета. Материалы по темам вы можете найти в конспектах лекций в папке **`lessons`**.
 
### **Глава 1: Основные понятия баз данных**
*   Основные понятия теории БД: данные, информация, СУБД, база данных.
*   Архитектура ANSI/SPARC (уровни: внешний, концептуальный, внутренний).
*   Технологии работы с БД: клиент-серверная архитектура, транзакции, журналирование.

### **Глава 2: Взаимосвязи в моделях и реляционный подход**
*   Логическая и физическая независимость данных: определение и преимущества.
*   Типы моделей данных: иерархическая, сетевая, реляционная, объектно-ориентированная.
*   Реляционная модель данных: основные понятия (отношение, атрибут, кортеж, домен, ключ).
*   Реляционная алгебра: базовые операции (выборка, проекция, объединение, разность, декартово произведение, соединение).

### **Глава 3: Этапы проектирования баз данных**
*   Основные этапы проектирования: концептуальный, логический, физический.
*   Концептуальное проектирование БД: сущности, атрибуты, связи (ER-диаграммы).
*   Нормализация БД:
    *   Цели нормализации и аномалии (вставки, обновления, удаления).
    *   Нормальные формы: 1NF, 2NF, 3NF, BCNF (базовое понимание).

### **Глава 4: Проектирование структур баз данных**
*   Средства проектирования структур БД: CASE-инструменты (например, ERwin, dbdiagram.io).
*   Организация интерфейса с пользователем: представления (VIEW) для безопасности и удобства.

### **Глава 5: Основы языка SQL**
*   Основные понятия языка SQL. Синтаксис операторов, типы данных.
*   Классификация операторов SQL: DDL, DML, DCL, TCL.
*   **DDL (Data Definition Language):**
    *   Создание, модификация и удаление баз данных и таблиц (`CREATE`, `ALTER`, `DROP`).
    *   Определение ограничений целостности (`PRIMARY KEY`, `FOREIGN KEY`, `UNIQUE`, `NOT NULL`, `CHECK`).
*   **DML (Data Manipulation Language):**
    *   Операторы манипулирования данными: `INSERT`, `UPDATE`, `DELETE`.

### **Глава 6: Организация запросов на выборку данных (DQL)**
*   **Базовый оператор `SELECT`:** выборка столбцов, использование `*`, алиасы (`AS`).
*   **Ключевое слово `WHERE`:** фильтрация строк с использованием операторов сравнения и логических операторов (`AND`, `OR`, `NOT`).
*   **Сортировка данных:** оператор `ORDER BY` (сортировка по возрастанию и убыванию).
*   **Группировка данных:**
    *   Операторы `GROUP BY` и агрегатные функции (`COUNT`, `SUM`, `AVG`, `MAX`, `MIN`).
    *   Фильтрация групп с помощью `HAVING` (отличие от `WHERE`).
*   **Соединение таблиц (JOIN):**
    *   Внутреннее соединение (`INNER JOIN`).
    *   Внешние соединения (`LEFT JOIN`, `RIGHT JOIN`, `FULL JOIN`).
    *   Перекрестное соединение (`CROSS JOIN`).
