# **ЗАДАНИЕ 1. Исследование производительности периферийных устройств**

**Задача:**
Определить реальную производительность USB-устройства (флеш-накопителя, внешнего SSD или HDD) с помощью встроенных инструментов Windows и сторонних утилит.

---

## **Часть 1. Практическая**

1. Подключите USB-накопитель.
2. Выполните замер скорости через **Windows 10/11 → Средство проверки дисков (winsat)**:

   * Откройте *Командную строку (CMD)*
   * Выполните команду

     ```
     winsat disk -drive X
     ```
3. Выполните тест в программе **CrystalDiskMark** (если нет — протестировать аналогичным инструментом или онлайн-бенчмарком).
4. Зафиксируйте показатели:

   * Seq Read
   * Seq Write
   * 4K Random Read
   * 4K Random Write

1. **Титульный лист по ГОСТ-стилю**.
2. **Автоматическое оглавление** (Обязательно! Заголовки должны быть стилями Word).
3. **Вставить минимум 5 скриншотов**:

   * диспетчер устройств
   * окно драйверов

   * события Windows
   * параметры монитора

5. **Минимум 1 схема или блок-схема**, выполненная:

   * в Word SmartArt
   * или на Draw.io

7. **Минимум 2 страницы выводов в конце отчёта**:

   * сравнительные заключения
   * рекомендации
