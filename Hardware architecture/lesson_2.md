## **Задания для исследования**

### **Задание 1: Дефрагментация дисков**
**Вопрос:** Какие существуют бесплатные программы для дефрагментации жестких дисков в Windows 10? Сравните их по трем параметрам: скорость работы, дополнительные функции, поддержка SSD.

**Что нужно сделать:**
- Найти минимум 3 бесплатные программы
- Составить сравнительную таблицу
- Объяснить, нужна ли дефрагментация для SSD дисков

### **Задание 2: Проверка диска на ошибки**
**Вопрос:** Как с помощью встроенных средств Windows проверить жесткий диск на ошибки? Опишите пошагово два способа: через графический интерфейс и через командную строку.

**Что нужно найти:**
- Команды для CHKDSK с различными параметрами
- Как интерпретировать результаты проверки
- Какие типы ошибок может обнаружить утилита

### **Задание 3: Мониторинг здоровья диска**
**Вопрос:** Что такое S.M.A.R.T. технология и какие программы могут читать эти данные? Найдите 2 программы с поддержкой русского языка.

**Исследуйте:**
- Что означают основные параметры S.M.A.R.T.
- Какие значения считаются критическими
- Как часто нужно проверять эти параметры

### **Задание 4: Очистка дискового пространства**
**Вопрос:** Какие программы для глубокой очистки системы от временных файлов существуют? Сравните CCleaner с двумя альтернативами.

**Для исследования:**
- Функции очистки в каждой программе
- Безопасность использования
- Дополнительные инструменты

### **Задание 5: Управление разделами диска**
**Вопрос:** Найдите бесплатную альтернативу программе Partition Magic для работы с разделами жесткого диска. Опишите ее основные возможности.

**Что изучить:**
- Создание, удаление, изменение размеров разделов
- Безопасность операций
- Поддержка различных файловых систем

### **Задание 6: Восстановление данных**
**Вопрос:** Какие программы могут восстановить случайно удаленные файлы? Опишите алгоритм действий при случайном удалении важных файлов.

**Исследуйте:**
- Принципы работы программ восстановления
- Что делать сразу после удаления файлов
- Вероятность успешного восстановления

### **Задание 7: Тестирование скорости диска**
**Вопрос:** Какими программами можно измерить реальную скорость чтения/записи жесткого диска? Объясните, какие показатели считаются нормальными для HDD и SSD.

**Что найти:**
- Бесплатные программы для бенчмаркинга
- Как интерпретировать результаты тестов
- Факторы, влияющие на скорость диска

### **Задание 8: Резервное копирование**
**Вопрос:** Какие встроенные средства Windows можно использовать для резервного копирования? Сравните их со сторонними программами.

**Изучите:**
- История файлов
- Образ системы
- Сторонние решения для автоматического бэкапа

### **Задание 9: Работа с оптическими дисками**
**Вопрос:** Какие современные программы для записи CD/DVD/Blu-Ray дисков поддерживают русский язык и распространяются бесплатно?

**Найдите информацию о:**
- Поддерживаемых форматах
- Дополнительных функциях (создание образов, копирование дисков)
- Совместимости с Windows 10/11

### **Задание 10: Комплексное обслуживание**
**Вопрос:** Существуют ли программы, которые объединяют несколько функций обслуживания дисков в одном интерфейсе? Опишите их возможности.

- Набор инструментов в таких программах
