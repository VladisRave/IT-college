# Практическая работа №7. Диагностика и коррекция ошибок операционной системы, контроль доступа к операционной системе 

## Цель работы
Освоить методы диагностики проблем операционной системы Windows и изучить механизмы контроля доступа без внесения изменений в систему.

**Важно!** Все задания выполняются БЕЗ внесения изменений в систему. Только сбор информации и анализ.

---

## Теоретическая часть

### Что такое диагностика ОС?
Это процесс выявления и анализа проблем операционной системы с помощью встроенных инструментов.

### Основные инструменты диагностики в Windows:
- **Журналы событий** - запись всех системных событий
- **Диспетчер задач** - мониторинг процессов и ресурсов
- **Сведения о системе** - полная информация о конфигурации
- **Монитор стабильности** - анализ сбоев системы

### Контроль доступа:
- **Учетные записи пользователей**
- **Права доступа к файлам**
- **Брандмауэр Windows**
- **История входа в систему**

## ПРАКТИЧЕСКАЯ ЧАСТЬ 

## ЗАНЯТИЕ 1: Диагностика ошибок операционной системы

### Задание 1.1: Исследование журналов событий Windows 

**Цель:** Научиться находить и анализировать ошибки системы в журналах событий.

**Шаги выполнения:**

1. **Откройте Просмотр событий:**
   - Нажмите `Win + R`
   - Введите `eventvwr.msc`
   - Нажмите `Enter`

2. **Исследуйте основные журналы:**
   - **Журналы Windows → Система**
   - **Журналы Windows → Приложение**
   - **Журналы Windows → Безопасность**

3. **Задание для отчета:**
   - Найдите 3 последние ошибки в журнале "Система"
   - Запишите их:
     - Дата и время
     - Источник ошибки
     - Код события
     - Описание ошибки

**Пример заполнения:**
| Дата/Время | Источник | Код события | Описание |
|------------|----------|-------------|----------|
| 15.10.2024 10:30 | Service Control Manager | 7031 | Служба "Windows Search" неожиданно завершила работу |

### Задание 1.2: Анализ производительности системы 

**Цель:** Изучить текущую загрузку системных ресурсов.

**Шаги выполнения:**

1. **Откройте Диспетчер задач:**
   - `Ctrl + Shift + Esc`
   - Или `Ctrl + Alt + Delete` → Диспетчер задач

2. **Проанализируйте вкладки:**
   - **Процессы** - какие программы используют больше всего ресурсов
   - **Производительность** - загрузка CPU, памяти, диска, сети
   - **Автозагрузка** - программы, запускающиеся при старте системы

3. **Задание для отчета:**
   - Запишите 3 процесса с наибольшим использованием CPU
   - Запишите общий объем используемой оперативной памяти
   - Определите, какие программы запускаются автоматически

### Задание 1.3: Сбор системной информации 

**Цель:** Получить полную информацию о конфигурации системы.

**Шаги выполнения:**

1. **Откройте Сведения о системе:**
   - `Win + R`
   - Введите `msinfo32`
   - `Enter`

2. **Изучите разделы:**
   - **Аппаратные ресурсы**
   - **Компоненты**
   - **Программная среда**

3. **Задание для отчета:**
   - Запишите:
     - Модель процессора
     - Объем оперативной памяти
     - Версия операционной системы
     - Время последней загрузки системы

### Задание 1.4: Монитор стабильности системы 

**Цель:** Проанализировать историю сбоев системы.

**Шаги выполнения:**

1. **Откройте Монитор стабильности:**
   - Панель управления → Система и безопасность → Центр поддержки
   - Разверните "Обслуживание" → Нажмите "Показать журнал стабильности работы"

2. **Проанализируйте график стабильности:**
   - Отмечаются ли критические события?
   - Есть ли закономерности в сбоях?

3. **Задание для отчета:**
   - Опишите 2 последних критические события (если есть)
   - Оцените общую стабильность системы по 5-балльной шкале

## ЗАНЯТИЕ 2: Контроль доступа к операционной системе

### Задание 2.1: Анализ учетных записей пользователей  

**Цель:** Изучить настройки учетных записей и их привилегии.

**Шаги выполнения:**

1. **Откройте Управление компьютером:**
   - Щелкните правой кнопкой на "Этот компьютер" → Управление
   - Или `Win + R` → `compmgmt.msc`

2. **Изучите разделы:**
   - **Локальные пользователи и группы → Пользователи**
   - **Локальные пользователи и группы → Группы**

3. **Задание для отчета:**
   - Перечислите все учетные записи пользователей
   - Определите, какие учетные записи активны
   - Укажите, к каким группам принадлежит ваша учетная запись

### Задание 2.2: Исследование прав доступа к файлам 

**Цель:** Понять систему разрешений NTFS.

**Шаги выполнения:**

1. **Создайте тестовую папку:**
   - На Рабочем столе создайте папку "Тест_доступ"
   - Щелкните правой кнопкой → Свойства → Безопасность

2. **Изучите вкладку "Безопасность":**
   - Какие пользователи/группы имеют доступ?
   - Какие разрешения у каждой группы?

3. **Задание для отчета:**
   - Опишите права доступа для группы "Пользователи"
   - Какие права есть у вашей учетной записи?
   - Есть ли ограниченный доступ у каких-либо групп?

### Задание 2.3: Анализ настроек Брандмауэра Windows 

**Цель:** Изучить правила сетевой безопасности.

**Шаги выполнения:**

1. **Откройте Брандмауэр Защитника Windows:**
   - Панель управления → Система и безопасность → Брандмауэр Защитника Windows
   - Или `Win + R` → `firewall.cpl`

2. **Изучите настройки:**
   - **Разрешить взаимодействие с приложением...**
   - **Дополнительные параметры** (если доступно)

3. **Задание для отчета:**
   - Запишите, включен ли брандмауэр для частной и общественной сети
   - Перечислите 3 приложения, которым разрешен сетевой доступ
   - Проверьте, включено ли уведомление о блокировке

### Задание 2.4: Аудит событий входа в систему 

**Цель:** Научиться отслеживать события безопасности.

**Шаги выполнения:**

1. **Откройте Просмотр событий:**
   - `eventvwr.msc`
   - Перейдите: **Журналы Windows → Безопасность**

2. **Найдите события входа:**
   - Используйте фильтр: Код события 4624 (успешный вход)
   - Код события 4625 (неудачная попытка входа)

3. **Задание для отчета:**
   - Запишите время последнего успешного входа в систему
   - Были ли неудачные попытки входа?
   - С какого IP-адреса выполнялся вход (если указано)
