## **ПОЯСНЕНИЯ К ЗАДАЧАМ:**

### **Для задач на диаграммы Эйлера-Венна:**
- Рисуем три пересекающихся круга
- Подписываем A, B, C
- Заштриховываем указанную область
- Выписываем элементы, попавшие в заштрихованную область

### **Для задач на мощность:**
Используем формулу включений-исключений:
- |A ∪ B| = |A| + |B| - |A ∩ B|
- |A ∪ B ∪ C| = |A| + |B| + |C| - |A∩B| - |A∩C| - |B∩C| + |A∩B∩C|

### **Для задач на свойства отношений:**
- **Рефлексивность:** все (a,a) ∈ R
- **Симметричность:** если (a,b) ∈ R, то (b,a) ∈ R  
- **Транзитивность:** если (a,b) ∈ R и (b,c) ∈ R, то (a,c) ∈ R

### **Для задач на классы функций:**
- **T0:** f(0,0,...,0) = 0
- **T1:** f(1,1,...,1) = 1
- **S:** f(x) = ¬f(¬x)
- **M:** если x ≤ y, то f(x) ≤ f(y)
- **L:** можно представить линейным многочленом Жегалкина
