## Теоретическая часть

### 1. Понятие отображения

**Отображение** - это правило, которое каждому элементу одного множества (области определения) ставит в соответствие ровно один элемент другого множества (области значений).

**Обозначение:** f: A → B

**Пример:** 
- A = {1, 2, 3}, B = {a, b, c}
- f(1) = a, f(2) = b, f(3) = c

### 2. Виды отображений

#### 2.1. Инъективное отображение (вложение)
Разные элементы переходят в разные:
- Если a₁ ≠ a₂, то f(a₁) ≠ f(a₂)
- Пример: f(x) = 2x на множестве натуральных чисел

#### 2.2. Сюръективное отображение (наложение)
Каждый элемент области значений имеет прообраз:
- Для любого b ∈ B существует a ∈ A: f(a) = b
- Пример: f(x) = x² на множестве неотрицательных чисел

#### 2.3. Биективное отображение (взаимно-однозначное)
Одновременно инъективно и сюръективно:
- Пример: f(x) = x + 1 на множестве целых чисел

### 3. Подстановки (перестановки)

**Подстановка** - это биективное отображение конечного множества на себя.

**Обозначение:**
```
(1 2 3 4)
(3 1 4 2)
```
означает: 1→3, 2→1, 3→4, 4→2

### 4. Циклическая запись подстановок

**Цикл** - подстановка, циклически переставляющая элементы:
- (1 3 2) означает: 1→3, 3→2, 2→1

**Транспозиция** - цикл длины 2, меняющий два элемента местами:
- (1 2) означает: 1→2, 2→1

### 5. Алгебра подстановок

#### 5.1. Умножение подстановок
Умножение = последовательное применение:
- (σ∘τ)(x) = σ(τ(x))

#### 5.2. Обратная подстановка
σ⁻¹ такая, что σ∘σ⁻¹ = ε (тождественная подстановка)

#### 5.3. Тождественная подстановка
ε(x) = x для всех x

### 6. Свойства подстановок

- **Ассоциативность:** (σ∘τ)∘ρ = σ∘(τ∘ρ)
- **Существование единицы:** σ∘ε = ε∘σ = σ
- **Существование обратного:** σ∘σ⁻¹ = σ⁻¹∘σ = ε
