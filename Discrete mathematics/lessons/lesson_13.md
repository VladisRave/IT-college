# **Раздел 4. Элементы теории графов. Основные понятия. Виды графов: ориентированные и неориентированные.**

#### **Введение и основные понятия**

**1. Что такое граф?**
Граф — это математическая модель, которая состоит из двух множеств:
*   Множества **вершин** (узлов, точек). Обозначается: `V` (vertices).
*   Множества **рёбер** (линий, дуг). Обозначается: `E` (edges).
Каждое ребро соединяет две вершины (либо одну и ту же вершину с собой).

**Аналогия из жизни:**
*   **Вершины** — это города.
*   **Рёбра** — это дороги между ними.
Карта автомобильных дорог — наглядный пример неориентированного графа.

**2. Основные термины и обозначения:**
*   **Вершина (узел):** Основной элемент, обычно изображается точкой или кружком.
*   **Ребро:** Линия, соединяющая две вершины. Обозначается парой вершин: `(A, B)`.
*   **Степень вершины (deg(v)):** Количество рёбер, выходящих из данной вершины.
    *   Для вершины `A` на рисунке: `deg(A) = 2`.
    *   **Петля** (ребро из вершины в себя) увеличивает степень вершины на **2**.
*   **Смежные вершины:** Вершины, соединённые ребром.
*   **Инцидентность:** Ребро инцидентно вершине, если оно соединяет эту вершину с другой (или с ней же). Ребро `(A,B)` инцидентно вершинам `A` и `B`.
*   **Путь:** Последовательность вершин, в которой каждая следующая вершина соединена ребром с предыдущей. Пример: `A - B - C - D`.
*   **Цикл:** Путь, начальная и конечная вершины которого совпадают. Пример: `A - B - C - A`.

**Практическое задание на разбор:**

**Задача 1.** Дана схема друзей в социальной сети. Анна (А) дружит с Борисом (Б) и с Дмитрием (Д). Борис дружит с Анной и с Еленой (Е). Дмитрий дружит с Анной и с Еленой. Елена дружит с Борисом, Дмитрием и Фёдором (Ф). Фёдор дружит только с Еленой.

**Решение:**
1.  **Выделяем объекты (вершины):** А, Б, В, Г, Д, Е, Ф? Нет, по условию есть только А, Б, Д, Е, Ф. Вершины: `V = {А, Б, Д, Е, Ф}`.
2.  **Выделяем связи (рёбра):** Дружба — это взаимная связь.
    *   А дружит с Б -> ребро (А, Б).
    *   А дружит с Д -> ребро (А, Д).
    *   Б дружит с Е -> ребро (Б, Е).
    *   Д дружит с Е -> ребро (Д, Е).
    *   Е дружит с Ф -> ребро (Е, Ф).
3.  **Строим граф:**
    ```
        Б ----- Е ----- Ф
         \     /
          \   /
           А-Д
    ```
    *Примечание: вершины можно располагать произвольно, важно сохранить связи.*
4.  **Отвечаем на вопросы:**
    *   **Степень вершины А?** `deg(A) = 2` (связана с Б и Д).
    *   **Степень вершины Ф?** `deg(Ф) = 1` (связан только с Е).
    *   **Смежна ли вершина Б с вершиной Д?** Нет, между ними нет прямого ребра.
    *   **Является ли последовательность (А-Б-Е-Ф) путём?** Да, каждые две соседние вершины соединены ребром. Это путь длины 3.
    *   **Есть ли в графе циклы?** Да, например, (А-Б-Е-Д-А).

#### **Часть 2: Виды графов**

**1. Неориентированный граф (обычный граф):**
*   Ребро не имеет направления. Соединяет вершины на равных.
*   Ребро — это неупорядоченная пара `{A, B}`.
*   **Пример:** Схема знакомств, карта дорог, схема метро (если не учитывать направление движения поездов).

**2. Ориентированный граф (орграф):**
*   Ребро имеет направление и называется **дугой**.
*   Дуга — это упорядоченная пара `(A, B)`, где `A` — начало, `B` — конец дуги. Обозначается стрелкой: `A → B`.
*   **Пример:** Схема односторонних дорог, подчинённость в организации (кто кому отчитывается), блок-схема алгоритма.

**Новые понятия для орграфа:**
*   **Исходящая степень (deg⁺(v)):** Количество дуг, **выходящих** из вершины.
*   **Входящая степень (deg⁻(v)):** Количество дуг, **входящих** в вершину.

**Задача 2.** На острове живут рыцари (которые всегда говорят правду) и лжецы (которые всегда лгут). Каждый житель высказался про другого: "Он рыцарь". Эти высказывания представлены в виде ориентированного графа, где дуга `A → B` означает "A сказал про B, что тот рыцарь".
Дан граф: `A → B, B → C, C → A, C → D, D → C`.
Кто из жителей (A, B, C, D) точно является рыцарем, а кто — лжецом?

**Решение (логический разбор):**
1.  **Анализируем цикл `A → B → C → A`.**
    *   Если A — рыцарь (правдив), то B — рыцарь (т.к. A сказал правду). Тогда C — рыцарь (т.к. B сказал правду). Тогда A — рыцарь (т.к. C сказал правду). Всё сходится.
    *   Если A — лжец (лжёт), то B — лжец (т.к. A солгал). Тогда C — лжец (т.к. B солгал). Тогда A — рыцарь (т.к. C солгал о нём). **Противоречие:** из предположения "A — лжец" получили "A — рыцарь". Значит, это невозможно.
    *   **Вывод:** A, B, C — **рыцари**.
2.  **Анализируем дуги с участием D: `C → D` и `D → C`.**
    *   Мы уже знаем, что C — рыцарь. Значит, его утверждение `C → D` правдиво. Следовательно, D — **рыцарь**.
    *   Проверяем: D (рыцарь) говорит про C (рыцаря), что тот рыцарь. Это правда. Всё согласуется.
3.  **Ответ:** Все четверо (A, B, C, D) — рыцари.

#### **Часть 3: Классификация графов по особенностям структуры**

*   **Полный граф (Kₙ):** Граф, в котором **каждая** вершина соединена ребром с **каждой** другой вершиной.
    *   Число рёбер в полном графе с `n` вершинами: `n(n-1)/2`.
*   **Двудольный граф:** Вершины можно разбить на два непересекающихся множества так, что рёбра соединяют только вершины из *разных* множеств.
    *   **Пример:** Граф "Работники и станки", где рёбра показывают, какой рабочий умеет работать на каком станке.
*   **Взвешенный граф:** Каждому ребру (дуге) присвоено некоторое числовое значение — **вес**.
    *   **Пример:** Граф дорог, где вес — это расстояние или стоимость проезда.
*   **Псевдограф:** Граф, в котором допускаются **петли** (ребра из вершины в себя) и **кратные рёбра** (несколько рёбер между одной парой вершин).
*   **Лес и дерево:**
    *   **Дерево** — это связный граф **без циклов**.
    *   **Лес** — это граф, состоящий из нескольких непересекающихся деревьев (несвязный граф без циклов).

### **Практические задания для самостоятельного решения студентов**

**Задание 1 (Базовое, на построение и анализ неориентированного графа).**
Шесть команд (`A`, `B`, `C`, `D`, `E`, `F`) сыграли турнир по футболу в один круг (каждая сыграла с каждой один раз).
1.  Изобразите граф турнира, где вершины — команды, а ребро — сыгранный матч.
2.  Чему равна степень каждой вершины? Сколько всего ребер в графе?
3.  Команды `A`, `B`, `C` договорились сыграть дополнительный мини-турнир между собой. Добавьте в граф соответствующие рёбра. Как называется полученный подграф для вершин `A, B, C`?
4.  По результатам основного турнира команда `F` дисквалифицирована, и все её результаты аннулированы. Удалите из графа вершину `F` и все связанные с ней рёбра. Останется ли граф полным?

**Задание 2 (Работа с ориентированным графом).**
Дан ориентированный граф, описывающий распространение слухов в компании:
`V = {Анна, Борис, Вика, Григорий, Дарья}`.
Дуги: `Анна → Борис`, `Анна → Вика`, `Борис → Григорий`, `Вика → Григорий`, `Григорий → Дарья`, `Дарья → Вика`.
1.  Изобразите этот орграф.
2.  Для каждой вершины укажите её полустепень исхода (`deg⁺`) и полустепень захода (`deg⁻`).
3.  Анна узнала новость. Кто в итоге её узнает, если каждый передаёт слух только тем, на кого указывает его дуга? Кто никогда её не узнает?
4.  Найдите в графе все циклы (если они есть).

**Задание 3 (Задача на взвешенный граф и двудольность).**
Три курьера (`К1`, `К2`, `К3`) нужно направить на три разных заказа (`З1`, `З2`, `З3`). Каждый курьер может выполнить любой заказ, но время выполнения разное:
*   `К1`: `З1` - 1 ч, `З2` - 4 ч, `З3` - 3 ч.
*   `К2`: `З1` - 2 ч, `З2` - 3 ч, `З3` - 5 ч.
*   `К3`: `З1` - 3 ч, `З2` - 2 ч, `З3` - 4 ч.

1.  Представьте эту ситуацию в виде **взвешенного двудольного графа**. Опишите его множества вершин. Что будут представлять собой рёбра и их веса?
2.  Изобразите этот граф.
3.  *Продвинутый вопрос:* Попробуйте логически рассадить курьеров так, чтобы **суммарное время** было минимальным.
