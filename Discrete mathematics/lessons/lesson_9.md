## 1. Что такое бинарное отношение?

**Простыми словами:** Бинарное отношение - это когда мы можем сказать, связаны ли два элемента между собой или нет.

**Математическое определение:** Бинарное отношение между множествами A и B - это подмножество декартова произведения A × B.

**Пример:**
- A = {Иван, Мария, Петр}
- B = {яблоко, груша, банан}
- Отношение R = "любит фрукт"
- R = {(Иван, яблоко), (Мария, груша), (Петр, банан)}

## 3. Основные свойства отношений

### 3.1 Рефлексивность
**Определение:** ∀a ∈ A: (a,a) ∈ R

**Графически:** У каждой вершины есть петля
```
1 → 1
2 → 2
3 → 3
```

**Пример:** Отношение "≤" на натуральных числах

### 3.2 Симметричность
**Определение:** ∀a,b ∈ A: если (a,b) ∈ R, то (b,a) ∈ R

**Графически:** Все стрелки двусторонние
```
1 ↔ 2
2 ↔ 3
```

**Пример:** Отношение "быть родственником"

### 3.3 Антисимметричность  
**Определение:** ∀a,b ∈ A: если (a,b) ∈ R и (b,a) ∈ R, то a = b

**Графически:** Нет двусторонних стрелок между разными вершинами
```
1 → 2
2 → 3
3 → 1
```

**Пример:** Отношение "≤"

### 3.4 Транзитивность
**Определение:** ∀a,b,c ∈ A: если (a,b) ∈ R и (b,c) ∈ R, то (a,c) ∈ R

**Графически:** Если есть путь a→b→c, то есть и стрелка a→c
```
1 → 2 → 3  ⇒  1 → 3
```

## 4. Операции над отношениями

### 4.1 Объединение отношений
R ∪ S = {(a,b) | (a,b) ∈ R или (a,b) ∈ S}

**Пример:**
```python
R = {(1,2), (2,3)}
S = {(2,3), (3,4)}
R ∪ S = {(1,2), (2,3), (3,4)}
```

### 4.2 Пересечение отношений  
R ∩ S = {(a,b) | (a,b) ∈ R и (a,b) ∈ S}

**Пример:**
```python
R = {(1,2), (2,3), (3,4)}
S = {(2,3), (3,4), (4,5)}
R ∩ S = {(2,3), (3,4)}
```

### 4.3 Композиция отношений
R ∘ S = {(a,c) | ∃b: (a,b) ∈ R и (b,c) ∈ S}

**Пример:**
```python
R = {(1,2), (2,3)}
S = {(2,4), (3,5)}
R ∘ S = {(1,4), (2,5)}
```

### 4.4 Обратное отношение
R⁻¹ = {(b,a) | (a,b) ∈ R}

**Пример:**
```python
R = {(1,2), (2,3), (3,4)}
R⁻¹ = {(2,1), (3,2), (4,3)}
```

## 5. Важные типы отношений

### 5.1 Отношение эквивалентности
- Рефлексивное
- Симметричное  
- Транзитивное

**Пример:** "иметь одинаковый остаток при делении на 3"

### 5.2 Отношение порядка
- Рефлексивное
- Антисимметричное
- Транзитивное

**Пример:** "≤" на множестве чисел

## 6. Разбор задач

### Задача 1
Дано отношение R = {(1,1), (1,2), (2,1), (2,2), (3,3)} на множестве {1,2,3}

**Решение:**
- Рефлексивность: ✅ (есть (1,1), (2,2), (3,3))
- Симметричность: ✅ (есть (1,2) и (2,1))
- Антисимметричность: ❌ (есть (1,2) и (2,1), но 1≠2)
- Транзитивность: ✅ (проверяем все комбинации)

**Вывод:** Отношение эквивалентности

### Задача 2
Дано отношение "делит" на множестве {2,4,6,8}

**Решение:**
R = {(2,2), (2,4), (2,6), (2,8), (4,4), (4,8), (6,6), (8,8)}

- Рефлексивность: ✅
- Симметричность: ❌ (2 делит 4, но 4 не делит 2)
- Антисимметричность: ✅
- Транзитивность: ✅

**Вывод:** Отношение порядка
