# Практическая работа №6. Исследование свойств бинарных отношений. 

## 1. Что такое бинарное отношение?

**Простыми словами:** Бинарное отношение - это связь между элементами двух множеств (или одного множества).

**Примеры из жизни:**
- "x является другом y" - отношение между людьми
- "число a меньше числа b" - отношение между числами
- "город A соединен дорогой с городом B" - отношение между городами

**Математическая запись:** R ⊆ A × B (R - подмножество декартова произведения)

---

## 2. Основные свойства бинарных отношений

### 2.1 Рефлексивность
**Определение:** Каждый элемент связан сам с собой.

**Проще:** "Каждый элемент дружит сам с собой"

**Математика:** ∀a ∈ A: (a,a) ∈ R

**Пример:** Отношение "живет в одном городе с" - рефлексивно (каждый живет в одном городе с самим собой)

**Контрпример:** Отношение "является отцом" - не рефлексивно (никто не является своим отцом)

### 2.2 Симметричность
**Определение:** Если a связано с b, то b связано с a.

**Проще:** "Дружба взаимна"

**Математика:** ∀a,b ∈ A: если (a,b) ∈ R, то (b,a) ∈ R

**Пример:** Отношение "является братом" - симметрично

**Контрпример:** Отношение "любит" - не симметрично (может быть безответная любовь)

### 2.3 Антисимметричность
**Определение:** Если a связано с b и b связано с a, то a = b.

**Проще:** "Не может быть взаимной связи между разными элементами"

**Математика:** ∀a,b ∈ A: если (a,b) ∈ R и (b,a) ∈ R, то a = b

**Пример:** Отношение "≤" на числах - антисимметрично

**Контрпример:** Отношение "дружит с" - не антисимметрично

### 2.4 Транзитивность
**Определение:** Если a связано с b и b связано с c, то a связано с c.

**Проще:** "Друг моего друга - мой друг"

**Математика:** ∀a,b,c ∈ A: если (a,b) ∈ R и (b,c) ∈ R, то (a,c) ∈ R

**Пример:** Отношение "≤" на числах - транзитивно

**Контрпример:** Отношение "нравится" - не транзитивно

---

## 3. Важные типы отношений

### 3.1 Отношение эквивалентности
**Условия:** Рефлексивное + Симметричное + Транзитивное

**Примеры:** 
- "равно" для чисел
- "имеет тот же рост, что и" для людей
- "параллельность" для прямых

### 3.2 Отношение порядка
**Условия:** Рефлексивное + Антисимметричное + Транзитивное

**Примеры:**
- "≤" для чисел
- "является делителем" для натуральных чисел
- "включение ⊆" для множеств

---

## 4. Как исследовать свойства отношений

### Пример 1: R = {(1,1), (2,2), (3,3), (1,2), (2,1)} на множестве {1,2,3}

**Проверяем:**
- **Рефлексивность:** (1,1), (2,2), (3,3) ∈ R ✓
- **Симметричность:** (1,2) ∈ R и (2,1) ∈ R ✓
- **Антисимметричность:** (1,2) ∈ R и (2,1) ∈ R, но 1 ≠ 2 ✗
- **Транзитивность:** (1,2) ∈ R и (2,1) ∈ R ⇒ (1,1) ∈ R ✓

**Вывод:** Отношение эквивалентности

### Пример 2: R = {(1,1), (2,2), (3,3), (1,2), (2,3)} на множестве {1,2,3}

**Проверяем:**
- **Рефлексивность:** ✓
- **Симметричность:** (1,2) ∈ R, но (2,1) ∉ R ✗
- **Антисимметричность:** ✓ (нет пар (a,b) и (b,a) с a≠b)
- **Транзитивность:** (1,2) ∈ R и (2,3) ∈ R ⇒ (1,3) ∉ R ✗

**Вывод:** Отношение порядка

## Памятка для исследования

1. **Рефлексивность:** Проверить все пары (a,a)
2. **Симметричность:** Для каждой пары (a,b) проверить наличие (b,a)
3. **Антисимметричность:** Если есть (a,b) и (b,a), то должно быть a=b
4. **Транзитивность:** Для всех цепочек (a,b) и (b,c) проверить наличие (a,c)

**Совет:** Рисуйте графы отношений - это помогает визуализировать свойства!
