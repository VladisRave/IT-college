# **Интерполирование и экстраполирование функций. Интерполяционный многочлен Лагранжа**

## **1. Введение в проблему интерполяции**

Представьте себе, что вы проводите физический эксперимент и измеряете температуру вещества каждые 10 минут. После нескольких измерений у вас появляется таблица значений:

| Время (мин) | 0  | 10 | 20 | 30 | 40 |
|-------------|----|----|----|----|----|
| Температура (°C) | 15 | 22 | 35 | 48 | 52 |

Возникает естественный вопрос: какова была температура в момент времени 15 минут? Или 25 минут? Или даже 45 минут? Именно такие задачи решает теория интерполяции.

**Интерполяция** — это нахождение промежуточных значений функции по известному дискретному набору её значений. Если же мы хотим найти значение функции за пределами известного интервала (например, при времени 50 минут), то это уже задача **экстраполяции**.

Исторически задача интерполяции возникла в астрономии — нужно было предсказывать положения небесных тел в моменты времени, когда непосредственные наблюдения были невозможны (из-за облачности или времени суток). Сегодня интерполяция используется повсеместно: в компьютерной графике (при масштабировании изображений), в геоинформационных системах (построение карт по точкам измерений), в финансовом анализе (прогнозирование курсов валют), в машинном обучении и многих других областях.

## **2. Постановка задачи интерполяции в математической форме**

Пусть нам известны значения некоторой функции f(x) в n+1 различных точках x₀, x₁, ..., xₙ. Эти точки называются **узлами интерполяции**. Значения функции в этих узлах обозначим как y₀ = f(x₀), y₁ = f(x₁), ..., yₙ = f(xₙ).

**Задача интерполяции** состоит в том, чтобы найти такую функцию F(x), которая:
1. В узлах интерполяции принимает те же значения, что и исходная функция: F(xᵢ) = yᵢ для всех i = 0, 1, ..., n
2. Принадлежит заданному классу функций (многочлены, тригонометрические функции, сплайны и т.д.)

Наиболее распространённый случай — когда в качестве F(x) выбирается **алгебраический многочлен**. Почему именно многочлен? Потому что многочлены легко вычислять, дифференцировать, интегрировать, и, что особенно важно, согласно теореме Вейерштрасса, любую непрерывную функцию на отрезке можно сколь угодно точно приблизить многочленом.

Таким образом, мы приходим к задаче: найти многочлен Pₙ(x) степени не выше n, который в заданных n+1 узлах принимает заданные значения.

Существует важная теорема, которая гарантирует решение этой задачи:

**Теорема о существовании и единственности интерполяционного многочлена:**
Для любых различных узлов x₀, x₁, ..., xₙ и любых значений y₀, y₁, ..., yₙ существует ровно один многочлен Pₙ(x) степени не выше n, такой что Pₙ(xᵢ) = yᵢ для всех i = 0, 1, ..., n.

Доказательство этой теоремы основано на том, что условия Pₙ(xᵢ) = yᵢ образуют систему из n+1 линейных уравнений относительно n+1 коэффициентов многочлена. Определитель этой системы — это определитель Вандермонда, который отличен от нуля при различных xᵢ.

## **3. Интерполяционный многочлен Лагранжа: построение и вывод формулы**

Существует несколько способов построения интерполяционного многочлена. Один из самых элегантных и симметричных способов был предложен Жозефом Луи Лагранжем в 1795 году.

### **3.1. Идея Лагранжа**

Идея Лагранжа гениальна в своей простоте. Давайте построим n+1 вспомогательных многочленов Lᵢ(x), каждый степени n, обладающих следующим свойством:

```
Lᵢ(xⱼ) = 1, если i = j
Lᵢ(xⱼ) = 0, если i ≠ j
```

Графически это означает, что каждый многочлен Lᵢ(x) равен 1 в своём узле xᵢ и 0 во всех остальных узлах.

Если мы построим такие многочлены, то интерполяционный многочлен можно будет записать как линейную комбинацию:

```
Pₙ(x) = y₀·L₀(x) + y₁·L₁(x) + ... + yₙ·Lₙ(x)
```

Действительно, проверим условие интерполяции:

```
Pₙ(xⱼ) = y₀·L₀(xⱼ) + y₁·L₁(xⱼ) + ... + yⱼ·Lⱼ(xⱼ) + ... + yₙ·Lₙ(xⱼ)
```

Все слагаемые, кроме j-го, равны нулю (по свойству Lᵢ(x)), а Lⱼ(xⱼ) = 1, поэтому:

```
Pₙ(xⱼ) = yⱼ·1 = yⱼ
```

Что и требовалось.

### **3.2. Построение базисных многочленов Лагранжа**

Теперь построим многочлены Lᵢ(x). Требование Lᵢ(xⱼ) = 0 при j ≠ i означает, что все точки xⱼ (при j ≠ i) должны быть корнями многочлена Lᵢ(x). Значит, Lᵢ(x) должен содержать множители (x - xⱼ) для всех j ≠ i:

```
Lᵢ(x) = Cᵢ · (x - x₀)·(x - x₁)·...·(x - xᵢ₋₁)·(x - xᵢ₊₁)·...·(x - xₙ)
```

где Cᵢ — некоторая константа, которую мы определим из условия Lᵢ(xᵢ) = 1:

```
Lᵢ(xᵢ) = Cᵢ · (xᵢ - x₀)·(xᵢ - x₁)·...·(xᵢ - xᵢ₋₁)·(xᵢ - xᵢ₊₁)·...·(xᵢ - xₙ) = 1
```

Отсюда находим Cᵢ:

```
Cᵢ = 1 / [(xᵢ - x₀)·(xᵢ - x₁)·...·(xᵢ - xᵢ₋₁)·(xᵢ - xᵢ₊₁)·...·(xᵢ - xₙ)]
```

### **3.3. Формула интерполяционного многочлена Лагранжа**

Объединяя всё вместе, получаем окончательную формулу:

**Интерполяционный многочлен Лагранжа:**

```
         n
Pₙ(x) =  ∑  yᵢ · Lᵢ(x)
        i=0
```

где **базисные многочлены Лагранжа** Lᵢ(x) имеют вид:

```
               n
Lᵢ(x) = ∏ (x - xⱼ) / (xᵢ - xⱼ)
             j=0
             j≠i
```

В развёрнутой форме это выглядит так:

```
       (x - x₀)(x - x₁)...(x - xᵢ₋₁)(x - xᵢ₊₁)...(x - xₙ)
Lᵢ(x) = ——————————————————————————————————————————————————
       (xᵢ - x₀)(xᵢ - x₁)...(xᵢ - xᵢ₋₁)(xᵢ - xᵢ₊₁)...(xᵢ - xₙ)
```

А сам интерполяционный многочлен:

```
                  n       (x - x₀)...(x - xᵢ₋₁)(x - xᵢ₊₁)...(x - xₙ)
Pₙ(x) = y₀·L₀(x) + ... + ∑ yᵢ · ————————————————————————————————————
                 i=0     (xᵢ - x₀)...(xᵢ - xᵢ₋₁)(xᵢ - xᵢ₊₁)...(xᵢ - xₙ)
```

### **3.4. Особенности и свойства многочлена Лагранжа**

1. **Симметричность:** Формула Лагранжа симметрична относительно всех узлов и значений функции.

2. **Линейность по yᵢ:** Если мы меняем одно значение yᵢ, то меняется только одно слагаемое в сумме.

3. **Вычислительная сложность:** Для вычисления значения многочлена в точке x требуется O(n²) операций. Это делает формулу Лагранжа не самой эффективной при большом количестве узлов.

4. **Численная устойчивость:** При большом количестве узлов и определённых их расположениях вычисления по формуле Лагранжа могут стать неустойчивыми из-за ошибок округления.

## **4. Разобранные примеры**

### **Пример 1: Построение многочлена Лагранжа для двух точек (линейная интерполяция)**

**Задача:** Построить интерполяционный многочлен Лагранжа для функции, заданной таблицей:

| x | 1 | 3 |
|---|---|---|
| y | 4 | 2 |

**Решение:**

У нас два узла: x₀ = 1, x₁ = 3, и соответствующие значения: y₀ = 4, y₁ = 2.

Строим базисные многочлены:

1. Для i = 0:
   ```
          (x - x₁)   (x - 3)
   L₀(x) = ———————— = ———————
          (x₀ - x₁)   (1 - 3)
   
   L₀(x) = (x - 3) / (-2) = (3 - x)/2
   ```

2. Для i = 1:
   ```
          (x - x₀)   (x - 1)
   L₁(x) = ———————— = ———————
          (x₁ - x₀)   (3 - 1)
   
   L₁(x) = (x - 1) / 2
   ```

Интерполяционный многочлен:

```
P₁(x) = y₀·L₀(x) + y₁·L₁(x) = 4·(3 - x)/2 + 2·(x - 1)/2
```

Упрощаем:

```
P₁(x) = 2(3 - x) + (x - 1) = 6 - 2x + x - 1 = -x + 5
```

**Ответ:** P₁(x) = 5 - x

**Проверка:** 
- При x = 1: P₁(1) = 5 - 1 = 4 (совпадает с y₀)
- При x = 3: P₁(3) = 5 - 3 = 2 (совпадает с y₁)

### **Пример 2: Построение многочлена Лагранжа для трёх точек (квадратичная интерполяция)**

**Задача:** Построить интерполяционный многочлен Лагранжа для функции, заданной таблицей:

| x | -1 | 0 | 2 |
|---|---|---|---|
| y | 4  | 1 | 5 |

**Решение:**

У нас три узла: x₀ = -1, x₁ = 0, x₂ = 2, и значения: y₀ = 4, y₁ = 1, y₂ = 5.

Строим базисные многочлены:

1. L₀(x):
   ```
          (x - x₁)(x - x₂)   (x - 0)(x - 2)     x(x - 2)
   L₀(x) = ————————————————— = ——————————————— = —————————
          (x₀ - x₁)(x₀ - x₂)   (-1 - 0)(-1 - 2)   (-1)·(-3)
   
   L₀(x) = x(x - 2) / 3
   ```

2. L₁(x):
   ```
          (x - x₀)(x - x₂)   (x + 1)(x - 2)   (x + 1)(x - 2)
   L₁(x) = ————————————————— = ——————————————— = —————————————
          (x₁ - x₀)(x₁ - x₂)   (0 + 1)(0 - 2)     1·(-2)
   
   L₁(x) = -(x + 1)(x - 2) / 2
   ```

3. L₂(x):
   ```
          (x - x₀)(x - x₁)   (x + 1)(x - 0)   x(x + 1)
   L₂(x) = ————————————————— = ——————————————— = —————————
          (x₂ - x₀)(x₂ - x₁)   (2 + 1)(2 - 0)     3·2
   
   L₂(x) = x(x + 1) / 6
   ```

Интерполяционный многочлен:

```
P₂(x) = y₀·L₀(x) + y₁·L₁(x) + y₂·L₂(x)
      = 4·[x(x - 2)/3] + 1·[-(x + 1)(x - 2)/2] + 5·[x(x + 1)/6]
```

Упрощаем:

```
P₂(x) = (4/3)x(x - 2) - (1/2)(x + 1)(x - 2) + (5/6)x(x + 1)
```

Приведём к общему знаменателю 6:

```
P₂(x) = (8/6)x(x - 2) - (3/6)(x + 1)(x - 2) + (5/6)x(x + 1)
      = [8x(x - 2) - 3(x + 1)(x - 2) + 5x(x + 1)] / 6
```

Раскроем скобки:

1. 8x(x - 2) = 8x² - 16x
2. -3(x + 1)(x - 2) = -3(x² - 2x + x - 2) = -3(x² - x - 2) = -3x² + 3x + 6
3. 5x(x + 1) = 5x² + 5x

Суммируем:

```
8x² - 16x - 3x² + 3x + 6 + 5x² + 5x = (8x² - 3x² + 5x²) + (-16x + 3x + 5x) + 6
                                     = 10x² - 8x + 6
```

Таким образом:

```
P₂(x) = (10x² - 8x + 6) / 6 = (5x² - 4x + 3) / 3
```

**Ответ:** P₂(x) = (5x² - 4x + 3)/3

**Проверка:**
- При x = -1: P₂(-1) = (5·1 + 4 + 3)/3 = (5+4+3)/3 = 12/3 = 4 (совпадает)
- При x = 0: P₂(0) = (0 - 0 + 3)/3 = 1 (совпадает)
- При x = 2: P₂(2) = (5·4 - 8 + 3)/3 = (20-8+3)/3 = 15/3 = 5 (совпадает)

## **5. Погрешность интерполяции**

Когда мы заменяем неизвестную функцию f(x) интерполяционным многочленом Pₙ(x), возникает ошибка:

```
Rₙ(x) = f(x) - Pₙ(x)
```

Эта ошибка называется **остаточным членом интерполяции** или **погрешностью интерполяции**.

Для функции f(x), имеющей непрерывную производную (n+1)-го порядка на отрезке [a, b], содержащем узлы интерполяции x₀, x₁, ..., xₙ, справедлива формула:

```
              f⁽ⁿ⁺¹⁾(ξ)
Rₙ(x) = —————————————————— · ωₙ(x)
             (n+1)!
```

где:
- f⁽ⁿ⁺¹⁾(ξ) — (n+1)-я производная функции f в некоторой точке ξ, лежащей между минимальным и максимальным из чисел x, x₀, x₁, ..., xₙ
- ωₙ(x) = (x - x₀)(x - x₁)·...·(x - xₙ) — так называемый «многочлен узлов»

**Важные следствия из этой формулы:**

1. Если x совпадает с одним из узлов, то ωₙ(x) = 0, и погрешность равна нулю (как и должно быть по определению интерполяции).

2. Погрешность зависит от:
   - Производной функции f (чем «гладче» функция, тем меньше погрешность)
   - Расположения узлов интерполяции
   - Расстояния от точки x до узлов интерполяции

3. При экстраполяции (когда x лежит за пределами отрезка, содержащего узлы) величина ωₙ(x) быстро растёт, поэтому погрешность экстраполяции обычно значительно больше погрешности интерполяции.

## **6. Практические рекомендации**

1. **Выбор количества узлов:** С увеличением количества узлов степень многочлена растёт, но это не всегда приводит к повышению точности. Для некоторых функций (особенно с резкими изменениями) многочлены высоких степеней могут сильно колебаться между узлами (явление Рунге).

2. **Выбор расположения узлов:** Для уменьшения погрешности интерполяции на отрезке [a, b] часто используют чебышёвские узлы:
   ```
   xᵢ = (a + b)/2 + ((b - a)/2)·cos((2i + 1)π/(2n + 2)), i = 0, 1, ..., n
   ```
   которые минимизируют максимальное значение |ωₙ(x)| на отрезке.

3. **Экстраполяция:** Будьте осторожны при экстраполяции! Предсказание значений за пределами известного интервала часто ненадёжно, особенно для сложных процессов.

## **8. Применение в вычислительной практике**

В реальных вычислениях формула Лагранжа редко используется в явном виде из-за её вычислительной неэффективности при большом количестве узлов. Однако она имеет важное теоретическое значение и часто используется:

1. **В численных методах** для вывода других формул (например, формул численного дифференцирования и интегрирования).

2. **В компьютерной графике** для плавного проведения кривых через заданные точки.

3. **В криптографии** в схемах разделения секрета Шамира.

4. **В финансовой математике** для определения недостающих значений временных рядов.

Для практических вычислений с большим количеством узлов чаще используются:
- **Конечные разности** и интерполяционные формулы Ньютона
- **Кубические сплайны** (кусочно-полиномиальная интерполяция)
- **Метод наименьших квадратов** (если данные содержат ошибки измерений)

## **Заключение**

Интерполяционный многочлен Лагранжа представляет собой элегантное и симметричное решение задачи интерполяции. Несмотря на свои вычислительные недостатки при большом количестве узлов, он остаётся важным инструментом в теории аппроксимации и служит основой для понимания более сложных методов интерполяции.

Ключевые моменты, которые нужно запомнить:
1. Интерполяция — нахождение значений между известными точками, экстраполяция — за пределами известного интервала.
2. Интерполяционный многочлен Лагранжа степени n проходит через n+1 заданную точку.
3. Формула Лагранжа симметрична и линейна относительно значений функции в узлах.
4. Погрешность интерполяции зависит от производных функции и расположения узлов.
5. Экстраполяция, как правило, менее точна, чем интерполяция.
