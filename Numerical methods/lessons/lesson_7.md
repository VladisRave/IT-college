# Практическая работа №6. Решение систем методом Гаусса. Вычисление определителя

## Теоретическая часть

### 1. Введение в метод Гаусса

**Метод Гаусса** - это последовательное исключение неизвестных из системы линейных уравнений для приведения ее к треугольному виду.

**Общий вид системы из n уравнений с n неизвестными:**
```
a₁₁x₁ + a₁₂x₂ + ... + a₁ₙxₙ = b₁
a₂₁x₁ + a₂₂x₂ + ... + a₂ₙxₙ = b₂
...
aₙ₁x₁ + aₙ₂x₂ + ... + aₙₙxₙ = bₙ
```

### 2. Матричная форма системы

Систему можно записать в матричной форме:
```
AX = B
```
где:
- A - матрица коэффициентов размера n×n
- X - столбец неизвестных
- B - столбец свободных членов

**Расширенная матрица системы:**
```
[ a₁₁  a₁₂  ...  a₁ₙ | b₁ ]
[ a₂₁  a₂₂  ...  a₂ₙ | b₂ ]
[ ...  ...  ...  ... | ... ]
[ aₙ₁  aₙ₂  ...  aₙₙ | bₙ ]
```

### 3. Элементарные преобразования строк

**Разрешенные преобразования:**
1. Перестановка двух строк
2. Умножение строки на число, отличное от нуля
3. Прибавление к одной строке другой, умноженной на число

### 4. Прямой ход метода Гаусса

**Цель:** Привести расширенную матрицу к ступенчатому виду

**Алгоритм:**
1. Выбираем ведущий элемент в первом столбце
2. Обнуляем элементы под ведущим элементом
3. Переходим к следующему столбцу
4. Повторяем до получения треугольной матрицы

### 5. Обратный ход метода Гаусса

**Цель:** Найти значения неизвестных

**Алгоритм:**
1. Начинаем с последнего уравнения
2. Выражаем последнюю неизвестную
3. Подставляем в предыдущие уравнения
4. Повторяем для всех неизвестных

### 6. Вычисление определителя

**Определитель матрицы** - это числовая характеристика квадратной матрицы

**Свойства определителя:**
1. При перестановке строк определитель меняет знак
2. При умножении строки на k определитель умножается на k
3. Определитель не меняется при элементарных преобразованиях 3-го типа

**Вычисление методом Гаусса:**
1. Приводим матрицу к треугольному виду
2. Определитель равен произведению элементов главной диагонали
3. Учитываем коэффициент, равный (-1)^k, где k - количество перестановок строк

## Подробный разбор примеров

### Пример 1: Решение системы методом Гаусса

**Решить систему:**
```
2x + y - z = 8
-3x - y + 2z = -11
-2x + y + 2z = -3
```

**Шаг 1: Составляем расширенную матрицу**
```
[ 2   1  -1 |  8 ]
[-3  -1   2 | -11]
[-2   1   2 | -3 ]
```

**Шаг 2: Прямой ход**

1. Первую строку делим на 2:
```
[ 1   0.5  -0.5 |  4 ]
[-3   -1     2   | -11]
[-2    1     2   | -3 ]
```

2. Ко второй строке прибавляем первую, умноженную на 3:
```
[ 1   0.5  -0.5 |  4 ]
[ 0   0.5   0.5 |  1 ]
[-2    1     2   | -3 ]
```

3. К третьей строке прибавляем первую, умноженную на 2:
```
[ 1   0.5  -0.5 |  4 ]
[ 0   0.5   0.5 |  1 ]
[ 0   2     1   |  5 ]
```

4. Вторую строку умножаем на 2:
```
[ 1   0.5  -0.5 |  4 ]
[ 0   1     1   |  2 ]
[ 0   2     1   |  5 ]
```

5. Из третьей строки вычитаем вторую, умноженную на 2:
```
[ 1   0.5  -0.5 |  4 ]
[ 0   1     1   |  2 ]
[ 0   0    -1   |  1 ]
```

**Шаг 3: Обратный ход**

Из третьего уравнения: -z = 1 ⇒ z = -1

Из второго уравнения: y + z = 2 ⇒ y - 1 = 2 ⇒ y = 3

Из первого уравнения: x + 0.5y - 0.5z = 4 ⇒ x + 1.5 + 0.5 = 4 ⇒ x = 2

**Ответ:** x = 2, y = 3, z = -1

### Пример 2: Вычисление определителя

**Вычислить определитель:**
```
| 2  1 -1 |
|-3 -1  2 |
|-2  1  2 |
```

**Шаг 1: Приводим к треугольному виду**

1. К второй строке прибавляем первую, умноженную на 1.5:
```
| 2  1   -1 |
| 0  0.5  0.5 |
|-2  1    2 |
```

2. К третьей строке прибавляем первую:
```
| 2  1   -1 |
| 0  0.5  0.5 |
| 0  2    1 |
```

3. Из третьей строки вычитаем вторую, умноженную на 4:
```
| 2  1   -1 |
| 0  0.5  0.5 |
| 0  0   -1 |
```

**Шаг 2: Вычисляем определитель**

Определитель треугольной матрицы = произведению диагональных элементов:
det = 2 × 0.5 × (-1) = -1

## Подробные решения заданий

### Решение Задания 1:

**Расширенная матрица:**
```
[ 1  2  3 | 1 ]
[ 3  2  1 | 1 ]
[ 2  3  1 | 1 ]
```

**Прямой ход:**
1. R₂ = R₂ - 3R₁:
```
[ 1  2   3 | 1 ]
[ 0 -4  -8 | -2 ]
[ 2  3   1 | 1 ]
```

2. R₃ = R₃ - 2R₁:
```
[ 1  2   3 | 1 ]
[ 0 -4  -8 | -2 ]
[ 0 -1  -5 | -1 ]
```

3. R₂ = R₂ / (-4):
```
[ 1  2   3 | 1 ]
[ 0  1   2 | 0.5 ]
[ 0 -1  -5 | -1 ]
```

4. R₃ = R₃ + R₂:
```
[ 1  2   3 | 1 ]
[ 0  1   2 | 0.5 ]
[ 0  0  -3 | -0.5 ]
```

**Обратный ход:**
Из R₃: -3z = -0.5 ⇒ z = 1/6

Из R₂: y + 2z = 0.5 ⇒ y + 1/3 = 0.5 ⇒ y = 1/6

Из R₁: x + 2y + 3z = 1 ⇒ x + 1/3 + 0.5 = 1 ⇒ x = 1/6

**Ответ:** x = 1/6, y = 1/6, z = 1/6

### Решение Задания 3:

**Исходная матрица:**
```
| 1  2  3  4 |
| 2  3  4  1 |
| 3  4  1  2 |
| 4  1  2  3 |
```

**Приводим к треугольному виду:**
1. R₂ = R₂ - 2R₁, R₃ = R₃ - 3R₁, R₄ = R₄ - 4R₁:
```
| 1  2    3    4 |
| 0 -1   -2   -7 |
| 0 -2   -8  -10 |
| 0 -7  -10  -13 |
```

2. R₃ = R₃ - 2R₂, R₄ = R₄ - 7R₂:
```
| 1  2    3    4 |
| 0 -1   -2   -7 |
| 0  0   -4    4 |
| 0  0    4   36 |
```

3. R₄ = R₄ + R₃:
```
| 1  2    3    4 |
| 0 -1   -2   -7 |
| 0  0   -4    4 |
| 0  0    0   40 |
```

**Определитель:** 1 × (-1) × (-4) × 40 = 160
