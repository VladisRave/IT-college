# Практическая работа №4
## Решение систем линейных уравнений приближёнными методами

**Цель работы:** освоить методы простой итерации и Зейделя для решения систем линейных уравнений.

**Время выполнения:** 1 час 15 минут

---

### Теоретическая справка

**Метод простой итерации:**
- Система Ax = b приводится к виду x = Cx + d
- Итерационная формула: x⁽ᵏ⁺¹⁾ = Cx⁽ᵏ⁾ + d
- Условие сходимости: ‖C‖ < 1

**Метод Зейделя:**
- Использует уже вычисленные компоненты на текущей итерации
- Более быстрая сходимость по сравнению с методом простой итерации

---

### Образец решения (для Задачи 1):

1. **Приводим к виду x = Cx + d:**
   ```
   x₁ = 0.5 - 0.25x₂
   x₂ = 0.333 - 0.333x₁
   ```

2. **Начальное приближение:** x⁽⁰⁾ = (0, 0)

3. **Первая итерация:**
   ```
   x₁⁽¹⁾ = 0.5 - 0.25·0 = 0.5
   x₂⁽¹⁾ = 0.333 - 0.333·0.5 = 0.167
   ```

4. **Вторая итерация:**
   ```
   x₁⁽²⁾ = 0.5 - 0.25·0.167 = 0.458
   x₂⁽²⁾ = 0.333 - 0.333·0.458 = 0.181
   ```
