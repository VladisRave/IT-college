# Метод Зейделя для решения систем линейных уравнений

## Теоретическая часть

### Что такое метод Зейделя?

**Метод Зейделя** - это итерационный метод решения систем линейных алгебраических уравнений. Он похож на метод Якоби, но имеет важное отличие: при вычислении очередного неизвестного используются уже вычисленные на этой же итерации значения других неизвестных.

### Основная идея

Представьте, что вы решаете головоломку: чтобы найти ответ, вы используете не только старые предположения, но и уже найденные новые подсказки. Метод Зейделя работает именно так!

---

## Алгоритм решения

### Шаг 1: Проверка условия сходимости

**Условие диагонального преобладания:**
Для каждого уравнения модуль диагонального коэффициента должен быть больше суммы модулей остальных коэффициентов:

```
|a₁₁| > |a₁₂| + |a₁₃| + ... + |a₁ₙ|
|a₂₂| > |a₂₁| + |a₂₃| + ... + |a₂ₙ|
...
|aₙₙ| > |aₙ₁| + |aₙ₂| + ... + |aₙₙ₋₁|
```

### Шаг 2: Преобразование системы

Исходная система:
```
a₁₁x₁ + a₁₂x₂ + ... + a₁ₙxₙ = b₁
a₂₁x₁ + a₂₂x₂ + ... + a₂ₙxₙ = b₂
...
aₙ₁x₁ + aₙ₂x₂ + ... + aₙₙxₙ = bₙ
```

Преобразованная система (выражаем каждую переменную):
```
x₁ = (b₁ - a₁₂x₂ - a₁₃x₃ - ... - a₁ₙxₙ) / a₁₁
x₂ = (b₂ - a₂₁x₁ - a₂₃x₃ - ... - a₂ₙxₙ) / a₂₂
...
xₙ = (bₙ - aₙ₁x₁ - aₙ₂x₂ - ... - aₙₙ₋₁xₙ₋₁) / aₙₙ
```

### Шаг 3: Выбор начального приближения

Обычно берут нулевое приближение:
```
x₁⁽⁰⁾ = 0, x₂⁽⁰⁾ = 0, ..., xₙ⁽⁰⁾ = 0
```

### Шаг 4: Итерационный процесс

**Ключевое отличие от метода Якоби:** используем УЖЕ вычисленные на текущей итерации значения!

Для (k+1)-й итерации:
```
x₁⁽ᵏ⁺¹⁾ = (b₁ - a₁₂x₂⁽ᵏ⁾ - a₁₃x₃⁽ᵏ⁾ - ... - a₁ₙxₙ⁽ᵏ⁾) / a₁₁
x₂⁽ᵏ⁺¹⁾ = (b₂ - a₂₁x₁⁽ᵏ⁺¹⁾ - a₂₃x₃⁽ᵏ⁾ - ... - a₂ₙxₙ⁽ᵏ⁾) / a₂₂
x₃⁽ᵏ⁺¹⁾ = (b₃ - a₃₁x₁⁽ᵏ⁺¹⁾ - a₃₂x₂⁽ᵏ⁺¹⁾ - ... - a₃ₙxₙ⁽ᵏ⁾) / a₃₃
...
```

### Шаг 5: Критерий остановки

Итерации продолжаем до тех пор, пока максимальное изменение не станет меньше заданной точности ε:

```
max| xᵢ⁽ᵏ⁺¹⁾ - xᵢ⁽ᵏ⁾ | < ε
```

## Пример решения

### Решим систему:
```
4x₁ + x₂ = 5
x₁ + 3x₂ = 6
```
С точностью ε = 0.01

### Шаг 1: Проверка сходимости
- Для 1-го уравнения: |4| > |1| ✓
- Для 2-го уравнения: |3| > |1| ✓
**Вывод:** метод сходится

### Шаг 2: Преобразуем систему
```
x₁ = (5 - x₂) / 4
x₂ = (6 - x₁) / 3
```

### Шаг 3: Начальное приближение
```
x₁⁽⁰⁾ = 0, x₂⁽⁰⁾ = 0
```

### Шаг 4: Итерационный процесс

**Итерация 1:**
```
x₁⁽¹⁾ = (5 - x₂⁽⁰⁾) / 4 = (5 - 0) / 4 = 1.25
x₂⁽¹⁾ = (6 - x₁⁽¹⁾) / 3 = (6 - 1.25) / 3 = 1.5833
```

**Итерация 2:**
```
x₁⁽²⁾ = (5 - x₂⁽¹⁾) / 4 = (5 - 1.5833) / 4 = 0.8542
x₂⁽²⁾ = (6 - x₁⁽²⁾) / 3 = (6 - 0.8542) / 3 = 1.7153
```

**Итерация 3:**
```
x₁⁽³⁾ = (5 - x₂⁽²⁾) / 4 = (5 - 1.7153) / 4 = 0.8212
x₂⁽³⁾ = (6 - x₁⁽³⁾) / 3 = (6 - 0.8212) / 3 = 1.7263
```

**Итерация 4:**
```
x₁⁽⁴⁾ = (5 - x₂⁽³⁾) / 4 = (5 - 1.7263) / 4 = 0.8184
x₂⁽⁴⁾ = (6 - x₁⁽⁴⁾) / 3 = (6 - 0.8184) / 3 = 1.7272
```

### Шаг 5: Проверка точности
После 4-й итерации:
- |x₁⁽⁴⁾ - x₁⁽³⁾| = |0.8184 - 0.8212| = 0.0028 < 0.01
- |x₂⁽⁴⁾ - x₂⁽³⁾| = |1.7272 - 1.7263| = 0.0009 < 0.01

**Точность достигнута!**

### Ответ:
```
x₁ ≈ 0.818, x₂ ≈ 1.727
```

## Задачи для самостоятельного решения

### Задача 1 (простая)
Решить систему с точностью ε = 0.001:
```
5x₁ + 2x₂ = 9
3x₁ + 7x₂ = 8
```

**Подсказка:** Проверьте диагональное преобладание и выразите:
```
x₁ = (9 - 2x₂)/5
x₂ = (8 - 3x₁)/7
```

### Задача 2 (средней сложности)
Решить систему с точностью ε = 0.0001:
```
4x₁ - x₂ + x₃ = 4
x₁ + 6x₂ - 2x₃ = 9
-2x₁ + x₂ + 5x₃ = 2
```

### Задача 3 (трехмерная система)
Решить систему с точностью ε = 0.001:
```
10x₁ + x₂ - x₃ = 10
x₁ + 10x₂ + x₃ = 12
-x₁ + x₂ + 10x₃ = 11
```

### Задача 4 (практическая)
Решить систему с точностью ε = 0.0001:
```
3x₁ + 0.1x₂ + 0.2x₃ = 7.85
0.1x₁ + 7x₂ - 0.3x₃ = -19.3
0.3x₁ - 0.2x₂ + 10x₃ = 71.4
```

### Задача 5 (проверка сходимости)
Исследовать сходимость и решить систему с точностью ε = 0.001:
```
8x₁ + 3x₂ - 2x₃ = 10
x₁ - 5x₂ + 2x₃ = -3
2x₁ + 3x₂ + 8x₃ = 25
```

## ОСНОВНЫЕ ВЫВОДЫ

1. **Метод Зейделя** сходится быстрее метода Якоби
2. **Обязательно проверяйте** условие диагонального преобладания
3. **Используйте уже вычисленные значения** на текущей итерации
4. **Контролируйте точность** после каждой итерации
5. **Ведите аккуратные записи** - это помогает избежать ошибок
