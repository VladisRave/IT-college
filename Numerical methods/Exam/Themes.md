# **Диффиренцируемый зачет по предмету "Численные методы"**

Данный документ содержит перечень всех тем, знание которых необходимо для успешной сдачи дифференцируемого зачета. Материалы по темам вы можете найти в конспектах лекций в папке **`lessons`**.

### **Глава 1: Элементы теории погрешностей**
*   Источники и классификация погрешностей результата численного решения задачи (неустранимые, методические, вычислительные, абсолютная и относительная погрешности).
*   Вычисление погрешностей результатов арифметических действий над приближёнными числами (сложение, вычитание, умножение, деление).

### **Глава 2: Решение алгебраических и трансцендентных уравнений**
*   Постановка задачи локализации корней. Отделение корней.
*   Численные методы решения уравнений:
    *   Метод половинного деления (бисекции).
    *   Метод простой итерации (условия сходимости).
    *   Метод Ньютона (касательных).
    *   Метод хорд (секущих).
*   Сравнение методов по скорости сходимости и сложности реализации.

### **Глава 3: Решение систем линейных алгебраических уравнений (СЛАУ)**
*   Точные методы: Метод Гаусса (прямой ход, обратная подстановка). Вычисление определителя в процессе решения.
*   Приближенные итерационные методы:
    *   Метод простой итерации (приведение к виду x = Bx + c).
    *   Метод Зейделя (модификация метода итераций).
    *   Условия сходимости итерационных методов.

### **Глава 4: Интерполирование и аппроксимация функций**
*   Постановка задачи интерполяции. Интерполяционный многочлен Лагранжа.
*   Интерполяционные формулы Ньютона (для равноотстоящих узлов).
*   Интерполирование сплайнами (понятие кубического сплайна, граничные условия).

### **Глава 5: Численное интегрирование (квадратура)**
*   Квадратурные формулы Ньютона-Котеса:
    *   Формулы прямоугольников (левых, правых, средних).
    *   Формула трапеций.
    *   Формула Симпсона (парабол).
*   Оценка погрешности формул численного интегрирования.

### **Глава 6: Численное решение обыкновенных дифференциальных уравнений (ОДУ)**
*   Постановка задачи Коши для ОДУ первого порядка.
*   Метод Эйлера (ломаных Эйлера).
*   Уточнённые методы (модифицированный метод Эйлера, метод Эйлера-Коши).
*   Метод Рунге-Кутта. Понятие о шаге и точности метода.
