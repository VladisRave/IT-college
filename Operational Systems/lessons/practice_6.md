# **Практическая работа №6**

## **Работа с программой «Файл-менеджер Проводник». Работа с файловыми системами и дисками**

### **Цель работы**

Научиться эффективно работать с файловым менеджером **Проводник Windows**, организовывать данные на компьютере, понимать различия файловых систем, выполнять операции с файлами и папками, а также использовать базовые инструменты управления дисками.

### **Задачи работы**

Студент должен уметь:

* находить, копировать, перемещать и удалять файлы и папки;
* создавать структуру каталогов и настраивать отображение элементов в Проводнике;
* работать с внешними накопителями;
* понимать различия файловых систем (NTFS, FAT32, exFAT);
* выполнять простейшие операции через «Управление дисками».

### **Оборудование**

* Персональный компьютер с Windows
* Подключение к интернету (разрешается использовать Google для поиска информации)
* Программа **Microsoft Word** для оформления отчёта
* Внешняя флешка (по возможности)

---

# **Ход выполнения работы**

## **Задание 1. Исследование интерфейса Проводника**

1. Откройте **Проводник Windows**.
2. Изучите элементы окна: панель навигации, адресную строку, область содержимого, ленту инструментов.
3. Переключите способы отображения файлов (значки, список, таблица, плитки).
4. Создайте в документе Word краткое описание каждого элемента интерфейса (2–4 предложения для каждого).

**Что вставить в отчёт:**

* Скриншот окна Проводника
* Подписи и краткое описание основных элементов интерфейса

---

## **Задание 2. Создание структуры папок и работа с файлами**

1. На диске **D:** создайте папку **Практика_6_ФИО**.
2. Внутри неё создайте папки:

   * **Документы**
   * **Изображения**
   * **Архивы**
3. Скачайте из интернета любой текстовый файл, картинку и небольшой архив (например, .zip).
4. Поместите каждый файл в соответствующую папку.
5. Скопируйте папку **Документы** на рабочий стол.
6. Переименуйте папку **Изображения** в **Картинки**.

**Что вставить в отчёт:**

* Скриншоты структуры папок
* Подробное описание выполненных действий

---

## **Задание 3. Поиск и сортировка файлов**

1. Используя строку поиска в Проводнике, найдите на компьютере файлы формата *.txt*.
2. Отсортируйте найденные файлы по размеру, затем по дате изменения.
3. Откройте свойства любого найденного файла и изучите параметры: местоположение, размер, дата изменения, атрибуты.

**Что вставить в отчёт:**

* Скриншот окна поиска
* Список атрибутов выбранного файла (переписать вручную)

---

## **Задание 4. Файловые системы и работа с флеш-накопителем**

1. Подключите флешку к компьютеру.
2. Откройте её свойства и определите файловую систему (NTFS/FAT32/exFAT).
3. Найдите информацию в интернете:

   * чем отличаются NTFS, FAT32 и exFAT;
   * какая система лучше подходит для флешек;
   * почему некоторые файлы большого размера нельзя записать на FAT32.
4. Создайте в Word небольшую таблицу сравнения файловых систем (3–5 характеристик).

**Что вставить в отчёт:**

* Скриншот свойств флешки
* Таблица «Сравнение файловых систем»
* Краткие выводы (3–4 предложения)

---

## **Задание 5. Управление дисками**

1. Откройте инструмент **Управление дисками**:
   *Пуск → Панель управления → Администрирование → Управление компьютером → Управление дисками*.
2. Найдите свои диски: системный диск, логический диск, флешку.
3. Определите:

   * объём каждого диска;
   * свободное место;
   * тип тома (основной/логический);
   * состояние диска.
4. Сделайте скриншот окна «Управление дисками».

**Что вставить в отчёт:**

* Скриншот окна
* Подробнрое описание всех обнаруженных дисков

---

# **Форма отчёта в Word**

Отчёт должен содержать:

1. **Титульный лист** (название колледжа, дисциплина, ФИО, группа, номер работы).
2. **Цель и задачи практической работы**.
3. Отчёт по каждому из пяти заданий:

   * скриншоты;
   * краткие пояснения;
   * таблица сравнения файловых систем;
   * выводы.
4. **Общий вывод** — что студент узнал и чему научился.
