## Теоретическая справка

### Что такое процесс?
**Процесс** — это экземпляр программы, которая выполняется в операционной системе. Каждый процесс имеет:
- Уникальный идентификатор (PID)
- Выделенную область памяти
- Приоритет выполнения
- Состояние (выполняется, ожидает, завершен)

## Примеры выполнения

### Пример для Задания 1 (Windows):
```
Команда: tasklist
Назначение: Отображение списка запущенных процессов
Основные параметры:
  /FI "фильтр" - фильтрация по условию
  /FO table|list|csv - формат вывода
  /V - подробная информация
Пример: tasklist /FI "IMAGENAME eq notepad.exe" /FO TABLE
```

### Пример для Задания 2:
```
Шаг 1: Поиск процесса
  tasklist /FI "IMAGENAME eq notepad.exe"

Шаг 2: Получение PID
  wmic process where "name='notepad.exe'" get ProcessId

Шаг 3: Завершение процесса
  taskkill /PID 1234 /F
```
