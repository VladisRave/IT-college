## 1. Понятие дискретной случайной величины

### 1.1. Случайная величина как фундаментальное понятие теории вероятностей

**Случайная величина** — это числовая функция, заданная на пространстве элементарных исходов случайного эксперимента. Каждому элементарному исходу ставится в соответствие определенное числовое значение.

**Формальное определение:**
Пусть Ω — пространство элементарных исходов. Тогда случайная величина X — это функция X: Ω → ℝ, такая что для любого вещественного числа x множество {ω ∈ Ω: X(ω) < x} является событием.

### 1.2. Классификация случайных величин

Случайные величины делятся на два основных класса:

1. **Дискретные случайные величины** — принимают конечное или счетное множество значений
2. **Непрерывные случайные величины** — принимают несчетное множество значений (заполняют интервал)

### 1.3. Дискретная случайная величина (ДСВ)

**Определение:** Случайная величина X называется дискретной, если она принимает конечное или счетное число значений x₁, x₂, ..., xₙ, ... с вероятностями p₁, p₂, ..., pₙ, ... соответственно.

**Математическая запись:** P(X = xᵢ) = pᵢ для i = 1, 2, ..., n, ...

**Характеристики ДСВ:**
- Множество значений дискретно (изолированные точки)
- Вероятность каждого конкретного значения строго больше нуля
- Сумма вероятностей всех возможных значений равна 1

**Примеры ДСВ:**
- Число студентов, присутствующих на лекции
- Количество успешных запусков ракеты из 10 попыток
- Число вызовов, поступивших на телефонную станцию за час
- Результат броска двух игральных костей (сумма очков)

## 2. Способы задания дискретной случайной величины

### 2.1. Ряд распределения ДСВ

**Ряд распределения** — это полная характеристика дискретной случайной величины, представленная в табличной форме.

**Стандартная форма ряда распределения:**
| X | x₁ | x₂ | ... | xₙ |
|---|---|---|---|---|
| P | p₁ | p₂ | ... | pₙ |

где:
- xᵢ — возможные значения случайной величины
- pᵢ = P(X = xᵢ) — вероятности этих значений

### 2.2. Аксиоматические свойства распределения

Для любого ряда распределения должны выполняться следующие условия:

1. **Неотрицательность вероятностей:** pᵢ ≥ 0 для всех i = 1, 2, ..., n
2. **Нормированность:** ∑pᵢ = 1 (сумма всех вероятностей равна 1)
3. **Полнота:** ряд содержит все возможные значения случайной величины

### 2.3. Пример построения ряда распределения

**Задача:** Подбрасываем три монеты. Случайная величина X — число выпавших "орлов". Построить ряд распределения.

**Решение:**

1. **Пространство элементарных исходов:**
   Всего 2³ = 8 равновозможных исходов:
   ООО, ООР, ОРО, ОРР, РОО, РОР, РРО, РРР

2. **Значения случайной величины:**
   - ООО → X = 3
   - ООР, ОРО, РОО → X = 2
   - ОРР, РОР, РРО → X = 1
   - РРР → X = 0

3. **Вычисление вероятностей:**
   - P(X = 0) = 1/8
   - P(X = 1) = 3/8
   - P(X = 2) = 3/8
   - P(X = 3) = 1/8

4. **Ряд распределения:**

| X | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| P | 1/8 | 3/8 | 3/8 | 1/8 |

**Проверка нормированности:** 1/8 + 3/8 + 3/8 + 1/8 = 8/8 = 1 ✓

## 3. Графическое изображение распределения ДСВ

### 3.1. Многоугольник распределения

**Многоугольник распределения** — это график, соединяющий точки (xᵢ, pᵢ) на координатной плоскости.

**Алгоритм построения:**
1. Выбираем прямоугольную систему координат
2. На оси абсцисс откладываем значения случайной величины xᵢ
3. На оси ординат откладываем соответствующие вероятности pᵢ
4. Отмечаем точки с координатами (xᵢ, pᵢ)
5. Соединяем точки отрезками в порядке возрастания xᵢ

**Свойства многоугольника распределения:**
- Все точки лежат не ниже оси OX (pᵢ ≥ 0)
- Сумма ординат всех точек равна 1
- Форма многоугольника характеризует распределение вероятностей

### 3.2. Столбчатая диаграмма (гистограмма)

**Столбчатая диаграмма** — это график, где каждому значению случайной величины соответствует прямоугольник, площадь которого пропорциональна вероятности.

**Алгоритм построения:**
1. На оси OX отмечаем значения xᵢ
2. Над каждым xᵢ строим прямоугольник высотой pᵢ
3. Ширина столбцов обычно постоянна
4. Площадь каждого столбца равна pᵢ

### 3.3. Практическое значение графиков

**Аналитические возможности графиков:**
- Визуальная оценка моды распределения (наиболее вероятное значение)
- Определение симметричности/асимметричности распределения
- Сравнение различных распределений
- Выявление "тяжелых хвостов" распределения

## 4. Функции от дискретной случайной величины

### 4.1. Понятие функции от ДСВ

Если X — дискретная случайная величина с распределением P(X = xᵢ) = pᵢ, а φ(x) — некоторая числовая функция, то Y = φ(X) также является дискретной случайной величиной.

**Математическая запись:** Y = φ(X), где φ: ℝ → ℝ

### 4.2. Общий алгоритм нахождения распределения функции от ДСВ

**Алгоритм:**
1. Записываем ряд распределения исходной величины X
2. Для каждого значения xᵢ вычисляем yᵢ = φ(xᵢ)
3. Если разным xᵢ соответствуют одинаковые yᵢ, объединяем эти значения, суммируя соответствующие вероятности
4. Записываем ряд распределения для Y

**Формально:** P(Y = y) = ∑P(X = xᵢ) для всех i таких, что φ(xᵢ) = y

### 4.3. Пример вычисления распределения сложной функции

**Дано:** Распределение величины X
| X | -2 | -1 | 0 | 1 | 2 |
|---|---|---|---|---|---|
| P | 0.1 | 0.2 | 0.3 | 0.25 | 0.15 |

**Найти:** Распределение величины Y = X² + 1

**Решение:**

1. **Вычисляем Y для каждого X:**
   - X = -2 → Y = (-2)² + 1 = 4 + 1 = 5
   - X = -1 → Y = (-1)² + 1 = 1 + 1 = 2
   - X = 0 → Y = 0² + 1 = 0 + 1 = 1
   - X = 1 → Y = 1² + 1 = 1 + 1 = 2
   - X = 2 → Y = 2² + 1 = 4 + 1 = 5

2. **Объединяем одинаковые значения Y:**
   - Y = 1: только при X = 0 → P(Y=1) = 0.3
   - Y = 2: при X = -1 и X = 1 → P(Y=2) = 0.2 + 0.25 = 0.45
   - Y = 5: при X = -2 и X = 2 → P(Y=5) = 0.1 + 0.15 = 0.25

3. **Ряд распределения Y:**
| Y | 1 | 2 | 5 |
|---|---|---|---|
| P | 0.3 | 0.45 | 0.25 |

**Проверка нормированности:** 0.3 + 0.45 + 0.25 = 1 ✓

### 4.4. Особые случаи функций от ДСВ

**Линейное преобразование:** Y = aX + b
- Сохраняет структуру распределения
- Значения преобразуются линейно: yᵢ = axᵢ + b
- Вероятности остаются неизменными: P(Y = yᵢ) = P(X = xᵢ)

**Квадратичная функция:** Y = X²
- "Сворачивает" распределение (отрицательные значения отображаются в положительные)
- Требует суммирования вероятностей для одинаковых yᵢ

## 5. Практические примеры и приложения

### 5.1. Контроль качества продукции

На заводе проверяют партию из 20 деталей. Вероятность того, что деталь бракованная, равна 0.05. X — число бракованных деталей в партии.

**Задача:** Найти вероятность того, что в партии окажется от 1 до 3 бракованных деталей включительно.

### 5.2. Теория надежности

Система состоит из 5 независимо работающих элементов. Вероятность отказа каждого элемента за время T равна 0.1. X — число отказавших элементов за время T.

**Задача:** Определить, при каком минимальном количестве резервных элементов система будет работать с вероятностью не менее 0.99.

### 5.3. Обработка экспериментальных данных

В эксперименте регистрируется число частиц, попадающих в счетчик за фиксированный интервал времени. Известно, что среднее число частиц равно 4 за интервал.

**Задача:** Построить теоретическое распределение числа частиц и найти вероятность того, что за интервал будет зарегистрировано не менее 3 частиц.
