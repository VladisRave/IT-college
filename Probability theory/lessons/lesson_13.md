### **Краткий теоретический конспект**

**Непрерывная случайная величина (НСВ)** – это величина, которая в результате испытания может принять **любое** значение из некоторого числового промежутка. Вероятность отдельно взятого значения для НСВ равна нулю. Для её описания используют две функции:

1.  **Функция плотности вероятности (плотность распределения) `f(x)`**:
    *   Неотрицательна: `f(x) ≥ 0`.
    *   Вероятность попадания в интервал `[a; b]` равна площади под её графиком: `P(a ≤ X ≤ b) = ∫_{a}^{b} f(x) dx`.
    *   Условие нормировки: Полная площадь под кривой равна 1: `∫_{-∞}^{+∞} f(x) dx = 1`.

2.  **Интегральная функция распределения `F(x)`**:
    *   Определяет вероятность того, что НСВ примет значение меньше `x`: `F(x) = P(X < x)`.
    *   Связь с плотностью: `F(x) = ∫_{-∞}^{x} f(t) dt` (первообразная), и наоборот, `f(x) = F'(x)` (производная).
    *   Свойства: `0 ≤ F(x) ≤ 1`; `F(x)` – неубывающая; `F(-∞)=0`, `F(+∞)=1`.

**Равномерное распределение** – простейший закон распределения НСВ, где все значения на отрезке `[a; b]` равновозможны.
*   Плотность: `f(x) = 1/(b-a)` для `x ∈ [a; b]`, иначе `0`.
*   Функция распределения:
    *   `F(x) = 0` при `x < a`
    *   `F(x) = (x-a)/(b-a)` при `a ≤ x ≤ b`
    *   `F(x) = 1` при `x > b`
*   Числовые характеристики:
    *   Математическое ожидание: `M(X) = (a+b)/2`
    *   Дисперсия: `D(X) = (b-a)²/12`
    *   Среднее квадратическое отклонение: `σ(X) = (b-a)/√12`

**Геометрическое определение вероятности**: если множество всех элементарных исходов можно представить как область `Ω` некоторой меры (длины, площади, объема), а благоприятные исходы – как подобласть `A`, и попадание в любую точку области равновозможно, то `P(A) = mes(A) / mes(Ω)`.

**Центральная предельная теорема (ЦПТ)**: каковы бы ни были законы распределения независимых случайных величин (при выполнении некоторых условий), закон распределения их суммы (или среднего арифметического) при достаточно большом числе слагаемых будет сколь угодно близок к **нормальному закону**. Это объясняет широкую распространенность нормального распределения.
