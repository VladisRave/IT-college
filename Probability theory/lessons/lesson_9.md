# **Биномиальное распределение и его характеристики**

### 1. Введение

**Мотивация:** Многие реальные процессы описываются схемой повторных независимых испытаний:
- Контроль качества (бракованные/годные детали)
- Медицинские исследования (успех/неудача лечения)
- Социологические опросы (согласен/не согласен)

### 2. Схема Бернулли

#### 2.1. Определение

**Схема Бернулли** — это последовательность n независимых испытаний, в каждом из которых событие A происходит с постоянной вероятностью p.

**Характеристики:**
- n — количество испытаний
- p — вероятность "успеха" в каждом испытании
- q = 1 - p — вероятность "неудачи"

#### 2.2. Примеры схемы Бернулли

1. **Подбрасывание монеты 10 раз** (успех = "орел")
   - n = 10, p = 0.5

2. **Стрельба по мишени 5 раз** (успех = "попадание")
   - n = 5, p = 0.8 (если вероятность попадания 0.8)

3. **Проверка 20 деталей** (успех = "деталь бракованная")
   - n = 20, p = 0.05

### 3. Биномиальное распределение

#### 3.1. Определение

**Биномиальное распределение** описывает число успехов в n независимых испытаниях Бернулли.

**Обозначение:** X ~ B(n, p)

#### 3.2. Формула вероятности

Вероятность того, что в n испытаниях произойдет ровно k успехов:

```
P(X = k) = Cₙᵏ · pᵏ · (1-p)ⁿ⁻ᵏ
```

где `Cₙᵏ = n! / (k! · (n-k)!)` — биномиальный коэффициент

#### 3.3. Подробный пример

**Задача:** Монету подбрасывают 5 раз. X — количество выпавших "орлов". Найти распределение X.

**Решение:**

Параметры: n = 5, p = 0.5

Вычисляем вероятности для k = 0, 1, 2, 3, 4, 5:

```
P(X = 0) = C₅⁰ · (0.5)⁰ · (0.5)⁵ = 1 · 1 · 1/32 = 1/32
P(X = 1) = C₅¹ · (0.5)¹ · (0.5)⁴ = 5 · 0.5 · 1/16 = 5/32
P(X = 2) = C₅² · (0.5)² · (0.5)³ = 10 · 0.25 · 1/8 = 10/32
P(X = 3) = C₅³ · (0.5)³ · (0.5)² = 10 · 1/8 · 1/4 = 10/32
P(X = 4) = C₅⁴ · (0.5)⁴ · (0.5)¹ = 5 · 1/16 · 0.5 = 5/32
P(X = 5) = C₅⁵ · (0.5)⁵ · (0.5)⁰ = 1 · 1/32 · 1 = 1/32
```

**Ряд распределения:**
| X | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| P | 1/32 | 5/32 | 10/32 | 10/32 | 5/32 | 1/32 |

### 4. Числовые характеристики биномиального распределения (25 минут)

#### 4.1. Математическое ожидание

Для X ~ B(n, p):
```
M(X) = n·p
```

**Доказательство:**
```
X = X₁ + X₂ + ... + Xₙ, где Xᵢ — индикатор успеха в i-м испытании
M(Xᵢ) = 1·p + 0·(1-p) = p
M(X) = M(X₁) + ... + M(Xₙ) = n·p
```

#### 4.2. Дисперсия

Для X ~ B(n, p):
```
D(X) = n·p·(1-p) = n·p·q
```

**Доказательство:**
```
D(Xᵢ) = M(Xᵢ²) - [M(Xᵢ)]² = p - p² = p(1-p)
Так как Xᵢ независимы, D(X) = ΣD(Xᵢ) = n·p·(1-p)
```

#### 4.3. Среднеквадратическое отклонение

```
σ(X) = √[n·p·(1-p)]
```

#### 4.4. Пример вычисления характеристик

**Для примера с 5 подбрасываниями монеты:**
```
M(X) = 5 · 0.5 = 2.5
D(X) = 5 · 0.5 · 0.5 = 1.25
σ(X) = √1.25 ≈ 1.118
```

### 5. Свойства и особенности биномиального распределения

#### 5.1. Симметричность

Если p = 0.5, распределение симметрично относительно n/2.

#### 5.2. Мода распределения

**Мода** — наиболее вероятное значение:
- Если (n+1)·p — не целое: мода = ⌊(n+1)·p⌋
- Если (n+1)·p — целое: моды = (n+1)·p и (n+1)·p - 1

#### 5.3. Приближение нормальным распределением

При больших n (n > 20) и p не слишком близком к 0 или 1:
```
B(n, p) ≈ N(np, np(1-p))
```

### 6. Практические приложения

#### 6.1. Контроль качества

**Задача:** В партии 100 деталей, вероятность брака 0.02. Найти вероятность того, что в выборке из 10 деталей будет не более 1 бракованной.

#### 6.2. Медицинские исследования

**Задача:** Лечение эффективно в 70% случаев. Из 20 пациентов найти вероятность того, что лечение поможет хотя бы 15.

#### 6.3. Социологические опросы

**Задача:** 40% населения поддерживает кандидата. При опросе 100 человек найти вероятность того, что его поддержат от 35 до 45 человек.

4. **Задача 4:** Завод производит 1000 изделий в день. Вероятность брака 0.01. Найдите среднее число бракованных изделий в день и среднее квадратическое отклонение.
