# **Практическая работа №4**

## **Тема:**

**Построение закона распределения и функции распределения ДСВ.  
Вычисление основных числовых характеристик ДСВ.**

---

## **Теоретический материал**

### **1. Дискретная случайная величина (ДСВ)**

ДСВ — это величина $X$, которая может принимать отдельные, конкретные значения $x_1, x_2, x_3, \dots$ с некоторыми вероятностями.

---

### **2. Закон распределения (PMF)**

Закон распределения задан таблицей:

| $x_i$ | $p_i = P(X = x_i)$ |
| :---- | :----------------- |
| $x_1$ | $p_1$              |
| $x_2$ | $p_2$              |
| $\vdots$ | $\vdots$        |

Условия корректности:

$$p_i \ge 0, \qquad \sum_i p_i = 1$$

---

### **3. Функция распределения (CDF)**

Функция распределения:

$$F_X(x) = P(X \le x) = \sum_{x_i \le x} p_i$$

Это ступенчатая неубывающая функция:

$$\lim_{x\to -\infty} F(x) = 0, \qquad \lim_{x\to +\infty} F(x) = 1$$

---

### **4. Числовые характеристики**

#### **Математическое ожидание**

$$E[X] = \sum_i x_i p_i$$

#### **Второй момент**

$$E[X^2] = \sum_i x_i^2 p_i$$

#### **Дисперсия**

$$\operatorname{Var}(X) = E[X^2] - (E[X])^2$$

#### **Среднее квадратическое отклонение**

$$\sigma = \sqrt{\operatorname{Var}(X)}$$

---

### **5. Стандартный алгоритм в задачах**

1. Составить таблицу $(x_i, p_i)$
2. Проверить: $\sum p_i = 1$
3. Построить $F_X(x)$ — накопительные суммы
4. Найти $E[X]$
5. Найти $E[X^2]$
6. Найти $\operatorname{Var}(X)$ и $\sigma$

---

## **Разбор примеров**

### **ЗАДАЧА 1 (подробное решение)**

ДСВ $X$ принимает значения $-1, 0, 1$ с вероятностями  
$P(X=-1)=0.20$, $P(X=0)=0.50$, $P(X=1)=0.30$

Требуется:

1. Построить PMF
2. Построить CDF
3. Найти $E[X]$, $E[X^2]$, $\operatorname{Var}(X)$, $\sigma$

---

#### **Решение**

##### **1. Таблица PMF**

| $x$ | $p$ |
| :-- | :-- |
| -1  | 0.20 |
| 0   | 0.50 |
| 1   | 0.30 |

Проверка:  
$$0.20 + 0.50 + 0.30 = 1$$

##### **2. CDF**

$$F_X(x) = P(X \le x)$$

| Интервал $x$ | $F_X(x)$ |
| :----------- | :------- |
| $x < -1$     | 0        |
| $-1 \le x < 0$ | 0.20   |
| $0 \le x < 1$ | 0.70     |
| $x \ge 1$     | 1.00     |

##### **3. Математическое ожидание**

$$E[X] = (-1) \cdot 0.20 + 0 \cdot 0.50 + 1 \cdot 0.30 = 0.10$$

##### **4. Второй момент**

$$E[X^2] = (-1)^2 \cdot 0.20 + 0^2 \cdot 0.50 + 1^2 \cdot 0.30 = 0.20 + 0 + 0.30 = 0.50$$

##### **5. Дисперсия**

$$\operatorname{Var}(X) = 0.50 - (0.10)^2 = 0.49$$

##### **6. Стандартное отклонение**

$$\sigma = \sqrt{0.49} = 0.70$$

---

### **ЗАДАЧА 2 (подробное решение)**

Биномиальная ДСВ  
$n = 3$, $p = 0.4$

Требуется: построить PMF, CDF, найти $E[X]$, $\operatorname{Var}(X)$, $\sigma$

---

#### **Решение**

Пусть $q = 1 - p = 0.6$

Формула:

$$P(X = k) = \binom{3}{k} p^k q^{3-k}$$

Вычислим:

$$P(X = 0) = 0.6^3 = 0.216$$
$$P(X = 1) = 3 \cdot 0.4 \cdot 0.6^2 = 0.432$$
$$P(X = 2) = 3 \cdot 0.4^2 \cdot 0.6 = 0.288$$
$$P(X = 3) = 0.4^3 = 0.064$$

##### **PMF**

| $k$ | $P(X = k)$ |
| :-- | :--------- |
| 0   | 0.216      |
| 1   | 0.432      |
| 2   | 0.288      |
| 3   | 0.064      |

##### **CDF**

| $x$ | $F_X(x)$ |
| :-- | :------- |
| $x < 0$ | 0      |
| $0 \le x < 1$ | 0.216 |
| $1 \le x < 2$ | 0.648 |
| $2 \le x < 3$ | 0.936 |
| $x \ge 3$ | 1.000 |

##### **Математическое ожидание**

$$E[X] = n p = 3 \cdot 0.4 = 1.2$$

##### **Дисперсия**

$$\operatorname{Var}(X) = n p q = 3 \cdot 0.4 \cdot 0.6 = 0.72$$

##### **Стандартное отклонение**

$$\sigma = \sqrt{0.72} \approx 0.8485$$
