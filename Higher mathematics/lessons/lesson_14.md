## Теоретическая часть

### 1. Введение и мотивация

### 2. Определение двойного интеграла

#### 2.1. Основные понятия

**Область интегрирования D** — замкнутая ограниченная область в плоскости Oxy.

**Разбиение области D** — разделение на n элементарных областей ΔS₁, ΔS₂, ..., ΔSₙ.

**Диаметр разбиения** — максимальный диаметр элементарных областей.

#### 2.2. Формальное определение

Двойной интеграл от функции f(x,y) по области D определяется как предел интегральных сумм:

```math
     n
∬ f(x,y)dS = lim    ∑ f(ξᵢ,ηᵢ)ΔSᵢ
   D        d→0 i=1
```

где (ξᵢ,ηᵢ) — произвольная точка в i-й элементарной области.

#### 2.3. Геометрический смысл

Если f(x,y) ≥ 0, то двойной интеграл равен объему цилиндрического тела:
- Основание — область D
- Верхняя граница — поверхность z = f(x,y)

```math
V = ∬ f(x,y)dS
       D
```

### 3. Свойства двойных интегралов

#### 3.1. Линейность
```math
∬ [αf(x,y) + βg(x,y)]dS = α∬ f(x,y)dS + β∬ g(x,y)dS
 D                       D           D
```

#### 3.2. Аддитивность
Если D = D₁ ∪ D₂ и D₁ ∩ D₂ = ∅, то:
```math
∬ f(x,y)dS = ∬ f(x,y)dS + ∬ f(x,y)dS
 D           D₁           D₂
```

#### 3.3. Оценка интеграла
Если m ≤ f(x,y) ≤ M в области D, то:
```math
mS(D) ≤ ∬ f(x,y)dS ≤ MS(D)
           D
```

#### 3.4. Теорема о среднем
Если f(x,y) непрерывна в D, то существует точка (ξ,η)∈D такая, что:
```math
∬ f(x,y)dS = f(ξ,η)S(D)
   D
```

### 4. Вычисление двойных интегралов

#### 4.1. Сведение к повторным интегралам

**Случай 1:** Область D — прямоугольник
```math
     b d
∬ f(x,y)dS = ∫ ∫ f(x,y)dydx
   D     a c
```

**Случай 2:** Область D ограничена кривыми
```math
     b   φ₂(x)
∬ f(x,y)dS = ∫   ∫ f(x,y)dydx
   D     a φ₁(x)
```

#### 4.2. Пример области типа I:
```
D: a ≤ x ≤ b, φ₁(x) ≤ y ≤ φ₂(x)
```

#### 4.3. Пример области типа II:
```
D: c ≤ y ≤ d, ψ₁(y) ≤ x ≤ ψ₂(y)
```

### 5. Замена переменных в двойном интеграле

```math
∬ f(x,y)dxdy = ∬ f(x(u,v), y(u,v))|J|dudv
   D           D'
```

где J — якобиан преобразования:
```math
    ∂(x,y)
J = -------- = |∂x/∂u  ∂x/∂v|
    ∂(u,v)     |∂y/∂u  ∂y/∂v|
```
