# Конспект лекции по дифференциальным уравнениям

## 1. Основные понятия

### 1.1 Дифференциальное уравнение (ДУ)
Уравнение, связывающее неизвестную функцию, её аргумент и производные различных порядков.

**Общий вид ДУ первого порядка:**
```
F(x, y, y') = 0
```

**Общий вид ДУ второго порядка:**
```
F(x, y, y', y'') = 0
```

### 1.2 Виды решений
- **Общее решение** — семейство функций, содержащее произвольные постоянные
- **Частное решение** — конкретная функция из семейства, полученная при определённых начальных условиях
- **Особое решение** — решение, не получающееся из общего ни при каких значениях постоянных

### 1.3 Задача Коши
Найти решение ДУ, удовлетворяющее начальным условиям:
- Для ДУ 1-го порядка: y(x₀) = y₀
- Для ДУ 2-го порядка: y(x₀) = y₀, y'(x₀) = y₁

## 2. ДУ первого порядка

### 2.1 Уравнения с разделяющимися переменными
**Общий вид:** y' = f(x)g(y)

**Метод решения:**
1. Записать производную как dy/dx
2. Разделить переменные: dy/g(y) = f(x)dx
3. Проинтегрировать обе части: ∫dy/g(y) = ∫f(x)dx
4. Получить общее решение: G(y) = F(x) + C

### 2.2 Линейные однородные ДУ 1-го порядка
**Общий вид:** y' + p(x)y = 0

**Метод решения:**
1. Разделить переменные: dy/y = -p(x)dx
2. Проинтегрировать: ln|y| = -∫p(x)dx + C
3. Общее решение: y = Ce^{-∫p(x)dx}

## 3. ДУ второго порядка

### 3.1 Уравнения вида y'' = f(x)
**Метод решения:** Двукратное интегрирование
1. Интегрируем первый раз: y' = ∫f(x)dx + C₁
2. Интегрируем второй раз: y = ∫(∫f(x)dx)dx + C₁x + C₂

### 3.2 Уравнения, не содержащие явно y
**Общий вид:** F(x, y', y'') = 0

**Метод решения (понижение порядка):**
1. Замена: y' = p(x), тогда y'' = p'(x)
2. Получаем ДУ первого порядка относительно p(x)
3. Решаем, находим p(x) = y'
4. Интегрируем: y = ∫p(x)dx + C

### 3.3 Уравнения, не содержащие явно x
**Общий вид:** F(y, y', y'') = 0

**Метод решения (понижение порядка):**
1. Замена: y' = p(y), тогда y'' = p·dp/dy
2. Получаем ДУ первого порядка относительно p(y)
3. Решаем, находим p(y)
4. Возвращаемся к переменным: dy/dx = p(y)
5. Решаем ДУ с разделяющимися переменными

## 5. Ключевые формулы для запоминания

### Решение ДУ с разделяющимися переменными:
```
dy/dx = f(x)g(y) ⇒ ∫dy/g(y) = ∫f(x)dx + C
```

### Решение линейного однородного ДУ 1-го порядка:
```
y' + p(x)y = 0 ⇒ y = Ce^{-∫p(x)dx}
```

### Решение ДУ второго порядка y'' = f(x):
```
y' = ∫f(x)dx + C₁
y = ∫(∫f(x)dx)dx + C₁x + C₂
```

### Понижение порядка при отсутствии y:
```
y' = p(x), y'' = p'(x)
F(x, p, p') = 0
```

### Понижение порядка при отсутствии x:
```
y' = p(y), y'' = p·dp/dy
F(y, p, p·dp/dy) = 0
```

## 6. Алгоритмы решения

### Алгоритм 1: Решение ДУ с разделяющимися переменными
1. Представить y' как dy/dx
2. Перенести все y влево, все x вправо
3. Проинтегрировать обе части
4. Выразить y (если возможно)
5. Использовать начальные условия для нахождения C

### Алгоритм 2: Решение линейного однородного ДУ 1-го порядка
1. Разделить переменные
2. Проинтегрировать
3. Потенцировать (избавиться от ln)
4. Использовать начальные условия

### Алгоритм 3: Решение ДУ второго порядка y'' = f(x)
1. Первое интегрирование: найти y'
2. Второе интегрирование: найти y
3. Использовать два начальных условия для нахождения C₁ и C₂

### Алгоритм 4: Понижение порядка (отсутствует y)
1. Замена: y' = p(x)
2. Решить ДУ первого порядка для p(x)
3. Обратная замена: y' = p(x)
4. Интегрировать для нахождения y

### Алгоритм 5: Понижение порядка (отсутствует x)
1. Замена: y' = p(y), y'' = p·dp/dy
2. Решить ДУ первого порядка для p(y)
3. Обратная замена: dy/dx = p(y)
4. Решить ДУ с разделяющимися переменными

## 7. Примеры решений

### Пример 1 (ДУ с разделяющимися переменными):
```
y' = 2xy
dy/dx = 2xy
dy/y = 2x dx
∫dy/y = ∫2x dx
ln|y| = x² + C
y = e^{x² + C} = C₁e^{x²}, где C₁ = e^C
```

### Пример 2 (Линейное однородное):
```
y' + 3y = 0
dy/dx = -3y
dy/y = -3 dx
ln|y| = -3x + C
y = Ce^{-3x}
```

### Пример 3 (ДУ второго порядка):
```
y'' = 6x
y' = ∫6x dx = 3x² + C₁
y = ∫(3x² + C₁) dx = x³ + C₁x + C₂
```

## Пошаговые указания для сложных задач:

### Для задач 21-25 (не содержит y):
1. Делаем замену: `y' = p(x)`, тогда `y'' = p'(x)`
2. Подставляем в уравнение, получаем ДУ 1-го порядка для `p(x)`
3. Решаем это ДУ
4. Возвращаемся: `y' = p(x)`
5. Интегрируем: `y = ∫p(x)dx + C₂`

### Для задач 26-30 (не содержит x):
1. Делаем замену: `y' = p(y)`, тогда `y'' = d/dx(p) = dp/dy·dy/dx = p·dp/dy`
2. Подставляем в уравнение, получаем ДУ 1-го порядка для `p(y)`
3. Решаем это ДУ относительно `p(y)`
4. Возвращаемся: `dy/dx = p(y)`
5. Решаем ДУ с разделяющимися переменными

### Особые случаи:
- **Задача 25**: `y'' = (y')²`  
  После замены: `p' = p²` ⇒ `dp/p² = dx` ⇒ `-1/p = x + C₁` ⇒ `p = -1/(x + C₁)`

- **Задача 30**: `y'' = y'·y`  
  Случай 1: `y' = 0` ⇒ `y = C`  
  Случай 2: `p ≠ 0` ⇒ `dp/dy = y` ⇒ `p = ½·y² + C₁`

## Ключевые моменты для проверки решений:

1. **Порядок ДУ** = максимальный порядок производной
2. **Общее решение** ДУ 1-го порядка содержит 1 константу
3. **Общее решение** ДУ 2-го порядка содержит 2 константы
4. Для **частного решения** нужно столько условий, каков порядок
5. При **разделении переменных** проверьте, что делитель ≠ 0
6. В **задачах Коши** сначала найдите общее решение, потом константы
