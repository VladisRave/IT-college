# Вычисление определенных интегралов

## Определение определенного интеграла

**Определенный интеграл** — это число, которое показывает площадь под кривой функции на отрезке $[a, b]$.

## Формула Ньютона-Лейбница

Основная формула для вычисления определенных интегралов:

$$\int_{a}^{b} f(x)  dx = F(b) - F(a)$$

где:
- $\int$ — знак интеграла
- $a$ и $b$ — пределы интегрирования
- $f(x)$ — подынтегральная функция
- $F(x)$ — первообразная функции $f(x)$
- $dx$ — дифференциал

## Алгоритм решения задач на определенный интеграл

### Шаг 1: Найти первообразную $F(x)$

Используем правила интегрирования:

**Основные формулы:**
- $\int x^n  dx = \frac{x^{n+1}}{n+1} + C$ (при $n \neq -1$)
- $\int k  dx = kx + C$ ($k$ - константа)
- $\int e^x  dx = e^x + C$
- $\int \frac{1}{x}  dx = \ln|x| + C$

### Шаг 2: Подставить пределы интегрирования

Вычисляем $F(b)$ и $F(a)$

### Шаг 3: Найти разность $F(b) - F(a)$

## Примеры решения

### Пример 1

Вычислить: $\int_{1}^{3} 2x  dx$

**Решение:**

**Шаг 1:** Находим первообразную
$F(x) = \int 2x  dx = 2 \cdot \frac{x^2}{2} = x^2$

**Шаг 2:** Подставляем пределы
$F(3) = 3^2 = 9$
$F(1) = 1^2 = 1$

**Шаг 3:** Находим разность
$\int_{1}^{3} 2x  dx = F(3) - F(1) = 9 - 1 = 8$

**Ответ:** 8

### Пример 2

Вычислить: $\int_{0}^{4} (3x^2 + 2x + 1)  dx$

**Решение:**

**Шаг 1:** Находим первообразную
$F(x) = \int (3x^2 + 2x + 1)  dx = 3 \cdot \frac{x^3}{3} + 2 \cdot \frac{x^2}{2} + x = x^3 + x^2 + x$

**Шаг 2:** Подставляем пределы
$F(4) = 4^3 + 4^2 + 4 = 64 + 16 + 4 = 84$
$F(0) = 0^3 + 0^2 + 0 = 0$

**Шаг 3:** Находим разность
$\int_{0}^{4} (3x^2 + 2x + 1)  dx = F(4) - F(0) = 84 - 0 = 84$

**Ответ:** 84

### Пример 3

Вычислить: $\int_{1}^{9} \sqrt{x}  dx$

**Решение:**

**Шаг 1:** Записываем корень как степень и находим первообразную
$\sqrt{x} = x^{1/2}$
$F(x) = \int x^{1/2}  dx = \frac{x^{3/2}}{3/2} = \frac{2}{3} \cdot x^{3/2}$

**Шаг 2:** Подставляем пределы
$F(9) = \frac{2}{3} \cdot 9^{3/2} = \frac{2}{3} \cdot 27 = 18$
$F(1) = \frac{2}{3} \cdot 1^{3/2} = \frac{2}{3} \cdot 1 = \frac{2}{3}$

**Шаг 3:** Находим разность
$\int_{1}^{9} \sqrt{x}  dx = F(9) - F(1) = 18 - \frac{2}{3} = \frac{54}{3} - \frac{2}{3} = \frac{52}{3}$

**Ответ:** $\frac{52}{3}$

## Важные свойства определенных интегралов

### 1. Перестановка пределов интегрирования:
$$\int_{a}^{b} f(x)  dx = -\int_{b}^{a} f(x)  dx$$

**Пример:**
$\int_{3}^{1} 2x  dx = -\int_{1}^{3} 2x  dx = -8$

### 2. Интеграл на отрезке нулевой длины:
$$\int_{a}^{a} f(x)  dx = 0$$

### 3. Разбиение промежутка интегрирования:
$$\int_{a}^{c} f(x)  dx = \int_{a}^{b} f(x)  dx + \int_{b}^{c} f(x)  dx$$

## Геометрический смысл

Определенный интеграл $\int_{a}^{b} f(x)  dx$ численно равен площади криволинейной трапеции:

- Ограниченной сверху графиком функции $y = f(x)$
- Снизу — осью $OX$
- С боков — вертикальными прямыми $x = a$ и $x = b$

## Практическое применение

### 1. Вычисление площадей:
- Площадь под кривой
- Площадь между двумя кривыми

### 2. Физические приложения:
- Вычисление пути по известной скорости
- Работа переменной силы
- Центр масс

## Ключевые формулы для запоминания

1. $\int_{a}^{b} x^n  dx = \frac{b^{n+1} - a^{n+1}}{n+1}$
2. $\int_{a}^{b} k  dx = k(b - a)$
3. $\int_{a}^{b} e^x  dx = e^b - e^a$
4. $\int_{a}^{b} \frac{1}{x}  dx = \ln|b| - \ln|a|$

## Алгоритм для запоминания

1. **Найти первообразную** — используй таблицу интегралов
2. **Подставить верхний предел** — вычисляй $F(b)$
3. **Подставить нижний предел** — вычисляй $F(a)$
4. **Вычесть** — из верхнего значения вычти нижнее
5. **Проверить** — убедись, что ответ разумен
