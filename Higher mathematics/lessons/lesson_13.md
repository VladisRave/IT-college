# Лекция: Производные и дифференциалы высших порядков

## Введение

### Что такое производные высших порядков?

Представьте, что вы едете на машине. Ваша позиция на дороге - это функция пути s(t). 
- **Первая производная** s'(t) - это ваша **скорость** (как быстро меняется положение)
- **Вторая производная** s''(t) - это **ускорение** (как быстро меняется скорость)
- **Третья производная** s'''(t) - это **рывок** (как быстро меняется ускорение)

---

## 1. ПРОИЗВОДНЫЕ ВЫСШИХ ПОРЯДКОВ

### 1.1. Основные понятия

**Определение:** Производная высшего порядка - это производная от производной.

**Обозначения:**
- Вторая производная: y'', f''(x), $\frac{d²y}{dx²}$
- Третья производная: y''', f'''(x), $\frac{d³y}{dx³}$
- n-я производная: $y^{(n)}$, $f^{(n)}(x)$, $\frac{d^ny}{dx^n}$

### 1.2. Подробный пример вычисления

**Пример 1:** Найдем первые три производные функции y = x³ - 2x² + 5x - 1

**Шаг 1: Первая производная**
```
y = x³ - 2x² + 5x - 1
y' = 3x² - 4x + 5
```
*Объяснение:* Производная x³ равна 3x², производная -2x² равна -4x, производная 5x равна 5, производная константы -1 равна 0.

**Шаг 2: Вторая производная**
```
y' = 3x² - 4x + 5
y'' = 6x - 4
```
*Объяснение:* Производная 3x² равна 6x, производная -4x равна -4, производная константы 5 равна 0.

**Шаг 3: Третья производная**
```
y'' = 6x - 4
y''' = 6
```
*Объяснение:* Производная 6x равна 6, производная константы -4 равна 0.

**Ответ:** y' = 3x² - 4x + 5, y'' = 6x - 4, y''' = 6

### 1.3. Производные тригонометрических функций

**Пример 2:** Найдем производные функции y = sin(2x)

**Шаг 1: Первая производная**
```
y = sin(2x)
y' = cos(2x) · 2 = 2cos(2x)
```
*Объяснение:* Используем правило производной сложной функции: производная sin(u) = cos(u)·u'

**Шаг 2: Вторая производная**
```
y' = 2cos(2x)
y'' = 2 · (-sin(2x)) · 2 = -4sin(2x)
```
*Объяснение:* Производная cos(u) = -sin(u)·u'

**Шаг 3: Третья производная**
```
y'' = -4sin(2x)
y''' = -4 · cos(2x) · 2 = -8cos(2x)
```

**Ответ:** y' = 2cos(2x), y'' = -4sin(2x), y''' = -8cos(2x)

### 1.4. Производные показательных функций

**Пример 3:** Найдем производные функции y = e³ˣ

**Шаг 1: Первая производная**
```
y = e³ˣ
y' = e³ˣ · 3 = 3e³ˣ
```
*Объяснение:* Производная eᵘ = eᵘ·u'

**Шаг 2: Вторая производная**
```
y' = 3e³ˣ
y'' = 3 · e³ˣ · 3 = 9e³ˣ
```

**Шаг 3: Третья производная**
```
y'' = 9e³ˣ
y''' = 9 · e³ˣ · 3 = 27e³ˣ
```

**Шаг 4: Замечаем закономерность**
```
y⁽ⁿ⁾ = 3ⁿ · e³ˣ
```

## 2. ФОРМУЛА ЛЕЙБНИЦА ДЛЯ ПРОИЗВОДНОЙ ПРОИЗВЕДЕНИЯ

### 2.1. Общая формула

$(uv)^{(n)} = \sum_{k=0}^{n} C_n^k u^{(n-k)} v^{(k)}$

где $C_n^k = \frac{n!}{k!(n-k)!}$ - биномиальные коэффициенты

### 2.2. Подробный пример

**Пример 4:** Найти третью производную y = x²·eˣ

**Решение:**

**Шаг 1: Определяем u и v**
```
u = x², v = eˣ
```

**Шаг 2: Находим производные u и v**
```
u = x²      u' = 2x      u'' = 2      u''' = 0
v = eˣ      v' = eˣ      v'' = eˣ     v''' = eˣ
```

**Шаг 3: Применяем формулу Лейбница для n=3**
```
(uv)''' = C₃⁰·u'''·v + C₃¹·u''·v' + C₃²·u'·v'' + C₃³·u·v'''
```

**Шаг 4: Вычисляем биномиальные коэффициенты**
```
C₃⁰ = 1, C₃¹ = 3, C₃² = 3, C₃³ = 1
```

**Шаг 5: Подставляем значения**
```
(uv)''' = 1·0·eˣ + 3·2·eˣ + 3·2x·eˣ + 1·x²·eˣ
        = 0 + 6eˣ + 6xeˣ + x²eˣ
        = eˣ(x² + 6x + 6)
```

**Ответ:** y''' = eˣ(x² + 6x + 6)

## 3. ДИФФЕРЕНЦИАЛЫ ВЫСШИХ ПОРЯДКОВ

### 3.1. Основные понятия

**Первый дифференциал:** dy = f'(x)dx

**Второй дифференциал:** d²y = d(dy) = f''(x)(dx)²

**n-й дифференциал:** $d^ny = f^{(n)}(x)(dx)^n$

### 3.2. Подробный пример

**Пример 5:** Найти первый и второй дифференциал функции y = x³ - 2x

**Решение:**

**Шаг 1: Находим производные**
```
y = x³ - 2x
y' = 3x² - 2
y'' = 6x
```

**Шаг 2: Первый дифференциал**
```
dy = y'dx = (3x² - 2)dx
```

**Шаг 3: Второй дифференциал**
```
d²y = y''(dx)² = 6x(dx)²
```

**Ответ:** dy = (3x² - 2)dx, d²y = 6x(dx)²

### 3.3. Важное замечание!

**Дифференциалы высших порядков НЕ ИНВАРИАНТНЫ!**

Это значит, что формула d²y = f''(x)(dx)² работает только когда x - независимая переменная.

## 4. ПРОИЗВОДНЫЕ НЕЯВНЫХ ФУНКЦИЙ

### 4.1. Метод вычисления

**Пример 6:** Найти y'' для функции, заданной неявно: x² + y² = 25

**Решение:**

**Шаг 1: Первая производная (дифференцируем обе части)**
```
x² + y² = 25
2x + 2y·y' = 0
y' = -x/y
```

**Шаг 2: Вторая производная (дифференцируем y')**
```
y' = -x/y
y'' = -[(1·y - x·y')/y²] = -(y - x·y')/y²
```

**Шаг 3: Подставляем y' = -x/y**
```
y'' = -(y - x·(-x/y))/y² = -(y + x²/y)/y² = -(y² + x²)/y³
```

**Шаг 4: Используем x² + y² = 25**
```
y'' = -25/y³
```

**Ответ:** y'' = -25/y³

## 5. ПРОИЗВОДНЫЕ ПАРАМЕТРИЧЕСКИХ ФУНКЦИЙ

### 5.1. Метод вычисления

**Пример 7:** Найти y'' для функции, заданной параметрически:
```
x = t² + 1, y = t³ - 2t
```

**Решение:**

**Шаг 1: Первые производные по параметру**
```
dx/dt = 2t
dy/dt = 3t² - 2
```

**Шаг 2: Первая производная y по x**
```
y' = (dy/dt)/(dx/dt) = (3t² - 2)/(2t)
```

**Шаг 3: Вторая производная**
```
y'' = d(y')/dx = [d(y')/dt] / (dx/dt)
```

**Шаг 4: Находим d(y')/dt**
```
y' = (3t² - 2)/(2t) = (3/2)t - 1/t
d(y')/dt = 3/2 + 1/t²
```

**Шаг 5: Вычисляем y''**
```
y'' = (3/2 + 1/t²) / (2t) = (3/2 + 1/t²)/(2t)
```

**Ответ:** y'' = $\frac{3t² + 2}{4t³}$

## 6. ФИЗИЧЕСКИЙ СМЫСЛ ПРОИЗВОДНЫХ ВЫСШИХ ПОРЯДКОВ

### 6.1. Механика
- s(t) - положение
- v(t) = s'(t) - скорость
- a(t) = s''(t) - ускорение
- j(t) = s'''(t) - рывок

### 6.2. Экономика
- C(x) - функция затрат
- C'(x) - предельные затраты
- C''(x) - скорость изменения предельных затрат
