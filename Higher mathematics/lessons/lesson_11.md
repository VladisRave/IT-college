# **Дифференциальное исчисление функций нескольких переменных. Предел и непрерывность**

### **Часть 1: Введение**

#### **1.1 Что такое функция нескольких переменных?**

**Одномерный случай** (вспомним):
$$y = f(x) \quad \text{— одна переменная } x$$

**Многомерный случай** (новое!):
$$z = f(x, y) \quad \text{— две переменные } x, y$$
$$u = f(x, y, z) \quad \text{— три переменные}$$
$$w = f(x_1, x_2, ..., x_n) \quad \text{— n переменных}$$

**Геометрический смысл:**
- $z = f(x, y)$ — это **ПОВЕРХНОСТЬ** в трёхмерном пространстве
- Пример: $z = x^2 + y^2$ — параболоид (чашка)

#### **1.2 Примеры из жизни**

1. **Температура в комнате:** $T = T(x, y, z)$ — зависит от трёх координат
2. **Прибыль компании:** $P = P(цена, объём_продаж, затраты)$
3. **Расстояние до точки:** $d = \sqrt{x^2 + y^2 + z^2}$

**Практический пример 1:** Построим график $z = \sqrt{1 - x^2 - y^2}$
- Это **полусфера** радиусом 1
- Область определения: $x^2 + y^2 \leq 1$ (круг!)

### **Часть 2: Предел функции нескольких переменных**

#### **2.1 Понятие предела (аналогия с 1D)**

**В одномерном случае:**
$$\lim_{x \to a} f(x) = L$$
Приближаемся к точке $a$ **по прямой** (слева и справа)

**В многомерном случае:**
$$\lim_{(x,y) \to (a,b)} f(x,y) = L$$
Приближаемся к точке $(a,b)$ **по бесконечному количеству путей**!

#### **2.2 Формальное определение**

Функция $f(x,y)$ имеет предел $L$ в точке $(a,b)$, если:
> Для любой последовательности точек $(x_n, y_n)$, стремящейся к $(a,b)$, значения $f(x_n, y_n)$ стремятся к $L$

**Математически:**
$$\forall \epsilon > 0 \quad \exists \delta > 0:$$
$$0 < \sqrt{(x-a)^2 + (y-b)^2} < \delta \Rightarrow |f(x,y) - L| < \epsilon$$

**Простыми словами:** Как бы близко мы ни хотели подойти к значению $L$, мы можем найти такую окрестность точки $(a,b)$, где все значения функции будут близки к $L$.

#### **2.3 Подход по разным путям — главный метод!**

**Ключевая идея:** Если предел существует, то он должен быть **одинаковым** при приближении по любому пути.

**Пути приближения:**
- По прямым: $y = kx$
- По параболам: $y = kx^2$
- По осям: $x = 0$ или $y = 0$

#### **2.4 Примеры вычисления пределов**

**Пример 2:** Исследуем $\lim_{(x,y) \to (0,0)} \frac{xy}{x^2 + y^2}$

1. **По оси OX** ($y = 0$): 
   $$f(x,0) = \frac{x\cdot 0}{x^2 + 0} = 0 \to 0$$

2. **По прямой** $y = x$:
   $$f(x,x) = \frac{x\cdot x}{x^2 + x^2} = \frac{x^2}{2x^2} = \frac{1}{2} \to \frac{1}{2}$$

**Вывод:** Предел **не существует**, так как при разных путях получаем разные значения!

**Пример 3:** Исследуем $\lim_{(x,y) \to (0,0)} \frac{x^2y}{x^4 + y^2}$

1. **По оси OX** ($y = 0$): $f(x,0) = 0 \to 0$
2. **По параболе** $y = x^2$:
   $$f(x,x^2) = \frac{x^2\cdot x^2}{x^4 + (x^2)^2} = \frac{x^4}{2x^4} = \frac{1}{2} \to \frac{1}{2}$$

**Вывод:** Предел **не существует**!

### **Часть 3: Непрерывность**

#### **3.1 Определение непрерывности**

Функция $f(x,y)$ **непрерывна** в точке $(a,b)$, если:
1. $f(a,b)$ **определена**
2. $\lim_{(x,y) \to (a,b)} f(x,y)$ **существует**
3. $\lim_{(x,y) \to (a,b)} f(x,y) = f(a,b)$

**Геометрически:** Поверхность не имеет "разрывов", "дырок" или "скачков" в этой точке.

#### **3.2 Примеры непрерывных и разрывных функций**

**Непрерывные:**
- Многочлены: $f(x,y) = x^2 + 2xy + y^3$
- Экспоненты: $f(x,y) = e^{x+y}$
- Тригонометрические: $f(x,y) = \sin(xy)$

**Разрывные:**
- Дробные функции, где знаменатель обращается в 0
- Функции с разными пределами по разным путям

#### **3.3 Классификация точек разрыва**

1. **Устранимый разрыв:** предел существует, но не равен значению функции
2. **Неустранимый разрыв:** предел не существует

**Пример 4:** $f(x,y) = \frac{\sin(x^2 + y^2)}{x^2 + y^2}$ в точке $(0,0)$
- Предел существует и равен 1
- Если доопределить $f(0,0) = 1$, функция станет непрерывной

#### **3.4 Теоремы о непрерывных функциях**

1. **Сумма, разность, произведение, частное** непрерывных функций непрерывны
2. **Композиция** непрерывных функций непрерывна
3. **Теорема Вейерштрасса:** Непрерывная функция на замкнутом ограниченном множестве достигает своих наибольшего и наименьшего значений

### **Часть 4: Решение задач**

#### **4.1 Разбор практических заданий**

**Решение задания 1:**
1. $\lim_{(x,y) \to (0,0)} \frac{x^2 - y^2}{x^2 + y^2}$
   - По оси OX: $f(x,0) = 1$
   - По оси OY: $f(0,y) = -1$
   - **Предел не существует**

2. $\lim_{(x,y) \to (0,0)} \frac{xy^2}{x^2 + y^4}$
   - По $y = kx$: предел 0
   - По $x = y^2$: $f(y^2,y) = \frac{y^2\cdot y^2}{y^4 + y^4} = \frac{1}{2}$
   - **Предел не существует**

3. $\lim_{(x,y) \to (0,0)} \frac{\sin(x^2 + y^2)}{x^2 + y^2}$
   - Замена $t = x^2 + y^2$, тогда $\lim_{t \to 0} \frac{\sin t}{t} = 1$
   - **Предел существует и равен 1**

#### **4.2 Ключевые выводы**

1. **Функции нескольких переменных** — это поверхности в пространстве
2. **Предел** существует, если все пути дают одинаковый результат
3. **Непрерывность** означает отсутствие разрывов и скачков
4. **Метод исследования:** проверка по разным путям!
