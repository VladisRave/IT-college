### **Часть 1: Задания для отработки в классе (20 задач)**

#### **Блок А: Производная функции (10 задач)**

**Цель:** Отработка техники дифференцирования.

1.  Найти производную функции: $f(x) = 3x^4 - 5x^3 + 2x - 7$
2.  Найти производную функции: $f(x) = \frac{2x^2 - 1}{x^3}$
3.  Найти производную функции: $f(x) = e^{2x} \cdot \sin(x)$
4.  Найти производную функции: $f(x) = \ln(5x^2 + 1)$
5.  Найти производную функции: $f(x) = \sqrt{1 + 4x^2}$
6.  Найти производную функции, используя логарифмическое дифференцирование: $f(x) = x^{\cos(x)}$ (при $x > 0$)
7.  Найти производную второго порядка для функции: $y = x^3 - \frac{1}{x}$
8.  Найти дифференциал $dy$ функции: $y = \arctg(3x)$
9.  Найти уравнение касательной к графику функции $y = x^2 - 4x + 5$ в точке $x_0 = 3$.
10. Показать, что функция $y = e^{2x} + e^{-3x}$ удовлетворяет соотношению $y'' + y' - 6y = 0$.

#### **Блок Б: Интегралы (10 задач)**

**Цель:** Отработка техники интегрирования.

1.  Найти неопределенный интеграл: $\int (4x^3 - 3x^2 + 2x - 1)  dx$
2.  Найти неопределенный интеграл: $\int \frac{2x - 3}{x^2}  dx$
3.  Найти неопределенный интеграл: $\int \cos(3x)  dx$
4.  Найти неопределенный интеграл: $\int e^{-x}  dx$
5.  Найти неопределенный интеграл: $\int \frac{2x}{x^2 + 1}  dx$
6.  Найти неопределенный интеграл, используя метод подстановки: $\int x \cdot \sqrt{x^2 + 4}  dx$
7.  Найти неопределенный интеграл, используя метод интегрирования по частям: $\int x \cdot e^{x}  dx$
8.  Вычислить определенный интеграл: $\int_{1}^{2} (x^2 + \frac{1}{x^2})  dx$
9.  Вычислить определенный интеграл: $\int_{0}^{\pi} \sin(x)  dx$
10. Вычислить определенный интеграл: $\int_{1}^{e} \frac{\ln(x)}{x}  dx$

### **Часть 2: Домашнее задание (10 комплексных задач)**

**Цель:** Проверка понимания всех пройденных разделов.

1.  **(Пределы)** Вычислить предел, используя замечательные пределы: $\lim_{x \to 0} \frac{\sin(5x)}{2x}$
2.  **(Пределы)** Вычислить предел, раскрывая неопределенность: $\lim_{x \to 3} \frac{x^2 - 9}{x - 3}$
3.  **(Односторонние пределы)** Для функции $f(x) = \begin{cases} x^2 + 1, & \text{если } x < 2 \\ 5, & \text{если } x = 2 \\ 2x + 1, & \text{если } x > 2 \end{cases}$
    а) Найти $\lim_{x \to 2^-} f(x)$
    б) Найти $\lim_{x \to 2^+} f(x)$
    в) Существует ли $\lim_{x \to 2} f(x)$?
4.  **(Точки разрыва)** Исследовать функцию на непрерывность и найти точки разрыва, если они есть: $f(x) = \frac{1}{x - 4}$. Указать тип разрыва.
5.  **(Точки разрыва)** Для функции $f(x) = \frac{x^2 - 1}{x - 1}$ установить, является ли точка $x = 1$ точкой разрыва. Если да, то какого типа? Можно ли доопределить функцию, чтобы она стала непрерывной?
6.  **(Производная)** Найти производную функции: $f(x) = \sqrt[3]{x} + \frac{1}{\sqrt{x}}$. (Преобразовать к виду $x^{1/3} + x^{-1/2}$)
7.  **(Производная)** Найти производную сложной функции: $f(x) = \cos^2(3x)$
8.  **(Интеграл)** Найти неопределенный интеграл: $\int (2x - 1)^5  dx$
9.  **(Интеграл)** Вычислить определенный интеграл: $\int_{0}^{1} (e^x + x^2)  dx$
10. **(Исследование функции)** Найти интервалы возрастания и убывания функции $f(x) = x^3 - 3x^2$.
