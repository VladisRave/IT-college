# **Скалярное, векторное и смешанное произведения векторов**
 
**Введение:** Мы умеем складывать векторы и умножать их на число. Но как «умножить» вектор на вектор? Оказывается, есть три разных способа, и каждый дает свой уникальный результат (число или вектор).

**1. Скалярное произведение (Dot product)**
*   **Обозначение:** `𝑎⃗ · 𝑏⃗` (читается «а точка б»).
*   **Результат:** **Скаляр** (число)!
*   **Определение (геометрическое):** `𝑎⃗ · 𝑏⃗ = |𝑎⃗| * |𝑏⃗| * cos(φ)`, где `φ` — угол между векторами.
*   **Физический смысл:** Работа силы `𝐹⃗` по перемещению `𝑆⃗`: `A = 𝐹⃗ · 𝑆⃗ = F * S * cos(φ)`.
*   **Свойства:**
    *   Коммутативно: `𝑎⃗ · 𝑏⃗ = 𝑏⃗ · 𝑎⃗`.
    *   Дистрибутивно: `𝑎⃗ · (𝑏⃗ + 𝑐⃗) = 𝑎⃗ · 𝑏⃗ + 𝑎⃗ · 𝑐⃗`.
    *   **Важный частный случай:** Если векторы перпендикулярны (φ=90°, cos=0), то их скалярное произведение **равно нулю**. Это главный признак перпендикулярности!
*   **Вычисление в координатах (самое удобное!):**
    Если `𝑎⃗ = (a_x, a_y, a_z)`, `𝑏⃗ = (b_x, b_y, b_z)`, то:
    `𝑎⃗ · 𝑏⃗ = a_x*b_x + a_y*b_y + a_z*b_z`.
    *Пример:* `𝑎⃗=(1,2,3), 𝑏⃗=(4,5,6)`. `𝑎⃗·𝑏⃗ = 1*4 + 2*5 + 3*6 = 4+10+18 = 32`.

**2. Векторное произведение (Cross product)**
*   **Обозначение:** `𝑎⃗ × 𝑏⃗` или `[𝑎⃗, 𝑏⃗]`.
*   **Результат:** **Новый вектор!**
*   **Определение (геометрическое):** Вектор `𝑐⃗ = 𝑎⃗ × 𝑏⃗` такой, что:
    1.  **Длина:** |`𝑐⃗`| = |`𝑎⃗`| * |`𝑏⃗`| * sin(φ). Это численно равно **площади параллелограмма**, построенного на векторах `𝑎⃗` и `𝑏⃗`.
    2.  **Направление:** `𝑐⃗` **перпендикулярен** плоскости векторов `𝑎⃗` и `𝑏⃗`. Направление определяется **правилом правой руки** или **правилом буравчика**: если вращать первый вектор (`𝑎⃗`) ко второму (`𝑏⃗`) по кратчайшему пути, то `𝑐⃗` будет смотреть туда, куда движется буравчик с правой резьбой.
*   **Физический смысл:** Момент силы `𝑀⃗ = 𝑟⃗ × 𝐹⃗`, где `𝑟⃗` — радиус-вектор от точки вращения к точке приложения силы.
*   **Свойства:**
    *   **Антикоммутативно:** `𝑎⃗ × 𝑏⃗ = - (𝑏⃗ × 𝑎⃗)` (направление меняется на противоположное!).
    *   Дистрибутивно.
    *   Если векторы коллинеарны (φ=0° или 180°, sin=0), их векторное произведение — **нулевой вектор**. Это признак коллинеарности.
*   **Вычисление в координатах (через определитель):**
    Для `𝑎⃗=(a_x, a_y, a_z)`, `𝑏⃗=(b_x, b_y, b_z)`:
    ```
    𝑎⃗ × 𝑏⃗ = | 𝑖⃗    𝑗⃗    𝑘⃗  |
               | a_x   a_y   a_z |
               | b_x   b_y   b_z |
    ```
    Раскрываем этот определитель по первой строке:
    `𝑐⃗ = (a_y*b_z - a_z*b_y)*𝑖⃗ - (a_x*b_z - a_z*b_x)*𝑗⃗ + (a_x*b_y - a_y*b_x)*𝑘⃗`.
    Или проще: `𝑐⃗ = (a_y*b_z - a_z*b_y; a_z*b_x - a_x*b_z; a_x*b_y - a_y*b_x)`.
    *Пример:* `𝑎⃗=(1,2,3), 𝑏⃗=(4,5,6)`. `𝑐⃗ = (2*6-3*5; 3*4-1*6; 1*5-2*4) = (-3; 6; -3)`.

**3. Смешанное произведение (Triple product)**
*   **Обозначение:** `(𝑎⃗, 𝑏⃗, 𝑐⃗)` или `𝑎⃗ · (𝑏⃗ × 𝑐⃗)`.
*   **Результат:** **Скаляр** (число)!
*   **Геометрический смысл:** Это число по модулю равно **объему параллелепипеда**, построенного на векторах `𝑎⃗, 𝑏⃗, 𝑐⃗`. Знак показывает ориентацию тройки векторов («правая» или «левая»).
*   **Признак компланарности:** Если `(𝑎⃗, 𝑏⃗, 𝑐⃗) = 0`, то векторы компланарны (лежат в одной плоскости).
*   **Вычисление в координатах (через определитель матрицы из координат):**
    `(𝑎⃗, 𝑏⃗, 𝑐⃗) = | a_x  a_y  a_z |
                   | b_x  b_y  b_z |
                   | c_x  c_y  c_z |`.

**Вывод:** Три вида произведений — три разных инструмента. Скалярное определяет «сонаправленность», векторное — «перпендикулярность» и площадь, смешанное — объем и компланарность. Координатные формулы — наш главный вычислительный инструмент.
