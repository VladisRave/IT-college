# **Диффиренцируемый зачет по предмету "Введение в язык программирования Python"**

Данный документ содержит перечень всех тем, знание которых необходимо для успешной сдачи экзамена. Материалы по темам вы можете найти в конспектах лекций в папке **`lessons`**.

### **Глава 1: Введение в программирование и Python**
*   Основные парадигмы программирования (процедурная, объектно-ориентированная).
*   Краткий обзор современных языков программирования.
*   История, особенности и философия языка Python.
*   Сферы применения Python (веб-разработка, data science, автоматизация и др.).

### **Глава 2: Основы алгоритмизации**
*   Понятие алгоритма. Свойства алгоритмов.
*   Типы алгоритмических структур: линейные, ветвящиеся, циклические.
*   Представление алгоритмов с помощью блок-схем.
*   Базовые элементы блок-схем (начало/конец, процесс, решение, ввод/вывод).
*   Разработка простых алгоритмов и их отображение в виде блок-схем.

### **Глава 3: Начало работы с Python**
*   Установка интерпретатора Python.
*   Знакомство со средами разработки (IDE):
    *   **Основные для изучения:** Visual Studio Code, PyCharm.
    *   Другие: IDLE (стандартная), Spyder, Atom.
*   Запуск скриптов и работа в интерактивном режиме (Python Shell).

### **Глава 4: Базовый синтаксис Python**
*   Переменные: определение, именование, создание, динамическая типизация.
*   Основные встроенные типы данных: `int`, `float`, `str`, `bool`.
*   Операторы: арифметические, сравнения, логические, присваивания.
*   Приоритет операций.
*   Функции ввода (`input()`) и вывода (`print()`).
*   Преобразование типов данных (`int()`, `str()`, `float()`).
*   Основные синтаксические ошибки.

### **Глава 5: Управление ходом выполнения программы**
*   **Условные операторы:**
    *   Конструкции `if`, `if-else`, `if-elif-else`.
    *   Логические выражения.
*   **Циклы:**
    *   Цикл `while`. Понятие итерации и условия остановки.
    *   Цикл `for`. Итерирование по последовательностям и функция `range()`.
    *   Управление циклами: операторы `break` и `continue`.
    *   Вложенные циклы.

### **Глава 6: Структуры данных в Python**
*   **Строки (`str`):**
    *   Создание, индексация, срезы.
    *   Основные методы строк.
    *   Экранированные последовательности.
*   **Списки (`list`):**
    *   Создание, индексация, изменение элементов.
    *   Основные методы списков (добавление, удаление, поиск).
    *   Генераторы списков (list comprehension) — базовое понятие.
*   Понятие о кортежах (`tuple`), словарях (`dict`) и множествах (`set`) (если изучались).
*   Ключевое различие: **изменяемые** (mutable) и **неизменяемые** (immutable) типы данных.

### **Глава 7: Функции**
*   Понятие функции. Определение функций с помощью `def`.
*   Аргументы функции (позиционные, ключевые).
*   Возвращение значения (`return`).
*   Понятие области видимости переменных: **локальные** и **глобальные** переменные.
*   Зачем нужны функции (переиспользование кода, структурирование).

### **Глава 8: Обработка исключений и кодировки**
*   Обработка ошибок времени выполнения с помощью `try...except`.
*   Базовое понимание кодировок текста: `ASCII`, `Unicode (UTF-8)`.
