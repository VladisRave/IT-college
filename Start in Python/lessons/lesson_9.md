# **Вложенные циклы и управление выполнением в Python**

## Теоретическая часть

### Вложенные циклы

**Вложенный цикл** — это цикл, расположенный внутри тела другого цикла. Каждый раз, когда внешний цикл выполняется один раз, внутренний цикл выполняется полностью.

```python
# Базовый пример вложенных циклов
for i in range(3):
    print(f"Внешний цикл: i = {i}")
    for j in range(2):
        print(f"  Внутренний цикл: j = {j}")
```

**Ключевой момент:** Количество итераций внутреннего цикла умножается на количество итераций внешнего цикла. Для примера выше: 3 × 2 = 6 итераций.

### Практическое применение: Генерация комбинаций

```python
# Генерация всех двухбуквенных комбинаций
for first_letter in 'abc':
    for second_letter in 'xyz':
        print(f"{first_letter}{second_letter}")
```

### Оператор break

Оператор `break` используется для немедленного прерывания выполнения цикла.

```python
# Поиск первого числа, делящегося на 7 и 3
for number in range(1, 101):
    if number % 7 == 0 and number % 3 == 0:
        print(f"Найдено число: {number}")
        break
```

### Управление вложенными циклами с помощью флагов

Когда `break` используется во вложенном цикле, он прерывает только внутренний цикл. Для остановки внешнего цикла используются флаги.

```python
# Поиск определенной комбинации с остановкой обоих циклов
found = False

for i in range(5):
    for j in range(5):
        combination = f"{i}-{j}"
        print(f"Проверяем: {combination}")
        
        if combination == "2-3":
            print("Комбинация найдена!")
            found = True
            break  # Прерываем внутренний цикл
    
    if found:
        break  # Прерываем внешний цикл
```

### Оператор continue

Оператор `continue` пропускает оставшуюся часть текущей итерации и переходит к следующей.

```python
# Вывод только нечетных чисел
for i in range(1, 11):
    if i % 2 == 0:
        continue  # Пропускаем четные числа
    print(f"Нечетное число: {i}")
```

### Оператор else в циклах

Блок `else` выполняется после нормального завершения цикла (без использования `break`).

```python
# Проверка на простое число
number = 13

for divisor in range(2, number):
    if number % divisor == 0:
        print(f"{number} не является простым числом")
        break
else:
    print(f"{number} - простое число")
```

## Продвинутые техники

### Оптимизация вложенных циклов

```python
# Неоптимизированный подход
for i in range(1000):
    for j in range(1000):
        # Медленные операции
        result = i * j

# Более оптимальный подход (если применимо)
for i in range(1000):
    temp = i  # Вынесение вычислений из внутреннего цикла
    for j in range(1000):
        result = temp * j
```

### Использование вложенных циклов с while

```python
# Комбинация for и while
rows = 3
cols = 4

for i in range(rows):
    j = 0
    while j < cols:
        print(f"Позиция: ({i}, {j})")
        j += 1
```

## Типичные ошибки и их решение

### Бесконечные циклы

```python
# Ошибка: потенциально бесконечный цикл
i = 0
while i < 5:
    j = 0
    while j < 3:
        print(i, j)
        # Забыли увеличить j!
    i += 1

# Правильный вариант:
i = 0
while i < 5:
    j = 0
    while j < 3:
        print(i, j)
        j += 1  # Не забываем увеличивать счетчик
    i += 1
```

### Неправильное использование break

```python
# Неправильно: break только во внутреннем цикле
for i in range(5):
    for j in range(5):
        if i * j > 10:
            print("Найдено!")
            break  # Прервется только внутренний цикл

# Правильно: использование флага
stop_search = False
for i in range(5):
    if stop_search:
        break
    for j in range(5):
        if i * j > 10:
            print("Найдено!")
            stop_search = True
            break
```

## Заключение

**Ключевые принципы работы с вложенными циклами:**

1. Внутренний цикл выполняется полностью для каждой итерации внешнего цикла
2. `break` прерывает только текущий цикл
3. Флаги необходимы для координации между вложенными циклами
4. `continue` пропускает текущую итерацию, но не завершает цикл
5. Блок `else` выполняется только при нормальном завершении цикла
