## **Часть 1: Фундамент. Протокол HTTP**

Чтобы программы поняли друг друга, им нужны четкие правила — **протоколы**. Самый распространенный для веба — **HTTP (HyperText Transfer Protocol)**.

**Аналогия с рестораном:**
Представьте, что вы в ресторане (**Клиент**). Вы хотите сделать заказ.
1.  **Вы формируете запрос:** «Я хочу борщ и стейк средней прожарки» (это ваш **HTTP-запрос**).
2.  **Вы говорите официанту (браузеру/программе):** «Передайте, пожалуйста, этот заказ на кухню».
3.  **Кухня (Сервер)** получает заказ, готовит и через официанта дает **ответ**.
4.  **Ответ состоит из:**
    *   **Само блюдо (тело ответа):** Тарелка с едой (это могут быть HTML-страница, картинка, данные в формате JSON).
    *   **Устный комментарий (заголовки и статус):** «Ваш борщ, приятного аппетита!» или «Извините, стейк закончился».

### **Методы HTTP-запросов**
В HTTP есть разные «типы заказов» — **методы**:
*   **`GET`** — «Принеси мне что-то». Самый частый. Получить страницу, картинку, данные. (Пример: ввести адрес в браузере).
*   **`POST`** — «Вот тебе данные, обработай их». Отправить форму логина, загрузить файл.
*   **`PUT`/`DELETE`** — «Создай новое» или «Удали что-то».

### **Коды состояния HTTP**
А как понять, что ответил сервер? По **кодам состояния** (Status Code). Это трехзначные числа:
*   **2xx — Успех!** `200 OK` — всё идеально, ваш заказ выполнен.
*   **3xx — Перенаправление.** «Ваш заказ теперь готовят на другом филиале нашей кухни, следуйте за мной».
*   **4xx — Ошибка клиента.** `404 Not Found` — «Такого блюда (страницы) у нас в меню нет». `403 Forbidden` — «У вас нет прав заказывать это».
*   **5xx — Ошибка сервера.** `500 Internal Server Error` — «На нашей кухне пожар, приходите позже».

**Вывод:** HTTP — это язык «запрос-ответ» для общения между клиентом и сервером.

## **Часть 2: API — «Меню» для программ**

Итак, мы можем делать HTTP-запросы. Но куда именно? Как узнать, какой адрес «попросить погоду»?

Для этого сервисы предоставляют **API (Application Programming Interface)** — **программный интерфейс приложения**. Это такое **меню** или **инструкция**.

*   **В меню ресторана** написано: «Борщ — 300р. Стейк — 700р». Вы знаете, что нужно сказать официанту, чтобы получить нужное.
*   **В API Яндекс.Карт** написано: «Хочешь получить карту? Отправь GET-запрос на адрес `https://static-maps.yandex.ru/1.x/` и передай в параметрах `ll` (координаты) и `l` (тип карты)».

API скрывает от нас сложную внутреннюю кухню сервиса (как там рендерятся карты, где лежат файлы). Мы просто делаем запрос по правилам из «меню» и получаем готовый результат.

### **Пример API-запроса в браузере**
Давайте посмотрим на живой пример. Вот URL для API статических карт Яндекса:
`https://static-maps.yandex.ru/1.x/?ll=37.6173,55.7558&spn=0.1,0.1&l=map`
*   Адрес API: `https://static-maps.yandex.ru/1.x/`
*   Параметры после `?`:
    *   `ll=37.6173,55.7558` — долгота и широта центра (Москва).
    *   `spn=0.1,0.1` — размер области.
    *   `l=map` — тип «схема».

**Если вставить эту ссылку в браузер, вы получите не страницу, а просто картинку с картой!** Браузер сделал GET-запрос, а API вернул изображение. Теперь научимся делать то же самое из Python.

## **Часть 3: Практика с `requests`. GET-запрос к картам**

### **Установка и импорт**
Сначала установим нашего «почтальона». В терминале (командной строке):
```bash
pip install requests
```

В программе импортируем его:
```python
import requests # Импортируем всю библиотеку
# или
from requests import get # Импортируем только функцию get
```

### **Простейший GET-запрос**
Давайте «переведем» тот запрос из браузера на Python.

```python
from requests import get

# Формируем URL с параметрами вручную (как длинная строка)
url = "https://static-maps.yandex.ru/1.x/?ll=37.6173,55.7558&spn=0.1,0.1&l=map"
response = get(url) # Отправляем GET-запрос

print(response) # Что это?
# Вывод: <Response [200]>
```

`response` — это объект, содержащий весь ответ сервера. `[200]` — отличная новость, запрос успешен!

### **Извлекаем полезные данные**
Что полезного в этом ответе?
1.  **Статус-код:** `response.status_code` (число 200).
2.  **Заголовки ответа:** `response.headers` (информация о типе данных, кодировке и т.д.).
3.  **Тело ответа (самые важные данные):**
    *   `response.text` — если сервер вернул текст (HTML, JSON).
    *   `response.content` — если сервер вернул «бинарные» данные (картинку, PDF, архив). Это последовательность байтов.

Наш API вернул картинку (PNG). Сохраним ее.

```python
# Проверяем, что запрос был успешным
if response.status_code == 200:
    # Открываем файл для записи в бинарном режиме ('wb')
    with open('moscow_map.png', 'wb') as file:
        file.write(response.content) # Записываем байты картинки в файл
    print("Карта сохранена как 'moscow_map.png'!")
else:
    print("Ошибка! Код:", response.status_code)
```

### **Улучшаем код. Параметры и обработка ошибок**
Формировать URL строкой неудобно. Библиотека `requests` позволяет передавать параметры отдельным словарем.

```python
params = {
    'll': '37.6173,55.7558',
    'spn': '0.1,0.1',
    'l': 'map'
}
# Теперь код чище и параметры легче менять
response = get('https://static-maps.yandex.ru/1.x/', params=params)
```

**Что, если интернет отвалился?** Наш код упадет с ошибкой. Обработаем это!

```python
from requests import get, ConnectionError

try:
    response = get('https://static-maps.yandex.ru/1.x/', params=params, timeout=5)
except ConnectionError:
    print("Не удалось подключиться к интернету. Проверьте сеть.")
except Timeout:
    print("Сервер слишком долго не отвечает.")
else:
    # Этот блок выполнится, если ошибок не было
    if response.status_code == 200:
        with open('map.png', 'wb') as f:
            f.write(response.content)
```

## **Часть 4: Безопасный доступ. Авторизация и OAuth 2.0**

### **Зачем нужна авторизация?**
С картами мы работали анонимно. Но чтобы работать с личными данными (вашей почтой, облаком), нужно **доказать сервису, что вы это вы**.

**Плохой способ:** Спросить у пользователя логин и пароль и сохранить их в своей программе. **ОЧЕНЬ ОПАСНО!** Вы берете на себя огромную ответственность.

### **Принцип OAuth 2.0 на примере пропуска**
**Хороший способ — OAuth 2.0.** Аналогия:
1.  Вы (Пользователь) приходите на охраняемый объект (Яндекс.Диск).
2.  Охранник (Сервис Яндекса) не пускает.
3.  Вы звоните своему доверенному агенту (Ваше приложение) и говорите: «Дай мне доступ к моим файлам».
4.  Агент идет к охраннику и говорит: «Я представляю пользователя, вот мои документы (Client ID и Secret)».
5.  Охранник: «Хорошо, пусть пользователь *лично* подтвердит, что доверяет тебе». Вы подтверждаете в всплывающем окне Яндекса.
6.  Охранник выдает агенту **временный пропуск (Access Token)**. Не логин и пароль, а именно пропуск с ограниченными правами и сроком действия!
7.  Агент (ваша программа) теперь может ходить на объект, показывая только этот **токен** в заголовке `Authorization: OAuth <ваш_токен>`.

**Итог:** Пользователь никогда не отдает вам пароль. Он дает разрешение *сервису* выдать вашему приложению временный ключ.

## **Часть 5: Практика с API Яндекс.Диска**

### **Получение информации о диске**
Допустим, у нас уже есть токен (как его получить — отдельная процедура, описанная в вашем тексте). Покажем, как его использовать.

```python
import requests

ACCESS_TOKEN = 'ваш_секретный_токен_здесь'  # Храните его в безопасности!
headers = {'Authorization': f'OAuth {ACCESS_TOKEN}'}

# 1. Запрос информации о диске
response = requests.get('https://cloud-api.yandex.net/v1/disk', headers=headers)
if response.status_code == 200:
    disk_info = response.json() # Преобразуем ответ JSON в словарь Python
    print(f"Всего места: {disk_info['total_space'] // (1024**3)} Гб")
    print(f"Свободно: {disk_info['free_space'] // (1024**3)} Гб")
```

### **Создание папки и загрузка файла**

```python
# 2. Создаем папку на Диске
params = {'path': '/my_python_folder'}  # Путь в корне диска
response = requests.put('https://cloud-api.yandex.net/v1/disk/resources',
                         headers=headers,
                         params=params)
print(f"Создание папки: {response.status_code}")  # 201 - создано

# 3. Загружаем нашу карту в созданную папку
# Сначала получаем ссылку для загрузки
params = {'path': '/my_python_folder/moscow_map.png'}
response = requests.get('https://cloud-api.yandex.net/v1/disk/resources/upload',
                         headers=headers,
                         params=params)
upload_url = response.json().get('href')  # Временный URL для PUT-запроса

# Теперь загружаем файл по полученной ссылке
with open('moscow_map.png', 'rb') as f:
    file_data = f.read()
response = requests.put(upload_url, data=file_data)  # Отправляем файл
print(f"Загрузка файла: {response.status_code}")  # 201 - файл загружен
```
