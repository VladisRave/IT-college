# Работа с файлами и JSON в Python

## 1. Зачем нужно работать с файлами?

**Проблема:** Когда программа завершает работу, все данные в переменных исчезают.

**Решение:** Сохранять данные в файлы!

**Примеры из жизни:**
- Игра - сохранить прогресс
- Приложение - сохранить настройки  
- Программа - записать результаты работы

---

## 2. Самый простой способ - текстовые файлы

### Чтение файла
```python
# Открываем файл для чтения
file = open("мой_файл.txt", "r", encoding="utf-8")
content = file.read()  # Читаем всё содержимое
file.close()           # Закрываем файл

print(content)
```

### Запись в файл
```python
# Открываем файл для записи
file = open("результат.txt", "w", encoding="utf-8")
file.write("Привет, это мой первый файл!\n")
file.write("Вторая строка файла")
file.close()
```

---

## 3. Проблема и решение: менеджер контекста

### Проблема:
Что если программа упадет с ошибкой до `file.close()`?
```python
file = open("файл.txt", "r")
# Тут может произойти ошибка!
file.read()
file.close()  # Этот код может не выполниться!
```

### Решение - `with`:
```python
with open("файл.txt", "r", encoding="utf-8") as file:
    content = file.read()
# Файл автоматически закроется здесь!
```

**Аналогия:** Как снять деньги в банкомате:
- Без `with`: взять деньги → забыть карту в банкомате
- С `with`: взять деньги → карта автоматически возвращается

## 4. Разные способы чтения файлов

### Способ 1: Прочитать весь файл
```python
with open("данные.txt", "r", encoding="utf-8") as file:
    весь_текст = file.read()
print(весь_текст)
```

### Способ 2: Прочитать построчно
```python
with open("данные.txt", "r", encoding="utf-8") as file:
    for строка in file:
        print(строка.strip())  # strip() убирает лишние пробелы и \n
```

### Способ 3: Прочитать все строки в список
```python
with open("данные.txt", "r", encoding="utf-8") as file:
    строки = file.readlines()
print(строки)  # ['первая строка\n', 'вторая строка\n']
```

## 5. Режимы работы с файлами

```python
# "r" - чтение (файл должен существовать)
with open("файл.txt", "r") as f:
    data = f.read()

# "w" - запись (создает новый или очищает старый)
with open("файл.txt", "w") as f:
    f.write("Новый текст")

# "a" - добавление в конец
with open("файл.txt", "a") as f:
    f.write("\nДобавили эту строку")

# "r+" - чтение и запись
with open("файл.txt", "r+") as f:
    content = f.read()
    f.write("\nДописали в конец")
```

## 6. Что такое JSON и зачем он нужен?

### Проблема с обычными файлами:
```python
# Как сохранить список студентов?
студенты = [
    {"имя": "Анна", "возраст": 20, "оценка": 4.5},
    {"имя": "Борис", "возраст": 21, "оценка": 4.2}
]

# В текстовый файл это сохранить сложно...
```

### Решение - JSON!
JSON позволяет сохранять сложные структуры данных.

**Пример JSON:**
```json
[
    {
        "имя": "Анна",
        "возраст": 20,
        "оценка": 4.5
    },
    {
        "имя": "Борис", 
        "возраст": 21,
        "оценка": 4.2
    }
]
```

## 7. Работа с JSON в Python

### Сохраняем данные в JSON:
```python
import json

студенты = [
    {"имя": "Анна", "возраст": 20, "оценка": 4.5},
    {"имя": "Борис", "возраст": 21, "оценка": 4.2}
]

with open("студенты.json", "w", encoding="utf-8") as file:
    json.dump(студенты, file, ensure_ascii=False, indent=2)
```

**Что делает `ensure_ascii=False`?** - Позволяет сохранять русские буквы
**Что делает `indent=2`?** - Делает файл красивым и читаемым

### Читаем данные из JSON:
```python
import json

with open("студенты.json", "r", encoding="utf-8") as file:
    студенты = json.load(file)

for студент in студенты:
    print(f"{студент['имя']}, {студент['возраст']} лет")
```

## 8. Практические примеры

### Пример 1: Дневник настроения
```python
import json
from datetime import datetime

# Читаем старые записи
try:
    with open("настроение.json", "r", encoding="utf-8") as file:
        записи = json.load(file)
except FileNotFoundError:
    записи = []

# Добавляем новую запись
настроение = input("Какое у вас настроение? ")
новая_запись = {
    "дата": datetime.now().strftime("%d.%m.%Y %H:%M"),
    "настроение": настроение
}
записи.append(новая_запись)

# Сохраняем
with open("настроение.json", "w", encoding="utf-8") as file:
    json.dump(записи, file, ensure_ascii=False, indent=2)

print("Запись сохранена!")
```

### Пример 2: Список дел
```python
import json

def показать_задачи():
    try:
        with open("задачи.json", "r", encoding="utf-8") as file:
            задачи = json.load(file)
    except FileNotFoundError:
        задачи = []
    
    print("\nВаши задачи:")
    for i, задача in enumerate(задачи, 1):
        print(f"{i}. {задача}")

def добавить_задачу():
    задача = input("Введите новую задачу: ")
    
    try:
        with open("задачи.json", "r", encoding="utf-8") as file:
            задачи = json.load(file)
    except FileNotFoundError:
        задачи = []
    
    задачи.append(задача)
    
    with open("задачи.json", "w", encoding="utf-8") as file:
        json.dump(задачи, file, ensure_ascii=False, indent=2)
    
    print("Задача добавлена!")

# Использование
показать_задачи()
добавить_задачу()
```

## 9. Частые ошибки и как их избежать

### Ошибка 1: Файл не найден
```python
# ПЛОХО
file = open("несуществующий_файл.txt", "r")  # Ошибка!

# ХОРОШО
try:
    with open("несуществующий_файл.txt", "r") as file:
        content = file.read()
except FileNotFoundError:
    print("Файл не найден! Создаю новый...")
    with open("несуществующий_файл.txt", "w") as file:
        file.write("")
```

### Ошибка 2: Забыли кодировку
```python
# ПЛОХО (русские буквы превратятся в кракозябры)
with open("файл.txt", "w") as file:
    file.write("Привет")  # Сохранится неправильно

# ХОРОШО
with open("файл.txt", "w", encoding="utf-8") as file:
    file.write("Привет")  # Сохранится правильно
```

### Ошибка 3: Неправильный режим
```python
# ПЛОХО
with open("файл.txt", "r") as file:
    file.write("текст")  # Ошибка! Файл открыт только для чтения

# ХОРОШО
with open("файл.txt", "w") as file:
    file.write("текст")  # Работает! Файл открыт для записи
```

## 10. Итог - золотые правила

1. **Всегда используй `with`** - файл закроется автоматически
2. **Всегда указывай `encoding="utf-8"`** - чтобы русские буквы сохранялись правильно  
3. **Для сложных данных используй JSON** - вместо изобретения своего формата
4. **Обрабатывай ошибки** - с помощью `try/except`

### Шпаргалка:
```python
# Текстовый файл
with open("файл.txt", "r", encoding="utf-8") as f:
    текст = f.read()

with open("файл.txt", "w", encoding="utf-8") as f:
    f.write(текст)

# JSON файл
import json

with open("данные.json", "r", encoding="utf-8") as f:
    данные = json.load(f)

with open("данные.json", "w", encoding="utf-8") as f:
    json.dump(данные, f, ensure_ascii=False, indent=2)
```
