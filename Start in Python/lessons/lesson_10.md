### **1. Что такое коллекции?**

**Коллекция** — это тип данных, который позволяет хранить несколько значений одновременно.

**Упорядоченные коллекции** — это коллекции, где каждый элемент имеет свой порядковый номер (индекс). Сегодня мы разберем три основных типа:
*   **`str` (строка)** — последовательность символов.
*   **`list` (список)** — последовательность элементов любого типа.
*   **`tuple` (кортеж)** — последовательность элементов, похожая на список, но неизменяемая.

### **2. Индексация**

В Python индексация начинается с **0**.

*   **Первый** элемент имеет индекс `0`.
*   **Второй** — `1` и т.д.

**Обращение по индексу:**
```python
text = "Привет"
print(text[0])  # Выведет: П
print(text[2])  # Выведет: и
```

**Отрицательная индексация** (удобно для доступа с конца):
*   **Последний** элемент имеет индекс `-1`.
*   **Предпоследний** — `-2` и т.д.
```python
text = "Привет"
print(text[-1])  # Выведет: т
print(text[-2])  # Выведет: е
```

> **Важно!** Попытка обратиться к индексу, которого нет (например, `text[100]` для короткой строки), вызовет ошибку `IndexError`.

### **3. Проход по коллекциям в цикле**

Есть три основных способа:

**а) Цикл по индексам (когда нужен индекс):**
```python
text = "Мир"
for i in range(len(text)):
    print(f"Индекс: {i}, Символ: {text[i]}")
```

**б) Цикл по значениям (когда индекс не нужен):**
```python
text = "Мир"
for letter in text:
    print(letter)
```

**в) Цикл с `enumerate()` (когда нужен и индекс, и значение):**
```python
text = "Мир"
for i, letter in enumerate(text):
    print(f"Позиция {i}: '{letter}'")
```

### **4. Срезы**

**Срез** — это способ получить часть коллекции. Синтаксис: `[start:stop:step]`

*   `start` — индекс начала (включительно).
*   `stop` — индекс конца (***не включается!***).
*   `step` — шаг (по умолчанию 1).

**Примеры со строкой `text = "Программирование"`:**
```python
print(text[0:6])    # Програм
print(text[:6])     # Програм (начало с 0 можно опустить)
print(text[7:])     # мирование (до конца, если stop не указан)
print(text[::2])    # Порираие (каждый второй символ)
print(text[::-1])   # еоинавиммаргорП (разворот строки)
```

### **5. Строки (`str`) и их методы**

**Главное свойство: строки — НЕИЗМЕНЯЕМЫЕ.**
```python
# Так нельзя!
word = "Кот"
word[0] = "к"  # TypeError: 'str' object does not support item assignment
```

Чтобы изменить строку, нужно создать новую с помощью **методов**. Методы не меняют исходную строку, а возвращают новую.

| Метод | Что делает | Пример |
| :--- | :--- | :--- |
| `.upper()` | Переводит в верхний регистр | `"ПРИВЕТ"` |
| `.lower()` | Переводит в нижний регистр | `"привет"` |
| `.strip()` | Убирает пробелы с обоих концов | `"текст"` |
| `.replace(old, new)` | Заменяет одну подстроку на другую | `"Java".replace("J", "P") -> "Pava"` |
| `.split(разделитель)` | Разбивает строку на список по разделителю | `"a,b,c".split(",") -> ['a','b','c']` |
| `.find(подстрока)` | Ищет подстроку и возвращает её индекс | `"Привет".find("ив") -> 2` |

### **6. Списки (`list`) — изменяемые коллекции**

**Список** может хранить элементы любых типов.

**Создание:**
```python
numbers = [10, 20, 30]
mixed = [1, "текст", 2.5, True]
```

**Изменение элементов:**
```python
numbers = [10, 20, 50]
numbers[2] = 30  # Теперь список [10, 20, 30]
```

**Добавление элементов:**
```python
numbers = []
numbers.append(100)  # Добавить в конец
numbers.insert(0, 50)  # Вставить 50 на позицию 0
```

**Удаление элементов:**
```python
numbers = [10, 20, 30, 40]
del numbers[1]        # Удалить элемент с индексом 1 (20)
last = numbers.pop()  # Удалить и вернуть последний элемент (40)
numbers.remove(10)    # Удалить первый найденный элемент 10
```

**Другие полезные методы:**
*   `.sort()` — сортирует список (на месте).
*   `.reverse()` — переворачивает список (на месте).
*   `.count(x)` — считает, сколько раз встречается `x`.
*   `sorted(list)` — возвращает новый отсортированный список, исходный не меняет.

### **7. Кортежи (`tuple`) — неизменяемые списки**

**Кортеж** похож на список, но его нельзя изменить после создания.

**Создание:**
```python
coordinates = (10, 20)
single_element = (5,)  # ОБЯЗАТЕЛЬНА запятая для кортежа из одного элемента!
```

**Что можно делать с кортежами?**
Всё, что не меняет данные: индексация, срезы, циклы, `len()`, `.count()`, `.index()`.

**Зачем они нужны?**
*   Защита данных от изменений.
*   Скорость работы (обычно быстрее списков).
*   Использование в качестве ключей словаря (о словарях узнаем позже).

**Классический пример использования:**
```python
# Обмен значениями переменных
a, b = 10, 20
a, b = b, a  # Теперь a = 20, b = 10
```

### **8. Преобразование между коллекциями**

Можно преобразовать один тип коллекции в другой с помощью функций `list()`, `tuple()`, `str()`.

```python
text = "Привет"
list_from_text = list(text)   # ['П', 'р', 'и', 'в', 'е', 'т']
tuple_from_text = tuple(text) # ('П', 'р', 'и', 'в', 'е', 'т')

list_back = ['П', 'р', 'и', 'в', 'е', 'т']
# Внимание! str(list_back) вернет строку-представление списка: "['П', 'р', 'и', 'в', 'е', 'т']"
# Чтобы собрать список обратно в строку, используйте join:
text_back = ''.join(list_back)  # "Привет"
```

### **Итоги и ключевые выводы**

1.  **Строки, списки, кортежи** — упорядоченные коллекции. К их элементам можно обращаться по индексу (начиная с 0).
2.  **Изменяемость:**
    *   **Списки (`list`)** — **ИЗМЕНЯЕМЫЕ**. Можно менять, добавлять, удалять элементы.
    *   **Строки (`str`) и Кортежи (`tuple`)** — **НЕИЗМЕНЯЕМЫЕ**. Чтобы их "изменить", нужно создать новый объект.
3.  Для всех трёх типов работают: **индексация**, **срезы** и **циклы**.
4.  У строк и списков есть много полезных **методов**.
5.  Коллекции можно преобразовывать друг в друга с помощью `list()`, `tuple()`, `str()`.

**Что дальше?** Во второй части познакомимся с **множествами (`set`)** и **словарями (`dict`)** — неупорядоченными коллекциями.
