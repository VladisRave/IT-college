# Множества и Словари в Python

## Введение

На прошлых занятиях мы работали с упорядоченными коллекциями, такими как списки (`list`) и кортежи (`tuple`), где у каждого элемента есть свой индекс. Сегодня мы погрузимся в мир неупорядоченных коллекций — **множеств (`set`)** и **словарей (`dict`)**.

Почему они так важны? Представьте себе библиотеку. Список — это как полка, где книги стоят в определённом порядке. А словарь — это как картотека, где вы быстро находите книгу по её названию (ключу), не зная, на какой она полке. Множество — это как мешок с уникальными шариками, где нет ни порядка, ни дубликатов.

**Ключевые вопросы этого занятия:**
- Чем множества и словари принципиально отличаются от списков?
- Как создавать множества и выполнять над ними операции (объединение, пересечение)?
- Как устроен словарь и как с его помощью быстро получать данные по ключу?
- Какие методы и операции поддерживают множества и словари?

## Часть 1: Множества (Set)

### Что такое множество? Создание и основные свойства

Множество — это неупорядоченная коллекция **уникальных** элементов. Это как математическое множество.

**Создание:**

```python
# 1. Прямое перечисление в фигурных скобках
vowels = {"а", "е", "ё", "и", "о", "у", "ы", "э", "ю", "я"}
fruits = {"apple", "banana", "orange"}

# 2. Создание из другой коллекции с помощью функции set()
numbers_list = [1, 2, 2, 3, 4, 4, 5]
unique_numbers = set(numbers_list) # {1, 2, 3, 4, 5}
print(unique_numbers)

word = "программирование"
unique_letters = set(word) # {'п', 'р', 'о', 'г', 'а', 'м', 'и', 'н', 'е', 'в'}
print(unique_letters)

# 3. Пустое множество (только через set())!
empty_set = set()
print(empty_set) # set()
```

**Важные особенности:**

1. **Неупорядоченность.** Элементы не имеют индексов. При выводе порядок может быть разным.

```python
my_set = {"a", "b", "c"}
print(my_set) # Может вывести {'c', 'a', 'b'} или любой другой порядок
```

2. **Уникальность.** Повторяющиеся элементы автоматически удаляются.

```python
my_set = {1, 2, 2, 3, 3, 3}
print(my_set) # {1, 2, 3}
```

3. **Элементы множества должны быть неизменяемыми (хэшируемыми) типами.** Можно использовать числа, строки, кортежи. Нельзя использовать списки или другие множества.

### Операции с множествами (как в математике)

Множества в Python поддерживают все основные математические операции.

```python
set_a = {1, 2, 3, 4, 5}
set_b = {3, 4, 5, 6, 7}
```

- **Объединение (Union):** Все элементы из обоих множеств. Оператор `|` или метод `.union()`.

```python
print(set_a | set_b) # {1, 2, 3, 4, 5, 6, 7}
print(set_a.union(set_b)) # То же самое
```

- **Пересечение (Intersection):** Элементы, которые есть и в `set_a`, и в `set_b`. Оператор `&` или метод `.intersection()`.

```python
print(set_a & set_b) # {3, 4, 5}
print(set_a.intersection(set_b)) # То же самое
```

- **Разность (Difference):** Элементы, которые есть в `set_a`, но отсутствуют в `set_b`. Оператор `-` или метод `.difference()`.

```python
print(set_a - set_b) # {1, 2}
print(set_a.difference(set_b)) # То же самое
```

- **Симметрическая разность (Symmetric Difference):** Элементы, которые есть только в одном из множеств (исключая общие). Оператор `^` или метод `.symmetric_difference()`.

```python
print(set_a ^ set_b) # {1, 2, 6, 7}
print(set_a.symmetric_difference(set_b)) # То же самое
```

### Работа с элементами множества

- **Проверка принадлежности:** Оператор `in`.

```python
vowels = {"a", "e", "i"}
print("a" in vowels) # True
print("x" in vowels) # False
```

- **Добавление элемента:** Метод `.add()`.

```python
vowels.add("o")
print(vowels) # {'i', 'a', 'o', 'e'}
```

- **Удаление элемента:**
  - `.remove(element)` — удаляет элемент. Если элемента нет, вызывает ошибку `KeyError`.
  - `.discard(element)` — удаляет элемент, если он есть. Если нет — не делает ничего (и не вызывает ошибку). **Это безопаснее.**
  - `.pop()` — удаляет и возвращает **случайный** элемент (т.к. порядка нет). Если множество пустое — ошибка.

```python
numbers = {1, 2, 3}
numbers.discard(2) # Удаляет 2
numbers.discard(99) # Ничего не происходит
# numbers.remove(99) # Вызвал бы KeyError

popped_element = numbers.pop()
print(popped_element) # 1 или 3
```

- **Очистка множества:** Метод `.clear()`.

```python
numbers.clear()
print(numbers) # set()
```

### Сравнение множеств

В Python можно сравнивать множества — это удобно для анализа подмножеств, совпадений и включений.

- **Равенство:** Проверяет, содержат ли два множества одни и те же элементы, независимо от порядка. Оператор: `==`.

```python
s_1 = {1, 2, 3}
s_2 = {3, 1, 2}
print(s_1 == s_2) # True
```

- **Подмножество:** Проверяет, входят ли все элементы одного множества в другое. Оператор: `<=`.

```python
s_1 = {1, 2, 3}
s_2 = {1, 2, 3, 4}
print(s_1 <= s_2) # True
```

- **Надмножество:** Проверяет, содержит ли множество все элементы другого множества. Оператор: `>=`.

```python
s_1 = {1, 2, 3, 4}
s_2 = {1, 2, 3}
print(s_1 >= s_2) # True
```

## Часть 2: Словари (Dict)

### Что такое словарь? Создание и базовые операции

Словарь — это неупорядоченная коллекция пар **ключ: значение**. Ключ выступает в роли "адреса" для быстрого доступа к значению.

**Создание:**

```python
# 1. Прямое объявление в фигурных скобках {}
student = {
    "имя": "Иван",
    "возраст": 20,
    "курс": 1,
    "оценки": [85, 90, 78]
}

# 2. Создание с помощью функции dict()
country_capital = dict(Россия="Москва", Польша="Варшава") # Ключи передаются как именные аргументы (без кавычек)

# 3. Пустой словарь
empty_dict = {}
# или
empty_dict = dict()
```

**Особенности:**
- **Ключи** должны быть неизменяемыми типами (числа, строки, кортежи).
- **Значения** могут быть любыми типами (числа, строки, списки, другие словари).
- Ключи в одном словаре **уникальны**.

### Доступ, добавление и изменение элементов

- **Получение значения по ключу:** Используйте квадратные скобки `[]`.

```python
capitals = {"Россия": "Москва", "Польша": "Варшава"}
print(capitals["Россия"]) # Москва
# print(capitals["Германия"]) # KeyError: 'Германия'
```

- **Безопасное получение значения: Метод `.get()`**
  Этот метод не вызывает ошибку, если ключа нет.

```python
print(capitals.get("Германия")) # Выведет None
print(capitals.get("Германия", "Страна не найдена")) # Выведет "Страна не найдена"
```

- **Добавление и изменение элементов:**

```python
# Если ключ существует, его значение обновится
capitals["Польша"] = "Краков" # Изменили столицу Польши
print(capitals) # {'Россия': 'Москва', 'Польша': 'Краков'}

# Если ключа нет, он будет создан
capitals["Германия"] = "Берлин" # Добавили новую пару
print(capitals) # {'Россия': 'Москва', 'Польша': 'Краков', 'Германия': 'Берлин'}
```

- **Проверка наличия ключа:** Оператор `in`.

```python
if "Франция" in capitals:
    print("Столица Франции:", capitals["Франция"])
else:
    print("Такой страны еще нет в словаре.")
```

### Перебор словаря в цикле

Цикл `for` по словарю перебирает его **ключи**.

```python
capitals = {"Россия": "Москва", "Польша": "Варшава", "Германия": "Берлин"}

# 1. Перебор ключей (по умолчанию)
for country in capitals:
    print(f"Страна: {country}")

# 2. Перебор ключей явно (метод .keys())
for country in capitals.keys():
    print(f"Страна: {country}")

# 3. Перебор значений (метод .values())
for capital in capitals.values():
    print(f"Столица: {capital}")

# 4. Перебор пар ключ-значение (метод .items()) - САМЫЙ ЧАСТЫЙ СПОСОБ!
for country, capital in capitals.items():
    print(f"Столица {country} — {capital}")
```

### Полезные методы словарей

- **`.pop(key[, default])`** — удаляет пару по ключу и возвращает значение. Если ключа нет и задано `default`, возвращает его, иначе — ошибка.

```python
removed_capital = capitals.pop("Польша")
print(removed_capital) # Варшава
# capitals.pop("Испания") # KeyError
safe_remove = capitals.pop("Испания", "Нет такого ключа")
print(safe_remove) # Нет такого ключа
```

- **`.update(other_dict)`** — добавляет пары из другого словаря, перезаписывая существующие ключи.

```python
capitals.update({"Италия": "Рим", "Германия": "Бонн"}) # Обновили Германию и добавили Италию
```

- **`.setdefault(key[, default])`** — возвращает значение по ключу. Если ключа нет, создаёт его с значением `default` (или `None`).

```python
# Классический пример: группировка слов по первой букве
text = "apple banana apricot blueberry blackberry"
words_by_letter = {}
for word in text.split():
    first_letter = word[0]
    # Если ключа first_letter нет, создается пустой список
    words_by_letter.setdefault(first_letter, []).append(word)
print(words_by_letter) # {'a': ['apple', 'apricot'], 'b': ['banana', 'blueberry', 'blackberry']}
```

- **`.clear()`** — очищает словарь

```python
capitals.clear()
print(capitals) # {}
```

- **`len(dict)`** — возвращает количество пар ключ-значение в словаре

```python
print(len(capitals)) # 0
```

### Задача 1: Телефонная книга

Создайте простую телефонную книгу. Программа должна:
1. Добавлять контакты (имя и номер телефона).
2. Искать номер по имени контакта.
3. Выводить все контакты.

```python
phonebook = {}

while True:
    print("\n1. Добавить контакт")
    print("2. Найти контакт")
    print("3. Показать все контакты")
    print("4. Выйти")

        print(f"Контакт {name} добавлен!")

        name = input("Введите имя для поиска: ")

                print(f"  {name}: {phone}")
```

### Задача 2: Анализ текста

Напишите программу, которая принимает строку и подсчитывает, сколько раз в ней встречается каждое слово. Игнорируйте регистр.

```python
text = input("Введите текст для анализа: ").lower()
# Очистим текст от знаков препинания (простой способ)
for char in ".,!?;:":
    text = text.replace(char, "")
words = text.split()

word_count = {}
for word in words:
    # Если слово уже есть в словаре, увеличиваем счетчик на 1
    # Если нет, используем 0 как значение по умолчанию и затем увеличиваем на 1
    word_count[word] = word_count.get(word, 0) + 1

print("\nЧастота слов:")
for word, count in word_count.items():
    print(f"'{word}': {count} раз(а)")

```

### Задача 3: Учет студентов и оценок

Создайте программу для учета студентов и их оценок по разным предметам.

```python
students = {}

def add_student(name):
    """Добавляет студента в систему"""
    if name not in students:
        students[name] = {}
        print(f"Студент {name} добавлен в систему.")
    else:
        print(f"Студент {name} уже есть в системе.")

def add_grade(name, subject, grade):
    """Добавляет оценку студенту по предмету"""
    if name in students:
        if subject not in students[name]:
            students[name][subject] = []
        students[name][subject].append(grade)
        print(f"Оценка {grade} по предмету {subject} добавлена студенту {name}.")
    else:
        print(f"Студент {name} не найден в системе.")

def show_grades(name):
    """Показывает все оценки студента"""
    if name in students:
        print(f"\nОценки студента {name}:")
        for subject, grades in students[name].items():
            avg_grade = sum(grades) / len(grades)
            print(f"  {subject}: {grades} (средний: {avg_grade:.2f})")
    else:
        print(f"Студент {name} не найден в системе.")

# Пример использования
add_student("Анна")
add_student("Борис")

add_grade("Анна", "Математика", 5)
add_grade("Анна", "Математика", 4)
add_grade("Анна", "Физика", 5)
add_grade("Борис", "Математика", 3)
add_grade("Борис", "История", 4)

show_grades("Анна")
show_grades("Борис")
```

### Задача 4: Система рекомендаций

Создайте простую систему рекомендаций на основе общих интересов.

```python
# База данных пользователей и их интересов
users = {
    "Анна": {"книги", "кино", "путешествия"},
    "Борис": {"спорт", "музыка", "кино"},
    "Виктор": {"книги", "программирование", "путешествия"},
    "Дарья": {"искусство", "музыка", "кино"}
}

def find_similar_users(username, users_db):
    """Находит пользователей с похожими интересами"""
    if username not in users_db:
        return "Пользователь не найден"
    
    current_user_interests = users_db[username]
    similarities = {}
    
    for user, interests in users_db.items():
        if user != username:
            # Находим пересечение интересов
            common_interests = current_user_interests & interests
            if common_interests:
                similarities[user] = common_interests
    
    return similarities

def recommend_friends(username, users_db):
    """Рекомендует друзей на основе общих интересов"""
    similar_users = find_similar_users(username, users_db)
    
    if isinstance(similar_users, str):
        print(similar_users)
        return
    
    if not similar_users:
        print(f"Для пользователя {username} нет рекомендаций.")
        return
    
    print(f"Рекомендации для {username}:")
    for user, common_interests in similar_users.items():
        print(f"  {user} (общие интересы: {', '.join(common_interests)})")

# Пример использования
recommend_friends("Анна", users)
recommend_friends("Борис", users)
```

### Задача 5: Анализ продаж

Проанализируйте данные о продажах товаров.

```python
# Данные о продажах: товар -> количество продаж
sales_data = [
    ("яблоки", 15),
    ("бананы", 8),
    ("яблоки", 10),
    ("апельсины", 12),
    ("бананы", 5),
    ("яблоки", 7),
    ("апельсины", 3)
]

def analyze_sales(sales):
    """Анализирует данные о продажах и возвращает итоги по товарам"""
    sales_summary = {}
    
    for product, quantity in sales:
        sales_summary[product] = sales_summary.get(product, 0) + quantity
    
    return sales_summary

def find_top_product(sales_dict):
    """Находит товар с наибольшими продажами"""
    if not sales_dict:
        return None
    
    top_product = max(sales_dict, key=sales_dict.get)
    return top_product, sales_dict[top_product]

# Анализ данных
summary = analyze_sales(sales_data)
print("Итоги продаж:")
for product, total in summary.items():
    print(f"  {product}: {total} шт.")

top_product, top_sales = find_top_product(summary)
print(f"\nСамый продаваемый товар: {top_product} ({top_sales} шт.)")
```

Сегодня вы освоили два мощных инструмента для работы с данными:
- **Множества (`set`)** для работы с уникальными элементами и выполнения математических операций.

3. Используйте метод `.get()` для безопасного извлечения значений из словаря.
