# Встроенные возможности Python для работы с коллекциями

## Введение

Python предоставляет мощные инструменты для работы с коллекциями данных (списками, строками и другими наборами элементов). Эти инструменты помогают писать более компактный и эффективный код.

## 1. Библиотека itertools

### Что это такое?
`itertools` — встроенная библиотека Python, содержащая функции для создания и работы с итераторами. Главное преимущество — экономия памяти, так как элементы обрабатываются по одному, а не все сразу.

### Способы импорта
```python
# Способ 1: Импорт всей библиотеки
import itertools
result = itertools.product("АБ", [1,2])

# Способ 2: Импорт конкретных функций
from itertools import product
result = product("АБ", [1,2])
```

## 2. Бесконечные итераторы

### count() — бесконечный счётчик
Создаёт бесконечную числовую последовательность.

```python
from itertools import count

for i in count(10, 2):  # Начинает с 10, шаг 2
    if i > 20:
        break
    print(i)
# Вывод: 10 12 14 16 18 20
```

### cycle() — зацикливание коллекции
Бесконечно повторяет элементы коллекции.

```python
from itertools import cycle

c = 0
for item in cycle("RUS"):
    if c >= 7:
        break
    print(item, end=' ')  # R U S R U S R
    c += 1
```

### repeat() — повтор элемента
Повторяет элемент указанное количество раз.

```python
from itertools import repeat

result = list(repeat("Hello", 3))
print(result)  # ['Hello', 'Hello', 'Hello']
```

## 3. Функции для обработки данных

### accumulate() — накопление значений
Вычисляет накопленный результат на каждом шаге.

```python
from itertools import accumulate

numbers = [1, 2, 3, 4, 5]
result = list(accumulate(numbers))
print(result)  # [1, 3, 6, 10, 15]
```

### chain() — объединение коллекций
Объединяет несколько коллекций в одну.

```python
from itertools import chain

list1 = [1, 2, 3]
list2 = [4, 5, 6]
result = list(chain(list1, list2))
print(result)  # [1, 2, 3, 4, 5, 6]
```

### product() — декартово произведение
Создаёт все возможные комбинации элементов.

```python
from itertools import product

result = list(product([1, 2], "AB"))
print(result)  # [(1, 'A'), (1, 'B'), (2, 'A'), (2, 'B')]
```

## 4. Комбинаторные функции

### permutations() — перестановки
Создаёт все упорядоченные комбинации элементов.

```python
from itertools import permutations

result = list(permutations("ABC", 2))
print(result)  
# [('A', 'B'), ('A', 'C'), ('B', 'A'), ('B', 'C'), ('C', 'A'), ('C', 'B')]
```

### combinations() — сочетания
Создаёт неупорядоченные комбинации элементов.

```python
from itertools import combinations

result = list(combinations("ABC", 2))
print(result)  # [('A', 'B'), ('A', 'C'), ('B', 'C')]
```

## 5. Встроенные функции

### enumerate() — нумерация элементов
Добавляет индекс к элементам коллекции.

```python
fruits = ['apple', 'banana', 'orange']
for index, fruit in enumerate(fruits, 1):
    print(f"{index}. {fruit}")
# Вывод:
# 1. apple
# 2. banana
# 3. orange
```

### zip() — объединение коллекций
Объединяет элементы нескольких коллекций по индексам.

```python
names = ['Alice', 'Bob', 'Charlie']
scores = [85, 92, 78]

for name, score in zip(names, scores):
    print(f"{name}: {score}")
# Вывод:
# Alice: 85
# Bob: 92
# Charlie: 78
```

9. **Каталог товаров**: Используя `enumerate`, выведите список товаров `['Ноутбук', 'Мышь', 'Клавиатура']` в формате: "Позиция 1: Ноутбук".

- Бесконечные итераторы (`count`, `cycle`, `repeat`) полезны для создания последовательностей
- Функции обработки (`accumulate`, `chain`, `product`) упрощают работу с данными
- Комбинаторные функции (`permutations`, `combinations`) помогают в решении задач комбинаторики
