## Теоретическая часть

### 1. Введение в функции

#### Что такое функция?

Представьте, что вы каждый день делаете бутерброд. Вы берете хлеб, намазываете масло, добавляете колбасу, сыр. Вместо того чтобы каждый раз описывать все эти действия, вы можете сказать: "Сделай бутерброд". Это и есть функция!

**Функция** — это именованный блок кода, который выполняет определенную задачу и может быть многократно использован в программе.

#### Зачем нужны функции?

**1. Избегание повторения кода**
```python
# Без функции (плохо)
print("=== ЗАГОЛОВОК ===")
print("Содержание страницы")
print("=== КОНЕЦ ===")

print("=== ЗАГОЛОВОК ===")
print("Другое содержание")
print("=== КОНЕЦ ===")

# С функцией (хорошо)
def напечатать_страницу(содержание):
    print("=== ЗАГОЛОВОК ===")
    print(содержание)
    print("=== КОНЕЦ ===")

напечатать_страницу("Содержание страницы")
напечатать_страницу("Другое содержание")
```

**2. Упрощение сложных программ**
Сложную задачу разбиваем на простые подзадачи, каждую из которых решает отдельная функция.

**3. Улучшение читаемости**
Вместо непонятного кода видим понятные названия функций.

**4. Облегчение отладки**
Легче найти ошибку в маленькой функции, чем в большой программе.

#### Создание и вызов простейшей функции

```python
# Определение функции (создание)
def сказать_привет():
    print("Привет, мир!")
    print("Я - функция Python")

# Вызов функции (использование)
сказать_привет()  # Это вызовет выполнение кода внутри функции
сказать_привет()  # Можно вызывать много раз
```

**Важные моменты:**
- `def` — ключевое слово для создания функции
- После названия функции всегда ставятся круглые скобки `()`
- Двоеточие `:` в конце строки объявления
- Весь код функции сдвинут на 4 пробела (отступ)

### 2. Функции с параметрами

#### Что такое параметры?

**Параметры** — это переменные, которые функция получает при вызове. Они позволяют функции работать с разными данными.

```python
# Функция с одним параметром
def поздороваться(имя):
    print(f"Привет, {имя}!")
    print("Рад тебя видеть!")

# Вызовы с разными аргументами
поздороваться("Анна")     # "имя" становится "Анна"
поздороваться("Петр")     # "имя" становится "Петр"
поздороваться("Мария")    # "имя" становится "Мария"
```

#### Разница между параметрами и аргументами

- **Параметры** — это переменные в определении функции (в скобках после названия)
- **Аргументы** — это конкретные значения, которые мы передаем при вызове

```python
# Параметры: "а" и "б"
def умножить(а, б):
    результат = а * б
    print(f"{а} * {б} = {результат}")

# Аргументы: 5 и 3
умножить(5, 3)  # Выведет: 5 * 3 = 15

# Аргументы: 7 и 4  
умножить(7, 4)  # Выведет: 7 * 4 = 28
```

#### Разные типы параметров

**1. Обязательные параметры**
```python
def создать_письмо(кому, тема, текст):
    print(f"Кому: {кому}")
    print(f"Тема: {тема}")
    print(f"Текст: {текст}")

# Все три аргумента обязательны
создать_письмо("директору", "Отчет", "Представляю отчет...")
```

**2. Параметры со значениями по умолчанию**
```python
def создать_письмо(кому, тема, текст="С уважением!"):
    print(f"Кому: {кому}")
    print(f"Тема: {тема}")
    print(f"Текст: {текст}")

# Можно не передавать третий аргумент
создать_письмо("другу", "Привет")  # Используется значение по умолчанию
создать_письмо("коллеге", "Встреча", "Жду вас в 15:00")  # Свое значение
```

### 3. Возврат значений из функций

#### Оператор return

Функция может не только что-то делать, но и возвращать результат своей работы.

```python
def вычислить_площадь_прямоугольника(длина, ширина):
    площадь = длина * ширина
    return площадь  # Возвращаем результат

# Сохраняем результат в переменную
результат = вычислить_площадь_прямоугольника(5, 3)
print(f"Площадь прямоугольника: {результат}")  # Площадь прямоугольника: 15

# Используем результат сразу в выражении
общая_площадь = вычислить_площадь_прямоугольника(4, 2) + вычислить_площадь_прямоугольника(3, 3)
print(f"Общая площадь: {общая_площадь}")  # Общая площадь: 17
```

#### Возврат нескольких значений

Функция может возвращать несколько значений одновременно:

```python
def анализировать_числа(числа):
    минимум = min(числа)
    максимум = max(числа)
    среднее = sum(числа) / len(числа)
    return минимум, максимум, среднее  # Возвращаем три значения

# Получаем все три значения
мин, макс, ср = анализировать_числа([4, 2, 8, 1, 9])
print(f"Минимум: {мин}")    # Минимум: 1
print(f"Максимум: {макс}")  # Максимум: 9  
print(f"Среднее: {ср}")     # Среднее: 4.8
```

#### Что возвращает функция без return?

Если в функции нет оператора `return`, она возвращает специальное значение `None` (ничего).

```python
def напечатать_приветствие(имя):
    print(f"Привет, {имя}!")
    # Нет оператора return

результат = напечатать_приветствие("Анна")
print(результат)  # Выведет: None
```

### 4. Области видимости

#### Что такое область видимости?

**Область видимости** — это часть программы, где переменная доступна для использования.

#### Локальные переменные

Переменные, созданные внутри функции, называются **локальными**. Они существуют только внутри этой функции.

```python
def пример_функции():
    локальная_переменная = "Я существую только внутри функции"
    print(локальная_переменная)  # Работает

пример_функции()
# print(локальная_переменная)  # ОШИБКА! Переменная не существует снаружи
```

#### Глобальные переменные

Переменные, созданные вне функций, называются **глобальными**. Они доступны везде в программе.

```python
глобальная_переменная = "Я доступна везде"

def показать_переменную():
    print(f"Внутри функции: {глобальная_переменная}")  # Можем читать глобальную переменную

показать_переменную()
print(f"Снаружи функции: {глобальная_переменная}")  # Тоже работает
```

#### Проблема изменения глобальных переменных

По умолчанию мы не можем изменять глобальные переменные внутри функции:

```python
счетчик = 0

def увеличить_счетчик():
    # счетчик += 1  # ОШИБКА! Нельзя изменить глобальную переменную
    локальный_счетчик = счетчик + 1  # Но можем читать и создавать локальную копию
    print(f"Локальный счетчик: {локальный_счетчик}")

увеличить_счетчик()
print(f"Глобальный счетчик: {счетчик}")  # Все еще 0
```

#### Ключевое слово global

Если действительно нужно изменить глобальную переменную, используем `global`:

```python
счетчик = 0

def увеличить_счетчик():
    global счетчик  # Говорим Python, что мы хотим работать с глобальной переменной
    счетчик += 1
    print(f"Счетчик теперь: {счетчик}")

print(f"Начальное значение: {счетчик}")  # 0
увеличить_счетчик()  # Счетчик теперь: 1
увеличить_счетчик()  # Счетчик теперь: 2
увеличить_счетчик()  # Счетчик теперь: 3
print(f"Конечное значение: {счетчик}")   # 3
```

#### Лучший способ: возврат значений

Вместо изменения глобальных переменных лучше возвращать новые значения:

```python
счетчик = 0

def увеличить(значение):
    новое_значение = значение + 1
    return новое_значение

счетчик = увеличить(счетчик)  # 1
счетчик = увеличить(счетчик)  # 2  
счетчик = увеличить(счетчик)  # 3
print(f"Счетчик: {счетчик}")  # 3
```

### Задание 1: Простая функция-калькулятор

**Цель:** Научиться создавать функцию с параметрами и возвращать результат.

```python
def калькулятор(а, б, операция):
    """
    Функция выполняет арифметические операции над двумя числами.
    
    Параметры:
    а - первое число
    б - второе число  
    операция - символ операции: '+', '-', '*', '/'
    
    Возвращает:
    результат операции или сообщение об ошибке
    """
    if операция == '+':
        return а + б
    elif операция == '-':
        return а - б
    elif операция == '*':
        return а * б
    elif операция == '/':
        if б != 0:
            return а / б
        else:
            return "Ошибка: деление на ноль!"
    else:
        return "Ошибка: неизвестная операция"

# Проверка работы функции
print("=== Тестирование калькулятора ===")
print(f"10 + 5 = {калькулятор(10, 5, '+')}")
print(f"10 - 5 = {калькулятор(10, 5, '-')}")
print(f"10 * 5 = {калькулятор(10, 5, '*')}")
print(f"10 / 5 = {калькулятор(10, 5, '/')}")
print(f"10 / 0 = {калькулятор(10, 0, '/')}")
print(f"10 ? 5 = {калькулятор(10, 5, '?')}")
```

### Задание 2: Функция для работы со списками

**Цель:** Научиться возвращать несколько значений из функции.

```python
def анализ_списка(числа):
    """
    Анализирует список чисел и возвращает статистику.
    
    Параметры:
    числа - список чисел для анализа
    
    Возвращает:
    кортеж из (сумма, среднее, минимум, максимум)
    """
    if not числа:  # Если список пустой
        return 0, 0, 0, 0
    
    сумма = sum(числа)
    среднее = сумма / len(числа)
    минимум = min(числа)
    максимум = max(числа)
    
    return сумма, среднее, минимум, максимум

# Проверка работы функции

print(f"Список: {test_список}")
print(f"Сумма: {сумма}")
print(f"Среднее: {среднее}")
print(f"Минимум: {минимум}")
print(f"Максимум: {максимум}")

# Тест с пустым списком
```

### Задание 5: Функция для форматирования текста

**Цель:** Научиться создавать более сложные функции с циклами.

```python
def форматировать_текст(текст, макс_длина):
    """
    Разбивает текст на строки заданной максимальной длины.
    
    Параметры:
    текст - исходный текст
    макс_длина - максимальная длина строки
    
    Возвращает:
    текст, разбитый на строки
    """
    слова = текст.split()  # Разбиваем текст на слова
    текущая_строка = ""
    результат = ""
    
    for слово in слова:
        # Если добавление слова не превысит максимальную длину
        if len(текущая_строка) + len(слово) <= макс_длина:
            if текущая_строка:  # Если строка не пустая, добавляем пробел
                текущая_строка += " " + слово
            else:  # Если строка пустая, просто добавляем слово
                текущая_строка = слово
        else:
            # Добавляем текущую строку к результату и начинаем новую
            if результат:
                результат += "\n" + текущая_строка
            else:
                результат = текущая_строка
            текущая_строка = слово
    
    # Добавляем последнюю строку
    if текущая_строка:
        if результат:
            результат += "\n" + текущая_строка
        else:
            результат = текущая_строка
    
    return результат

# Проверка работы функции
print("\n=== Тестирование форматирования текста ===")
исходный_текст = "Это очень длинный текст который нужно разбить на несколько строк чтобы он хорошо выглядел при выводе на экран"

print("Исходный текст:")
print(исходный_текст)

print("\nФорматированный текст (максимальная длина 20):")
форматированный = форматировать_текст(исходный_текст, 20)
print(форматированный)

print("\nФорматированный текст (максимальная длина 30):")
форматированный = форматировать_текст(исходный_текст, 30)
print(форматированный)
```

## Частые ошибки и как их избежать

### Ошибка 1: Забыли двоеточие
```python
# Неправильно
def моя_функция()  # Нет двоеточия
    print("Привет")

# Правильно  
def моя_функция():  # Есть двоеточие
    print("Привет")
```

### Ошибка 2: Неправильные отступы
```python
# Неправильно
def моя_функция():
print("Привет")  # Нет отступа

# Правильно
def моя_функция():
    print("Привет")  # Есть отступ в 4 пробела
```

### Ошибка 3: Путаница с локальными и глобальными переменными
```python
счетчик = 0

# Неправильно
def увеличить():
    счетчик += 1  # Ошибка: попытка изменить глобальную переменную

# Правильно
def увеличить():
    global счетчик  # Указываем, что работаем с глобальной переменной
    счетчик += 1

# Или лучше так (без global):
def увеличить(текущее_значение):
    return текущее_значение + 1
```

### Ошибка 4: Функция определена, но не вызвана
```python
def полезная_функция():
    print("Я делаю что-то полезное")

# Функция не будет выполнена, так как нет вызова
# полезная_функция()  # Нужно раскомментировать эту строку
```
